## 阶段1：任务接收与分配

### 1.1 接收评分任务

**输入格式**：
```markdown
# 评分任务请求

## 基本信息
- 任务编号：[自动生成 RAT-YYYYMMDD-XXX]
- 请求人：[姓名/部门]
- 请求时间：YYYY-MM-DD HH:MM
- 截止时间：YYYY-MM-DD HH:MM

## 待评内容
- 内容类型：[文章/视频/代码/设计/其他]
- 内容标题：[标题]
- 内容来源：[URL/文件路径/附件]
- 内容格式：[文本/链接/文件]

## 评分要求
- 评分标准：[标准A/标准B/自定义]
- 重点关注：[维度列表]
- 特殊要求：[如有]

## 其他
- 优先级：[高/中/低]
- 是否需要仲裁：[是/否]
- 备注：[其他说明]
```

### 1.2 任务验证

协调员检查：
1. 内容是否完整可访问
2. 评分标准是否明确
3. 截止时间是否合理
4. 是否需要额外信息

**验证结果**：
- ✅ 通过 → 进入分配阶段
- ❌ 不通过 → 返回请求人，说明原因

### 1.3 任务分配

**分配动作**：

1. **生成任务编号**：`RAT-YYYYMMDD-XXX`
2. **创建任务文件夹**：`/rating-team/coordinator/tasks/RAT-YYYYMMDD-XXX/`
3. **复制待评内容**到共享区
4. **通知专家A**：
   ```
   发送给 expert-a：
   
   您有新的评分任务
   - 任务编号：RAT-YYYYMMDD-XXX
   - 内容类型：[类型]
   - 截止时间：YYYY-MM-DD HH:MM
   - 请立即开始独立评分
   - ⚠️ 禁止与专家B沟通
   ```
5. **通知专家B**：
   ```
   发送给 expert-b：
   
   您有新的评分任务
   - 任务编号：RAT-YYYYMMDD-XXX
   - 内容类型：[类型]
   - 截止时间：YYYY-MM-DD HH:MM
   - 请立即开始独立评分
   - ⚠️ 禁止与专家A沟通
   ```

## 阶段2：独立评分（核心阶段）

### 2.1 专家A评分流程

**步骤**：
1. 接收任务通知
2. 访问共享区获取待评内容
3. 阅读评分标准（**只使用专家A版本的标准**）
4. 进行独立评分
   - 不使用任何外部帮助（除了工具）
   - 不查看专家B的任何信息
   - 每个得分都记录详细理由
5. 填写评分报告模板（A版）
6. 质量自检
7. 提交报告到 `/rating-team/expert-a/reports/RAT-YYYYMMDD-XXX.md`
8. 通知协调员"评分完成"

**独立评分承诺书**（专家A）：
```
我，评分专家A，郑重承诺：

1. 本评分完全独立完成
2. 评分过程中未与专家B沟通
3. 未查看专家B的任何评分信息
4. 所有评分基于内容本身
5. 评分理由真实详细

承诺人：专家A（reality-checker）
时间：YYYY-MM-DD HH:MM:SS
```

### 2.2 专家B评分流程

**步骤**：（与专家A相同，但完全独立）

1. 接收任务通知
2. 访问共享区获取待评内容
3. 阅读评分标准（**只使用专家B版本的标准**）
4. 进行独立评分
   - 不使用任何外部帮助（除了工具）
   - 不查看专家A的任何信息
   - 每个得分都记录详细理由
5. 填写评分报告模板（B版）
6. 质量自检
7. 提交报告到 `/rating-team/expert-b/reports/RAT-YYYYMMDD-XXX.md`
8. 通知协调员"评分完成"

**独立评分承诺书**（专家B）：
```
我，评分专家B，郑重承诺：

1. 本评分完全独立完成
2. 评分过程中未与专家A沟通
3. 未查看专家A的任何评分信息
4. 所有评分基于内容本身
5. 评分理由真实详细

承诺人：专家B（test-results-analyzer）
时间：YYYY-MM-DD HH:MM:SS
```

### 2.3 独立性保证机制

**技术措施**：
- 专家A和B的工作区完全隔离
- 评分报告提交前，协调员不透露任何信息
- 使用文件权限控制访问

**流程措施**：
- 专家A和B不能同时在线讨论（如果可能）
- 评分完成后才能查看对方结果
- 违反独立性规定的评分作废

**监督措施**：
- 协调员监控评分过程
- 随机抽查评分记录
- 建立申诉机制

### 2.4 评分超时处理

**超时前30分钟**：协调员发送提醒
```
提醒：您的评分任务 RAT-YYYYMMDD-XXX 将在30分钟后到期，请尽快完成。
```

**超时后**：
- 专家A或B超时 → 协调员记录超时
- 超时 < 1小时 → 警告
- 超时 ≥ 1小时 → 任务重新分配或使用单方面评分

## 阶段3：结果收集

### 3.1 收集评分报告

**协调员动作**：

1. 接收专家A的"评分完成"通知
2. 接收专家B的"评分完成"通知
3. 从各自报告目录收集评分报告：
   - A版：`/rating-team/expert-a/reports/RAT-YYYYMMDD-XXX.md`
   - B版：`/rating-team/expert-b/reports/RAT-YYYYMMDD-XXX.md`
4. 验证报告完整性：
   - 是否包含所有必需字段
   - 是否有评分理由
   - 格式是否符合要求
5. 将报告复制到协调员工作区：
   - `/rating-team/coordinator/tasks/RAT-YYYYMMDD-XXX/expert-a-report.md`
   - `/rating-team/coordinator/tasks/RAT-YYYYMMDD-XXX/expert-b-report.md`

## 阶段4：对比分析

### 4.1 数据提取

从A版和B版报告中提取关键数据：

```json
{
  "taskId": "RAT-20260516-001",
  "expertA": {
    "dimension1": 8.5,
    "dimension2": 7.0,
    "dimension3": 9.0,
    "totalScore": 8.15,
    "grade": "B",
    "completionTime": "2026-05-16T14:30:00Z"
  },
  "expertB": {
    "dimension1": 8.0,
    "dimension2": 7.5,
    "dimension3": 8.5,
    "totalScore": 8.0,
    "grade": "B",
    "completionTime": "2026-05-16T15:00:00Z"
  }
}
```

### 4.2 差异计算

**计算公式**：

```
差异 = |专家A得分 - 专家B得分|

例如：
维度1差异 = |8.5 - 8.0| = 0.5
维度2差异 = |7.0 - 7.5| = 0.5
维度3差异 = |9.0 - 8.5| = 0.5
总分差异 = |8.15 - 8.0| = 0.15
```

### 4.3 一致性判断

**一致性标准**（可配置）：

| 差异范围 | 一致性等级 | 处理方式 |
|---------|-----------|---------|
| ≤ 1.0分 | ✅ 高一致性 | 直接进入报告生成 |
| 1.0-2.0分 | ⚠️ 中等差异 | 协调员审核后可生成报告 |
| 2.0-4.0分 | ⚠️⚠️ 低一致性 | **必须**进入冲突处理 |
| > 4.0分 | ❌ 严重冲突 | **必须**进入仲裁流程 |

### 4.4 生成对比分析报告

**contrast-analysis-report.md**
```markdown
# 评分对比分析报告

## 任务信息
- 任务编号：RAT-YYYYMMDD-XXX
- 分析时间：YYYY-MM-DD HH:MM:SS
- 协调员：[协调员标识]

## 评分对比

| 维度 | 专家A | 专家B | 差异 | 一致性 |
|------|-------|-------|------|--------|
| 维度1 | 8.5 | 8.0 | 0.5 | ✅ 高 |
| 维度2 | 7.0 | 7.5 | 0.5 | ✅ 高 |
| 维度3 | 9.0 | 8.5 | 0.5 | ✅ 高 |
| **总分** | **8.15** | **8.0** | **0.15** | ✅ 高 |

## 一致性评估

**整体一致性**：✅ 高一致性  
**平均差异**：0.44分  
**最大差异**：0.5分（维度1、2、3）  
**判断**：两位专家评分高度一致，无需冲突处理。

## 详细对比

### 优点共识
- [优点1]：两位专家都认可
- [优点2]：两位专家都认可

### 不足共识
- [不足1]：两位专家都指出
- [不足2]：两位专家都指出

### 差异点分析
- [差异点1]：专家A认为是优点，专家B认为是不足
  - 专家A理由：[...]
  - 专家B理由：[...]
  - 分析：[...]

## 建议

基于两位专家的评分，建议最终评分为：**8.08分**（平均分）  
建议等级：**B级（良好）**

## 下一步

- [x] 对比分析完成
- [ ] 无需冲突处理
- [ ] 进入报告生成阶段
```

## 阶段5：冲突处理（可选）

### 5.1 触发条件

**自动触发**：
- 任一维度差异 > 2.0分
- 总分差异 > 2.0分

**手动触发**：
- 协调员认为需要
- 请求人要求

### 5.2 冲突处理流程

**步骤1：通知专家**

```
发送给专家A和B：

评分任务 RAT-YYYYMMDD-XXX 进入冲突处理流程。

冲突详情：
- 冲突维度：[维度列表]
- 冲突程度：[轻微/中等/严重]

请准备：
1. 复审自己的评分
2. 阅读对方的评分理由
3. 准备辩护或调整

截止时间：YYYY-MM-DD HH:MM
```

**步骤2：独立复审**

专家A和B分别：
1. 阅读对方的评分报告
2. 对比差异
3. 决定：
   - **坚持原评分** → 提供辩护理由
   - **调整评分** → 提供调整理由和新评分

**步骤3：协商（可选）**

如果双方都同意，可以进行协商讨论：
- 协调员主持
- 每次讨论 ≤ 30分钟
- 讨论后各自独立决定

**步骤4：二次提交**

专家A和B提交最终评分：
- A版最终：`/coordinator/tasks/.../expert-a-final.md`
- B版最终：`/coordinator/tasks/.../expert-b-final.md`

**步骤5：二次对比**

协调员再次对比最终评分：
- 差异缩小 → 接受
- 差异仍大 → 进入仲裁

### 5.3 仲裁流程

**触发条件**：
- 二次对比后差异仍 > 2.0分
- 专家A和B无法达成一致
- 协调员判断需要仲裁

**仲裁员**：
- 默认：协调员担任
- 或：指定第三方专家（专家C）

**仲裁流程**：

1. 仲裁员接收所有材料：
   - A版最终评分
   - B版最终评分
   - 冲突处理记录
   - 原始待评内容

2. 仲裁员独立评审：
   - 重新评分（不依赖A和B）
   - 对比三方评分（A、B、仲裁员）
   - 确定最终评分

3. 生成仲裁报告：

```markdown
# 仲裁报告

## 任务信息
- 任务编号：RAT-YYYYMMDD-XXX
- 仲裁员：[标识]
- 仲裁时间：YYYY-MM-DD HH:MM:SS

## 三方评分对比

| 维度 | 专家A | 专家B | 仲裁员 | 最终评分 |
|------|-------|-------|--------|---------|
| 维度1 | X1 | Y1 | Z1 | Z1 |
| 维度2 | X2 | Y2 | Z2 | Z2 |
| 维度3 | X3 | Y3 | Z3 | Z3 |
| 总分 | X | Y | Z | Z |

## 仲裁理由

[详细解释为什么选择仲裁员的评分作为最终评分]

## 最终评分

**最终评分**：Z分  
**最终等级**：[A/B/C/D/E]  
**仲裁说明**：[简要说明]

## 签字

仲裁员：[签名]  
日期：YYYY-MM-DD
```
