## 二、分项知识沉淀

### 2.1 人设语言库（文案根·扣分项最多）

#### 老陈专属人设语言体系

**身份锚点库**（必用）
```
- "42岁研发总监"
- "33人团队"
- "三明学院出身"
- "20年老研发"
- "我是老陈"（固定结尾）
```

**人设金句库**（按情绪分类）

| 类型 | 金句 | 适用场景 |
|------|------|---------|
| 自嘲型 | "众生皆傻，何必在意" | 放下焦虑、真实表达 |
| 反击型 | "我是做研发的，AI说的我不全信" | 被质疑、理性分析 |
| 佛系型 | "见青山多妩媚，料青山见我应如是" | 平和心态、高境界 |
| 倔强型 | "今天我不管AI，拍完直接发" | 自我坚持、真实人设 |
| 结果型 | "播放2.6万，涨粉194" | 展示成绩、建立信任 |
| 忠告型 | "关注我，少踩坑" | 结尾引流（替代"交作业"） |

**33个爆款文案句式（精编版）**

*提问型开头（17选常用）*
```
1. [身份+结果] 20年老研发，如何从月薪5千做到总监？
2. [反问] 为什么三明学院毕业也能做到研发总监？
3. [共鸣] 有没有和我一样，被AI说没钩子的？
4. [警示] 你知道AI什么时候会骗你吗？
5. [对比] 稳重的人做自媒体，真的没冲劲的人爆吗？
6. [数字] 做研发20年，我发现职场人就分3种
```

*提醒型开头（16选常用）*
```
1. [身份标签] 研发总监提醒你：AI说的这3句话别信
2. [警告] 40岁以后，在职场一定要明白这件事
3. [利益] 三明学院毕业也能做研发总监，只需做到这几点
4. [排除] 不是所有人都适合AI自媒体，但你是例外
```

#### 老陈钩子公式（自创·已验证）

```
公式：身份锚点 + 反常识事实 + 悬念
示例："42岁研发总监，被AI说视频没钩子——我试了它说的'标准做法'，播放量只有500"
```

#### 人设语言禁忌（已踩坑）

| 禁忌 | 替代方案 |
|------|---------|
| "交作业" | "关注我，少踩坑" |
| "带你一起做" | "我的经验，你参考" |
| "私信我" | "评论区问我" |
| 晒具体薪资 | "从基层到总监" |
| 无身份开头 | 必须先报年龄/职位/背景 |

### 2.3 图文实操方法论

#### 抖音图文账号定位

| 类型 | 特点 | 适合老陈吗 | 操作建议 |
|------|------|-----------|---------|
| 图文带货 | 商品+图片 | ❌ 不适合 | — |
| 图文引流 | 公域→私域 | ✅ 适合导流 | 内容钩子+私信 |
| 静态图文IP | 品牌宣传 | ✅ 适合人设 | 固定模板+日更 |
| 图文矩阵 | 多账号分发 | ⚠️ 后期考虑 | 等万粉后 |

#### 图文内容制作5步法

```
Step 1 选题库搭建
→ 热点追踪工具抓取1000+爆款关键词
→ 按"职场/AI/人设/转型"分类

Step 2 内容模板化
→ 拆解为15秒/30秒/60秒三种版本
→ 老陈版本：统一封面模板（照片+文字）

Step 3 素材处理
→ 图文：9图横版（1封面+8内容）
→ 静态图文：固定字体+配色

Step 4 合规检查
→ 敏感词过滤（私信/收徒/带你等禁用）
→ 禁止二维码/外链

Step 5 智能分发
→ 定时发布（13:00/18:00黄金期）
→ 多平台同步（抖音+小红书+B站）
```

#### 图文爆款5大核心指标

| 指标 | 标准值 | 老陈现状 |
|------|--------|---------|
| 跨平台内容重复率 | ≤28% | 待建立 |

| 爆款二次创作周期 | ≤72小时 | 待建立 |
| 粉丝画像重合度 | 35-45% | 待测试 |
| 泛账号导流率 | ≥17% | 待建立 |

#### 图文+短视频协同策略

```
短视频（钩子）：吸引关注、展示人设
    ↓
```

### 2.4 铁粉运营机制

#### 铁粉机制原理

> 抖音铁粉机制：将内容**优先展示给铁粉**，铁粉喜爱程度决定是否进入更大流量池。
> 铁粉互动率 = 普通粉丝 **3倍以上**

#### 铁粉养成三步法

```
第一步：筛选（谁是铁粉？）
→ 关注≥7天
→ 点赞/评论/分享频次高
→ 观看时长>70%

第二步：激活（如何让铁粉更活跃？）
→ 粉丝群专属福利（未公开花絮、直播优先码）
→ 定期"翻牌"回复评论
→ 发起投票/打卡活动

第三步：转化（如何让铁粉带新粉？）
→ 引导分享："这期内容帮你朋友看看"
→ 互动钩子："评论区说出你的故事"
→ 裂变激励：转发@好友解锁隐藏内容
```

| 内容类型 | 占比 | 老陈可用形式 |
|---------|------|------------|
| 独家福利 | 30% | 直播花絮、未发视频、拍摄幕后 |
