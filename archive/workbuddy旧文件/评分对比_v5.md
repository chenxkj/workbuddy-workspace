## 一、本次学习内容摘要

### 文档1：30分钟直播带货剧本.doc ✅ 完整提取
**核心价值：直播剧本SOP**

| 阶段 | 时长 | 核心动作 |
|------|------|----------|
| 聚人 | 0-5min | 拉家常 + 包装产品背景/口碑，聚好奇心 |
| 留客 | 5-7min | 宣布促销政策（抽奖/红包/大让利），拖住用户 |
| 锁客 | 7-12min | 提问互动 + 现场试用，激发购买需求 |
| 举证 | 12-16min | 出示三证/好评/销量/专家背书 |
| 说服 | 16-22min | 功效/价位/成分/包装与竞品对比 |
| 催单 | 22-27min | 宣布价格 + 限时促销，热情高潮 |
| 逼单 | 27-30min | 倒计时 + 即时销量，营造紧迫感 |

**关键洞察：**
- "聚人"阶段不提产品，勾起好奇心后再讲
- "锁客"用提问方式让用户自己说出痛点
- "催单"前必须先完成"举证"和"说服"，顺序不能乱

**核心价值：行业直播节奏数据库**

覆盖行业：
- 食品类（零食/水果/农产品）：产地+试吃+实验+秒杀
- 彩妆类：手背涂抹+妆容教学+挂链接
