# 抖音运营核心规范

## 老陈专属公式
- **视频公式**：强钩子开头 + 每5秒有转折的中间 + 真话结尾
- **标题公式**：[仪式感/身份锚点] + [悬念/反差] + [真诚承诺]
- **钩子公式**：身份锚点 + 反常识事实 + 悬念
- **时长**：严格25-30秒
- **2秒跳出公式**：视频钩子 + 音乐钩子 = 降低2秒跳出率

## 核心数据基准
| 指标 | 目标 |
|------|------|
| 完播率 | ≥35%（实际冷启动8-15%） |
| 3秒完播 | ≥65% |
| 点赞率 | ≥3%（进入推荐池硬门槛） |
| 冷启动判定 | 12小时 |

## 三率权重
| 指标 | 权重 | 冷启动目标 | 进阶目标 |
|------|------|-----------|----------|
| 完播率 | 60% | ≥10% | ≥40% |
| 互动率 | 30% | ≥1.5% | ≥5% |
| 转化率 | 10% | ≥0.5% | ≥2% |

## 标题适配原则
**适合**：引发好奇/提出疑问/数字对比/身份反转/真诚表达
**禁用**：夸张型(格局炸裂)/情绪化(真的会谢)/无厘头(别点这是广告)
**禁用词**：格局炸裂/真的会谢/救命SOS/绝了/后悔没早点知道/教你三招

## 文案原则
- 不能用"真"做人设，不能说"用人设对抗算法"
- 描述事实+诚实归因，不贴标签
- ✅ "视频太长，没有节奏" / ❌ "我太端着"
- 描述文案≠口播逐字稿，制造好奇不剧透

## 账号核心原则
- 禁止讨好型AI内容，严禁无脑吹AI
- 只输出真实价值（AI能做什么/不能做什么/什么时候会骗你）

## 抖音合规红线
- 禁止具体薪资数额/数字暗示资产
- 禁止营销引流话术（带你一起做/评论区留言/收徒/有需要私信）
- 禁止任何二维码/分享码/联系方式
- 话题标签最多5个

## 拍摄风格标准
- 机位固定：正面近景，不动
- 表情克制：不夸张，不笑不哭不低头
- 背景固定：纯白墙，素材后期剪入
- 分镜只写画面说明，不写表情指令

## 封面设计规范
- 4要素：身份锚点 + 情绪关键词 + 数字悬念 + 人设感
- 封面与开场呼应：关键词重复/数字预埋/身份锚点
- 每期必须附即梦封面Prompt

## 踩坑教训（速查）
| 类别 | 核心教训 |
|------|----------|
| 限流 | 深度单点，不开头"分享3个工具"，2天1条换选题 |
| 开头 | 身份+金额+项目+冲突，3秒内 |
| 结构 | 每5秒转折，故事→冲突→干货→结尾 |
| 节奏 | 25-30秒，平铺直叙=完播崩盘 |
| 结尾 | "关注我少踩坑"替代"交作业" |
| AI内容 | 教用户识别AI讨好，客观分析AI能力边界 |

4. 流量预计+操作说明 5. 标题方案×5 6. 话题标签策略
7. 描述文案 8. BGM推荐 9. 冷启动暖场评论×3（≥15字）
10. 评论区运营策略 11. 7维质量评分卡（必须引用逐字稿）
12. 优化前后对比 13. 复盘模板 14. 即梦封面Prompt

**评分铁律**：每项得分必须有脚本逐字稿文字支撑，不引用备注/设计意图。

## 操作规范（固化）
- 写完方案 → 自检13项清单（不跳步）
- 用户发截图 → 先读再分析
- 承诺内容 → 必须匹配实际交付
- 用户确认内容 → 原样写入，不优化不改动
- **新规范 → 先读memory确认所有规范**
- replace_in_file失败 → 先重读文件确认old_str确切文字
