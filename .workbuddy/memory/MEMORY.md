### 19条公开视频全量分析·关键发现

| 发现 | 内容 | 修正前认知 |
|------|------|:---------:|
| **5s完播率≠播放量** | r=0.045（几乎无关） | 以为5s高→播放高 |
| **完播率≠粉丝增量** | r=-0.033（几乎无关） | 以为完播高→涨粉多 |
| **互动指标≠播放原因** | r=0.87-0.92（是结果） | 以为互动高→算法推更多 |
| **选题宽度=天花板** | 高播组全有大众话题 | 忽视选题因素 |

### 指标真实优先级（v1.2）
1. **选题受众宽度**：决定流量天花板（无法靠技巧弥补）
2. **5s完播率/2s跳出率**：冷启动漏斗第一关
3. **完播率**：留存天花板，影响二次推流
4. **互动指标**：二次推流信号，非播放量原因
5. **封面点击率**：后台17.15%（5-11至5-17周期）

### 高播(>1万) vs 低播(≤1万) 实测差异

| 播放均值 | 71,393 | 2,549 |
| 5s完播率 | 47.3% | 42.9% |

| 互动率 | 1.65% | 2.22%（低播反而更高！） |
