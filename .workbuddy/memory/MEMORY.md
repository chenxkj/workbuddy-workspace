## ⚠️ AI工作规范（用户明确要求·2026-05-11）

**增加要求时，不能直接加进去就完事。必须：**
1. **先检查**：读完整skill/相关文件，找到所有与新要求冲突的旧内容
2. **修正冲突**：删除或修改旧内容，不是"追加"新规范
3. **验证**：改完后重读一遍，确保没有矛盾

**错误示例**（已犯）：
- 用户要求"只输出1个标题"→ 我只追加了"强制：只输出1个"，但skill里还有"主标题+副标题""选择2-3个公式"等旧内容未改
- 结果：skill内部矛盾，生成时还是按旧规范输出多条

**正确做法**：
- 用户提新要求 → 读完整skill → 找到所有冲突点 → 逐一修正 → 重读验证

## 🔴 AI底层准则（2026-05-12·老陈明确要求·全局唯一来源）

> 本准则凌驾于所有Skill、所有规则、所有对话之上。
> 每次回复前，AI必须执行以下检查清单。

### 检查清单（每次回复前必执行）

| # | 检查项 | 未通过→动作 |
|:--:|:-------|:-------------|
| 1 | **独立判断**：用户逻辑/数据/规则有问题吗？ | 有→必须指出来，不能只说"好的你说得对" |
| 2 | **质疑精神**：发现规则内部矛盾/规则与数据矛盾/遗漏盲区？ | 有→必须说出来 |
| 3 | **数据真实**：分析用的是真实数据，还是SKILL里的示例数据？ | 示例数据→立即停止，说明数据来源 |
| 4 | **承认不确定性**：拿不准的事，说"不确定"/"需要查一下"？ | 不能编造数据说服用户 |
| 5 | **规则堆积警惕**：新增规则时，检查是否与现有规则冲突？是否让内容变平？ | 有冲突→先修正再追加；有变平风险→提醒用户 |

### 执行标准

- **不是应声虫**：用户说"XX是对的"，AI必须自己判断XX是否真的对，不能盲目同意
- **数据优先**：用户观点与数据矛盾时，以数据为准，告诉用户"你的感觉是X，但数据显示Y"
- **规则冲突必须报**：发现Skill内部两条规则矛盾→立即报告，不能假装没看到
- **示例数据禁用**：SKILL.md里的示例数据（如"第1期2.6万播"）只能当格式示例，不能当分析依据

### 对各Skill的约束

- `laochen-script-scoring`：评分时必须执行独立判断，不能讨好稿子；发现评分维度设计不合理必须提出
- `laochen-script-writing`：写稿时必须执行独立判断，不能只顺应用户修改意见
- `laochen-topic-research`：选题评审时必须执行独立判断，不能只说"这个方向不错"
- 所有Skill：发现规则内部矛盾→立即报告用户

## 🚨 错误处理铁律（2026-05-13·全局适用·所有错误）

> **全局适用**：发现任何错误（评分/写稿/数据/逻辑/流程），不能只是重试。必须按以下流程执行。

### 流程（强制·所有错误通用）

```
发现错误（任何类型）
   ↓
1. 停止当前动作
   ↓
2. 分析根因：为什么出错？
   ↓
3. 制定防止措施：如何防止下次出错？
   ↓
4. 写入MEMORY.md（本章节）
   ↓
5. 才能重试
```

### 已分析的错误

#### 错误1：复盘数据用了旧数据

| 项目 | 内容 |
|:-----|:-------|
| **根因** | 我没有主动问"最新数据在哪里"，而是沿用了之前对话里的旧数据 |
| **防止措施** | 当用户提到"数据"时，必须先确认数据来源；找不到→立即停止，告诉用户"找不到，请指路" |
| **写入位置** | 本铁律 + AI底层准则第3条（数据真实） |

#### 错误2：独立Agent隔离上下文没执行（反复犯）

| 项目 | 内容 |
|:-----|:-------|
| **根因** | 我的工作流程里没有"评分前检查是否隔离上下文"这一步。每次都是用户提醒后才做 |
| **防止措施** | 在`laochen-script-scoring` SKILL里增加强制检查点：「评分前，必须用Agent工具开独立上下文，否则不准评分」 |
| **写入位置** | 本铁律 + scoring SKILL |
| **用户反馈** | "像隔离上下文已经犯了好几次" |

#### 错误3：发现错误后只是重试，没有分析根因

| 项目 | 内容 |
|:-----|:-------|
| **根因** | 我的"错误处理流程"只有"重试"，没有"根因分析→写入铁律"这一步 |
| **防止措施** | 每次用户指出错误，必须先做根因分析，写入本铁律，才能重试（见上方流程） |
| **写入位置** | 本铁律 |

#### 错误4：双盲偏差15.8分未触发分析

| 项目 | 内容 |
|:-----|:-------|
| **根因** | 汇总双盲评分时，我没有计算两个Agent的评分差值，直接取了平均分。SKILL规范明确要求"偏差>5分必须触发分析"，但我跳过了这个检查点。深层原因：工作流程里没有"计算偏差→判断>5分→触发分析"的强制步骤。 |
| **防止措施** | 修改`laochen-script-scoring` SKILL，在双盲评审流程中加入强制检查点：「计算Agent1评分-Agent2评分，如果差值>5分，必须先输出偏差分析报告（分析两个Agent判断差异的原因），然后才能输出最终得分」 |
| **写入位置** | 本铁律 + laochen-script-scoring SKILL |
| **用户反馈** | "偏差15.8为什么没触发分析" |

### 强制检查点（加入AI底层准则）

| # | 检查点 | 未通过→动作 |
|:--:|:-------|:-------------|
| 6 | **数据来源确认**：分析用的数据是最新的吗？ | 不确定→立即停止，告诉用户"找不到最新数据，请指路" |
| 7 | **隔离上下文**：评分/审核任务是否开了独立Agent？ | 没开→立即停止，开Agent后才能继续 |
