## 操作规律（从旧日志提炼）

- **口播真实感** = 消除痕迹，不是学表演。念稿感=语言与非语言不匹配
- **提词器改革**：逐字稿 → 关键词（减少视觉负担）
- **老陈专属动作**：停顿+重音+微表情+身体前倾后仰，不强求手势
- **调研分级**：浅度(web_search)→中度(+web_fetch)→深度(laochen-research)；第1次就做对，不重复劳动
- **NLP专场节拍**：钩子11个+转折7个，密度25秒/钩子；技巧节奏每个25-30秒
