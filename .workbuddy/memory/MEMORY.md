## ⚠️ 内容创作流程（强制）

**标准流程**：选题调研 → 生成文案 → **评分（Marketing Psychology同步）→ 用户确认** → 修改 → 最终输出

> ⚠️ **禁止跳过"用户确认"步骤**。评分结果出来后必须停下来等老陈确认，再决定是否修改。逐字稿和评分卡在同一文档，老陈确认后统一更新版本号。

**Marketing Psychology集成规则**：每次6维评分必须同步输出心理模型应用记录（表格形式），包含：| 模型 | 是否应用 | 应用位置 | 状态 |。评分卡改动需在改动记录中标注模型依据。

## 标准体系（2026-04-29整合）

**单套标准原则**：laochen-script SKILL.md为唯一标准，禁止两套标准并立。
如有其他标准文件（yaml/toml/文档）引入脚本规范冲突，必须先让老陈选择确认。

**标准整合结果**：
- 删除：automations/老陈抖音内容生产工作流.yaml（两套标准并存）
- 删除：automations/老陈抖音内容生产工作流.toml（同上）
- 吸收：标题策略（5原则）+ 标签策略（4类）+ 发布时机 + 评论运营 → 写入laochen-script附录
- 钩子字数上限：≤12字（老陈实测，第25期11字钩子完播12.24%）
- 语速：3.2字/秒（标准4字/秒×0.8），钩子3秒内说完
- **时长约束调整（v1.3，2026-04-29）**：目标25-30秒，底线≤60秒，流畅优先
- **评分写作规范（v1.3，2026-04-29）**：低分必须写具体原因，<70分必须给出修改指令
- **方案文件逐字稿规范（v1.3，2026-04-29）**：仅保留最终定稿版本，版本记录只记改动原因
- **v1.4教训固化（2026-04-29）**：
  - 铁律六：老陈问好不好/要不要 → 必须给两方案对比，不直接附和

  - 铁律八：心理模型应用必须逻辑通顺，Scarcity不能放在逻辑断裂位置
