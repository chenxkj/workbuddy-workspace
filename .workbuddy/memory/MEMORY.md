# 抖音运营核心规范

## 老陈专属公式
- **视频公式**：强钩子开头 + 每5秒有转折的中间 + 真话结尾
- **标题公式**：[仪式感/身份锚点] + [悬念/反差] + [真诚承诺]
- **钩子公式**：身份锚点 + 反常识事实 + 悬念
- **时长**：严格25-30秒
- **2秒跳出公式**：视频钩子 + 音乐钩子 = 降低2秒跳出率

## 核心数据基准
| 指标 | 目标 |
|------|------|
| 完播率 | ≥35%（实际冷启动8-15%） |
| 3秒完播 | ≥65% |
| 点赞率 | ≥3%（进入推荐池硬门槛） |
| 冷启动判定 | 12小时 |

## 三率权重
| 指标 | 权重 | 冷启动目标 | 进阶目标 |
|------|------|-----------|----------|
| 完播率 | 60% | ≥10% | ≥40% |
| 互动率 | 30% | ≥1.5% | ≥5% |
| 转化率 | 10% | ≥0.5% | ≥2% |

## 标题适配原则
**适合**：引发好奇/提出疑问/数字对比/身份反转/真诚表达
**禁用**：夸张型(格局炸裂)/情绪化(真的会谢)/无厘头(别点这是广告)
**禁用词**：格局炸裂/真的会谢/救命SOS/绝了/后悔没早点知道/教你三招

## 文案原则
- 不能用"真"做人设，不能说"用人设对抗算法"
- 描述事实+诚实归因，不贴标签
- ✅ "视频太长，没有节奏" / ❌ "我太端着"
- 描述文案≠口播逐字稿，制造好奇不剧透

## 账号核心原则
- 禁止讨好型AI内容，严禁无脑吹AI
- 只输出真实价值（AI能做什么/不能做什么/什么时候会骗你）

## 抖音合规红线
- 禁止具体薪资数额/数字暗示资产
- 禁止营销引流话术（带你一起做/评论区留言/收徒/有需要私信）
- 禁止任何二维码/分享码/联系方式
- 话题标签最多5个

## 拍摄风格标准
- 机位固定：正面近景，不动
- 表情克制：不夸张，不笑不哭不低头
- 背景固定：纯白墙，素材后期剪入
- 分镜只写画面说明，不写表情指令

## 封面设计规范
- 4要素：身份锚点 + 情绪关键词 + 数字悬念 + 人设感
- 封面与开场呼应：关键词重复/数字预埋/身份锚点
- 每期必须附即梦封面Prompt

## 内容输出双轨原则（2026-04-24·核心·固化）

**每个主题必须同时覆盖两个方向，同一个人讲述：**

| 方向 | 定位 | 目标感受 |
|------|------|----------|
| **A轨：底层共鸣** | 程序员的自己人 | "这个总监站我们这边的" |
| **B轨：专业管理** | 懂行的职业人 | "这个总监是真的懂管理" |

**A轨写法**：先站在程序员立场说出他们想说但没人说的话，替他们骂、替他们叹、替他们认。让他们感觉这个总监是"自己人"。
- 典型语气：共情、吐槽、自嘲
- 目标情绪：认出来 → 被理解了 → 爽
- 句式特征：先押中痛点，再揭示真相

**B轨写法**：说出管理决策背后的真实逻辑，不是鸡汤，是真实的取舍考量。让程序员看到"总监也不容易"的同时，也让同行觉得"这个判断是专业的"。
- 典型语气：判断、取舍、账本语言
- 目标感受：有道理 → 原来是这样 → 记住了
- 句式特征：事实→逻辑→结论，不说教

**两轨融合原则**：同一期视频，A轨在前（建立共鸣），B轨在后（建立权威）。不能割裂讲，要融合在同一条叙事线里。

**实操要求**：每个文案主题立项时，必须明确写出：
1. A轨：我要替程序员说哪句他们说不出来的话？
2. B轨：我要让观众看到哪层他们平时看不到的逻辑？

**注意**：单轨达标即可，不用强求双轨。第25期"屎山签字人"就是纯A轨，100分S级。
