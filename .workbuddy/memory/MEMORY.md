# 操作规范（固化）

## 方案交付自检清单
每次方案完成后，必须逐项检查13项交付物，缺一不可。

## 错误预防机制
| 错误 | 预防措施 |
|------|----------|
| 数据夸大/错误 | 方案中数据必须用户确认后再写 |
| 承诺与内容不符 | 先问：这期是"展示结果"还是"教方法"？承诺必须匹配实际交付 |
| 图片素材未读取 | 用户发截图→必须先描述内容再分析 |
| 干货内容模糊 | 承诺的具体内容必须可执行 |
| 冷启动评论过短 | 每条≥15字 |
| **擅自改用户确认内容** | 用户确认的内容原样写入，不优化、不改动、不自行升级。AI判断"更好"的地方必须先问用户 |

## 复盘数据管理
1. 发布后48小时内填入：账号数据汇总.md + 对应期次方案文件
2. 亮点/不足/策略调整必须填写，不得留空

## 规范操作
1. 写完方案 → 自检13项清单
2. 用户发截图 → 先读再分析
3. 承诺内容 → 必须匹配实际交付
4. 数据填写 → 用户确认
