## 一、剪辑操作简化清单

### 录前准备（10分钟）
1. 手机固定机位，横屏/竖屏按平台选（抖音竖屏9:16，剪映直接适配）
2. 打开剪映，导入上期录好的素材
3. 确定本期脚本已熟读（不背稿，靠理解说）

### 剪辑流程（单期≤30分钟）

```
步骤1：粗剪（10分钟）
  → 保留完整段落，不掐细节
  → 删除明显卡壳段落（停顿>3秒可删）

步骤2：节奏调整（5分钟）
  → 语速偏慢没关系，不加速（素人感=真实感）
  → 停顿处适当留白，增强重量感

步骤3：字幕（5分钟）
  → 剪映自动识别 → 人工校对关键术语
  → 重点词加字幕高亮（如"活儿"/"本事"/"看清结构"）

步骤4：封面（5分钟）
  → 直接用下方封面模板
  → 固定位置放标题文字

步骤5：BGM（2分钟）
  → 从下方推荐歌单选一首
  → 音量：背景音乐30%，人声70%

步骤6：发布
  → 标题/描述/标签直接复制文档内容
  → 检查红线（薪资/公司名/裸辞等）→ 发布
```

### ⚡ 剪辑底线（必须遵守）
- 不加转场特效（闪白/滑动等），素人加特效=翻车
- 不加花字动画，静态字幕即可
- 不变速，真实语速
- 字幕不加颜色，统一白色黑边

## 四、统一纯文字封面设计（2026-04-18更新）

> **风格原则**：四个合集统一纯文字风格，无人物形象，统一排版规则
> **更新原因**：原合集封面风格不统一（卡通/写实混用），用户反馈"轻佻"

### 通用排版规则（四个合集统一）

```
┌─────────────────────────────────┐
│                                 │
│       【大字标题·主色】          │  ← 合集主色调字体
│       【小字副标题·白色】        │  ← 本期主题
│                                 │
│  ──────────────────            │
│  【合辑标签·右下角小字】        │  ← 第X合辑 · 老陈说AI
└─────────────────────────────────┘
```

### 合集一：AI实测避坑

| 元素 | 规格 |
|------|------|
| 背景色 | 深蓝灰 `#1a1f36` |
| 大字颜色 | 白色 `#FFFFFF` |
| 副标题颜色 | 浅灰 `#CCCCCC` |
| 合辑标签 | 第1合辑 · 老陈说AI |

**即梦Prompt（直接复制）**：
```
竖版封面，深蓝灰色纯色背景，冷色调科技感。上方大字体写着"【合集主标】"，下方小字体写着"【本期副标题】"，思源黑体，白色字体。右上角有一个男士头像小圆。底部小字写着"第1合辑 · 老陈说AI"。整体风格冷静、客观、有判断力，无装饰元素，纯文字封面。
```

**各期封面Prompt示例**：
- 第1期：`上方"AI实测避坑" / 下方"用AI写简历，这3个坑别踩"`
- 第4期：`上方"AI骗了我三次" / 下方"用这招让它原形毕露"`
- 第13期：`上方"想让AI不说废话" / 下方"先对它说这句话"`
