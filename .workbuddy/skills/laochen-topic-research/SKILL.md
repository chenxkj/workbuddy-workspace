# 老陈抖音·主题调研评审 Skill

> **职责边界**：只负责"选题是否值得做"，不碰文案，不评分
> **触发词**：研究一下/调研/这个方向行不行/选题
> **对应规范**：`抖音账号运营模板包/01_模板文件/老陈视频标准化生产模板.md` PHASE A

---

## 触发条件

- 老陈说"想做一个关于XX的视频"
- 老陈发了一个选题方向
- 老陈说"研究一下XX"
- 每周选题会

---

## 执行流程

### 步骤1：调研深度判断

| 档位 | 触发条件 | 操作 | 输出 |
|------|---------|------|------|
| A档·查一下 | 快速验证方向 | WebSearch一次，5分钟 | 一句话结论+来源 |
| B档·摸清楚 | 需要做判断 | 2-3轮搜索+竞品摸底 | 竞品定位+风险点+行动建议 |
| C档·深度调研 | 选题立项 | 纵横分析法（3子Agent并行） | 万字报告 |

**本期选择**：□A档  □B档  □C档

### 步骤2：7关否决制评审

**逐项检查，全部通过才进入写稿。任意一项❌→打回或降级。**

> **规范来源**：完整7关定义见主模板 PHASE A2。本skill执行评审流程，标准以主模板为准。

#### 第1关：爆款基因评审

| 检查项 | 标准 | 结果 |
|--------|------|:----:|
| 身份标签 | 有明确的职业/年龄/学历身份群体 | □✅ □❌ |
| 情绪共鸣 | 有具体情绪场景，不是抽象概念 | □✅ □❌ |
| 分享动机 | 能回答"我想让谁看" | □✅ □❌ |
| 独特性 | 19年经历 vs 通用方法论 | □✅ □❌ |

> **注意**：选题评审通过后，需确定视频的A/B/C/D时长分类（由老陈决定或由内容类型推导），后续写稿和评分按分类执行。

#### 第2关：脚本类型适配

| 类型 | 推荐度 | 本期选择 |
|------|:------:|:-------:|
| 身份标签+真实故事（信息差型） | ⭐⭐⭐⭐⭐ | |
| 冲突型叙事（信息差型） | ⭐⭐⭐⭐⭐ | |
| 纯共情/嘴替型 | ⭐⭐⭐⭐（上限7分） | |
| 情绪干货（故事+方法） | ⭐⭐⭐ | |
| 干货教程/方法论 | ⭐⭐ | |
| 座右铭/金句感悟 | ⭐ | |
| 汇报/复盘型 | ❌（禁止） | |

**⚠️ 座右铭/感悟/汇报三类在有成功案例前禁止拍摄。**

#### 第3关：逐字稿"第二秒钩子"检查

| 检查项 | 标准 | 结果 |
|--------|------|:----:|
| 开头3秒有冲突/悬念？ | 直接切入不铺垫 | □✅ □❌ |
| 第4-8秒有新的钩子接上？ | 每8秒有转折 | □✅ □❌ |
| 每隔8-10秒有转折/新信息？ | 节奏密度 | □✅ □❌ |
| 最后10秒有"非看不可"的悬念？ | 结尾钩子 | □✅ □❌ |

#### 第4关：传播预测评估（必须填·不可跳过）

> **执行方式**：调用 `laochen-view-prediction` skill 进行预测。
> **本关只确认预测结果是否合理**，不在此处手算预测值。

**内容类型判断**（决定基准值，由 view-prediction skill 执行）：

| 内容类型 | 完播率基准 | 播放量参考 |
|---------|:---------:|----------|
| 强情绪+冲突型（25-30秒） | **10-15%** | 1万-2万 |
| 强情绪+冲突型（35-45秒） | **8-12%** | 5千-1.5万 |
| 身份标签+强钩子（>40秒） | **4-6%** | 2万-4万 |
| 感悟/金句型 | **3-7%** | 500-2000 |
| 汇报/复盘型 | **3-4%** | 300-1000 |
| 方法论/干货型 | **2-5%** | 500-2000 |

**完整预测字段**（由 view-prediction skill 输出，本关确认）：

| 维度 | 预测指标 | 预测值 | 预测依据 |
|------|---------|:------:|---------|
| 完播率 | 5秒完播 | ___% | |
| 完播率 | 整体完播 | ___% | |
| 播放量 | 冷启动修正后 | ___ | |
| 分享率 | 预测值 | ___% | |
| 涨粉 | 预测值 | ___ | |

**确认**：□ view-prediction 输出已获取且冷启动修正已执行

#### 第5关：完播钩子（核心否决项）

> **核心问题**：用户为什么要看完？看完之前他们在等什么？

| 逐字稿句子 | 留人机制 | 评价 |
|-----------|---------|:----:|
| 开头钩子：_____ | 制造悬念/接住情绪/身份锚点？ | □✅ □❌ |
| 中段钩子：_____ | 说了什么让用户停下来等答案？ | □✅ □❌ |
| 结尾钩子：_____ | 最后一句话有没有收拢全文的力量？ | □✅ □❌ |
| 整体节奏：_____ | 每8秒有新信息吗？有没有"等答案"的时刻？ | □✅ □❌ |

**逐字稿中必须找到"让用户停下来的那句话"**，找不到=完播钩子缺失。

#### 第6关：互动动机（核心否决项）

> **核心问题**：用户看完之后，会做什么？

| 问题 | 回答 | 结果 |
|------|------|:----:|
| 目标观众是谁？（具体画像） | _____ | □✅ □❌ |
| 用户看完会转发给谁？（不是泛泛的"同行"） | _____ | □✅ □❌ |
| 转发的那句话是什么？（这条视频里哪句值得被转述） | _____ | □✅ □❌ |
| 用户会在评论区说什么？（不是"来了"，是具体内容） | _____ | □✅ □❌ |

**转发句标准**：必须是逐字稿里的原话。
**评论区标准**：必须有具体场景/争辩/发现的评论区预期。

#### 第6关附：参与接口强制检查（v3.1新增）

> **来源**：第28期复盘教训——零评论、零分享、零弹幕。

**参与接口定义**：视频结尾或中段必须设计一个让用户"有话想说"的触发点。

| 接口类型 | 示例 |
|---------|------|
| **反问型** | "你有没有被老板否定过，当时怎么处理的？" |
| **争议型** | "很多人觉得压抑情绪叫成熟，我觉得叫慢性自杀，你同意吗？" |
| **行动召唤型** | "这三步记下来，下次情绪上头时直接拿出来用" |
| **求助型** | "你们遇到过这种情况吗？怎么破的？评论区教教我" |

**强制检查**：
- [ ] 逐字稿中是否有明确的参与接口？
- [ ] 接口是否出现在视频后半段？
- [ ] 接口是否与视频主题直接相关？

**⚠️ 未设计参与接口 → 互动动机关不通过，打回修改。**

#### 第7关：利他属性检查（参考，第5+6关通过后补充）

| 问题 | 回答 | 结果 |
|------|------|:----:|
| 靠什么留住用户？（共情/新知/行动） | 靠_____层 | 参考 |
| 有没有"经历者才能说"的判断？ | _____ | 参考 |

### 步骤3：选题结论

```
□ 通过（7关✅→第5+6关通过）→ 进入写稿
□ 否决（第5关❌）→ 完播钩子缺失，打回
□ 否决（第6关❌）→ 互动动机缺失，打回
□ 否决（其他关❌）→ 对应维度问题
```

---

## 输出格式

输出一份选题评估报告，包含：
1. 调研深度判断（A/B/C档）
2. 7关否决结论
3. 内容类型判断及基准值
4. 预测字段（由 view-prediction skill 输出）
5. 选题结论（通过/否决+原因）
6. **建议时长分类**（A/B/C/D）

**交付文件位置**：`抖音账号运营模板包/03_选题评估/选题-YYYYMMDD-主题关键词.md`

---

## 纪律

1. **不生成文案**：本skill只出评估报告，不写逐字稿
2. **不做播放量预测**：预测由 `laochen-view-prediction` skill 负责
3. **否决必须说明原因**：任何❌项必须给出具体原因和修改方向
