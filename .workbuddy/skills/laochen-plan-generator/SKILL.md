# 老陈抖音·方案生成 Skill

> **职责边界**：把前面所有产出组装成完整方案文件，输出标题/描述/标签/BGM等
> **触发词**：生成方案/出方案/打包
> **对应规范**：`抖音账号运营模板包/01_模板文件/老陈视频标准化生产模板.md` v4.0 PHASE B

---

## 触发条件

- 评分通过后，老陈说"生成方案"
- 评分确认后自动组装

---

## 输入

- 选题评估报告
- 逐字稿（纯净口播+情绪节奏图）
- 评分卡（含分类A/B/C/D）
- 预测数据

---

## 输出

完整方案文件，包含交付物：

1. 📋 问题诊断报告
2. 🎬 完整脚本（逐字稿+情绪节奏图）
3. 📊 流量预计 + 关键节点
4. ✍️ 发布标题（1个主标题+2-4个备选）
5. 📝 视频描述（简介提炼）
6. #️⃣ 话题标签策略
7. 🎵 BGM推荐
8. 📊 内容质量评分卡（A/B/C/D对应标准）
9. 🔄 优化前后对比
10. 🎬 画面增强·分镜说明
11. 📅 复盘模板

---

## 执行流程

### 步骤1：组装问题诊断报告

从选题评估报告中提取选题分析、核心创意机制、风险评估。

### 步骤2：置入脚本

直接置入文案生成skill输出的纯净口播逐字稿和情绪节奏图。

### 步骤3：生成标题方案 ×3-5

**标题生成规则**：
- 主标题：1个，用于发布
- 备选标题：2-4个
- 每个标题标注类型（悬念型/故事+反差型/洞察型/好奇型/系列型）

**好标题的标准**：
- 制造悬念/仪式感/期待
- 让用户问出"是什么/为什么"

### 步骤4：生成描述文案

**核心原则**：简介 ≠ 口播复述；简介 = 提炼视频里没说出口的那层洞察

**禁止**：❌照抄口播原话 ❌列3条干货要点 ❌与标题重复 ❌营销话术

**底部固定格式**：
```
只说真话

#老陈说AI #AI #职场 #研发总监 #xxx（最多5个标签）
```

### 步骤5：生成话题标签

标签数量：5-8个
- 1-2个账号标签 / 2-3个领域标签 / 1-2个热点标签 / 1个合集标签

### 步骤6：推荐BGM

根据内容情绪推荐，参考主模板"BGM推荐"章节分段模板。

### 步骤7：置入评分卡

直接置入评分skill输出的评分卡（含A/B/C/D分类标注）、MP模型记录、合规结果。

### 步骤8：生成优化前后对比

记录修改历史：v1.0 = 初稿，v2.0 = 修改版...

### 步骤9：生成复盘模板

包含预测-实际对比表（留空）、关键问题记录清单、复盘分析框架。

### 步骤10：版本记录

```
| 版本 | 日期 | 改动内容 |
|:----:|------|----------|
| v1.0 | YYYY-MM-DD | 初稿 |
```

## 文件命名规则

**格式**：`抖音账号运营模板包/04_方案案例/XXX-第X期：主题.md`

**⚠️ 不含"合集"二字。**

**示例**：
- `聊职场-第4期：大厂offer vs 小厂高薪.md`
- `情商课-第2期：程序员对情绪编程.md`
- `嵌入式-第1期：交培训费入行是最大的坑.md`

**防错**：生成前`list_dir "04_方案案例/"`确认无重名。

---

## 纪律

1. **不修改逐字稿**：方案生成只组装，不改文案
2. **不重新评分**：评分卡直接置入，不重新评
3. **标题/描述必须原创**：不能照抄口播
4. **版本记录必须完整**
5. **命名不含"合集"**：XXX-第X期：主题.md
6. **防重名**：生成前必须检查目录
