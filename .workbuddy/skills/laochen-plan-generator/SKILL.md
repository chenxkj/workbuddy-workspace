# 老陈抖音·方案生成 Skill（v5.0）

> **职责边界**：把前面所有产出组装成完整方案文件，输出标题/描述/标签/BGM等
> **触发词**：生成方案/出方案/打包
> **规范唯一性**：本skill是方案组装规范的唯一来源，主模板不再存放详细规则

---

## 触发条件

- 评分通过后，老陈说"生成方案"
- 评分确认后自动组装

---

## 输入

- 选题评估报告
- 逐字稿（纯净口播+情绪节奏图）
- 评分卡（含分类A/B/C/D）
- 预测数据

---

## 输出

完整方案文件，包含交付物：

1. 📋 问题诊断报告
2. 🎬 完整脚本（逐字稿+情绪节奏图）
3. 📊 流量预计 + 关键节点
4. ✍️ 发布标题（唯一·只输出1个）
5. 📝 视频描述（简介提炼·禁用>引用格式）
6. #️⃣ 话题标签策略（5-8个，含类别标注）
7. 🎵 BGM推荐
8. 📊 内容质量评分卡（A/B/C/D对应标准）
9. 🔄 优化前后对比
10. 🎬 画面增强·分镜说明
11. 📅 复盘模板

---

## 执行流程

### 步骤1：组装问题诊断报告

从选题评估报告中提取选题分析、核心创意机制、风险评估。

### 步骤2：置入脚本

直接置入文案生成skill输出的纯净口播逐字稿和情绪节奏图。

### 步骤3：生成标题（唯一·只输出1个）

> **规范**：用户要求只输出1个标题，不输出多条备选。
> **强制**：禁止输出"主标题+备选标题1/2/3"格式。

> **规范来源**：本skill是标题生成规范的唯一来源，主模板不再存放。

#### 3.1 标题输出标准（只输出1个）

**强制规范**：只输出1个标题，不输出多个候选，不使用"主标题""副标题""备选"等字样。

输出格式：
```
标题：（5-20字，制造悬念/身份/数字反差）
```

> 不使用【标题X】、主标题、副标题、情绪爆点、推荐理由等格式。
> 只给1个最终标题。

#### 3.2 标题定义

**标题**：5-20字，制造悬念/身份锚点/数字反差，必须有钩子让人想点。

> 不分行，不加分标题，不加分情绪爆点字段。只输出1行标题。
#### 3.3 禁用模式（踩坑转化·强制）

| 模式 | 错误示例 | 问题 |
|------|----------|------|
| 标题剧透 | "普通本科找不到好工作？主要是人的问题" | 用户看完不点 |
| 太营销 | "震惊！普通本科也能拿高薪" | 不真实 |
| 太虚 | "普通本科的出路" | 无记忆点 |
| 太长 | "普通本科找不到好工作怎么办我来告诉你几个方法" | >20字，无记忆点 |

#### 3.4 核心公式（老陈专属·5类·按优先级排序）

##### 公式1：身份 + 悬念 ⭐⭐⭐⭐⭐

```
格式：[身份标签] + [悬念/冲突]
示例：
- "三明学院出身，42岁研发总监做抖音，有人说……"
- "42岁倔人，第一次公开说这些"
- "我是老陈，288个股东等着我汇报"
```

##### 公式2：数字 + 反差 ⭐⭐⭐⭐⭐

```
格式：[具体数字] + [反差结果]
示例：
- "10天从2个粉丝到288个，我想说几句真话"
- "播放264，完播5.79%，涨粉0——我接受"
- "42岁，研发总监，288个粉丝，开始说真话"
```

##### 公式3：问题型 ⭐⭐⭐⭐

```
格式：[引发思考的问题]
示例：
- "为什么三明学院能出研发总监？"
- "AI夸你的时候，你信吗？"
- "288位股东想听什么？"
```

##### 公式4：仪式感 + 承诺 ⭐⭐⭐⭐

```
格式：[身份锚点] + [承诺/行动]
示例：
- "288位股东，我有话要说"
- "42岁倔人，第1次向288位股东汇报"
```

##### 公式5：反常识 ⭐⭐⭐⭐

```
格式：[颠覆认知的观点]
示例：
- "养AI不是为了夸自己"
- "做抖音不追热点，行吗？"
```

#### 3.7 标题生成流程（自动执行）

```
1. 输入：本期主题 + 核心痛点
2. 匹配：从75个公式中选择最适合的1-2个
3. 生成：每个公式生成1-2个候选（总共不超过3个）
4. 过滤：去掉禁用词 + AI味检测
5. 评估：按五维标准打分（见3.8）
6. 选择：选分数最高的1个作为最终标题
7. 输出：只输出1个标题（不含"备选""主标题"等字样）
```

> **强制规范**：禁止输出"主标题+备选标题1/2/3"格式。
> 用户要求只输出1个标题，skill必须遵守。

| 维度 | 问题 | 权重 |
|------|------|:----:|

#### 3.10 结尾关注理由规范（从踩坑自检清单·涨粉踩坑转化）

> **强制规范**：结尾必须有"关注理由"，软给期待，不硬求关注。

| 期数 | 问题 | 根因 | 规范 |
|------|------|------|------|
| 第7期 | 播放519，涨粉0 | 无关注理由 | 结尾明确说"我下期说XX" |
| 第18期 | 播放264，涨粉-1 | 无利他价值，无引导 | 结尾给价值承诺 |
| 第25期 | 播放9562，涨粉3 | 共情有，但无"下期预告"类关注理由 | 结尾加"下期预告" |

**涨粉三要素**（结尾必须满足至少2条）：
1. 内容打动人
2. 结尾明确说"我下期说XX"（给期待）
3. 引导关注（不用硬求，软给理由）

### 步骤4：生成描述文案

**核心原则**：简介 ≠ 口播复述；简介 = 提炼视频里没说出口的那层洞察

**禁止**：❌照抄口播原话 ❌列3条干货要点 ❌与标题重复 ❌营销话术 ❌用 `>` 引用格式

**格式规范**：
- 简介正文：纯文本，不用任何Markdown引用格式（`>`）
- 换行：直接用换行符，不用 `> ` 前缀
- 标签部分：用代码块 ``` 包裹

**底部固定格式**：
```
只说真话

#老陈说AI #AI #职场 #研发总监 #xxx（最多5个标签）
```

> **强制**：简介正文禁止用 `>` 引用格式。这是用户明确要求，skill必须遵守。

### 步骤5：生成话题标签

标签数量：5-8个
