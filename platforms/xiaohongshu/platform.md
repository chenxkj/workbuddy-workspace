# 小红书平台适配

## 适用内容

- 图文笔记
- 视频笔记
- 经验贴
- 避坑贴
- 搜索型教程

## 交付字段

| 字段 | 要求 |
|:--|:--|
| 标题 | 搜索意图 + 具体收益，避免空泛情绪标题 |
| 正文 | 开头给结论，中段给步骤/案例，结尾给评论触点 |
| 首图/封面 | 信息密度高，可截图理解核心承诺 |
| 图片结构 | 每张图承担一个信息点，不做纯装饰 |
| 话题 | 关键词优先，结合平台搜索场景 |
| 评论引导 | 引导用户补充场景、提问、要模板 |

## 指标字段

| 类型 | 字段 |
|:--|:--|
| 触达 | 阅读量/播放量、搜索曝光 |
| 互动 | 点赞、评论、收藏、转发 |
| 转化 | 涨粉、私信/咨询 |
| 长尾 | 搜索排名、持续曝光 |

## 读取规则

账号数据从当前账号项目读取。本文件只定义小红书平台字段和指标，不保存任何账号数值。
