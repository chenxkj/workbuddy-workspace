# B站平台适配

## 适用内容

- 中视频
- 长视频
- 系列教程
- 经验复盘
- 直播切片二创剪辑

## 交付字段

| 字段 | 要求 |
|:--|:--|
| 标题 | 搜索关键词 + 明确对象 + 具体收益，避免纯情绪标题 |
| 简介 | 说明视频解决什么问题，补充目录、资料、评论引导 |
| 口播稿/大纲 | 允许比抖音更完整，必须有章节结构 |
| 封面 | 信息清楚，主标题可读，人物/场景/关键词突出 |
| 分P/章节 | 长视频建议分段，便于检索和跳转 |
| 标签 | 领域标签 + 搜索词 + 系列标签 |
| 发布检查 | 标题搜索意图、封面可读性、前30秒留存、评论引导 |

## 指标字段

| 类型 | 字段 |
|:--|:--|
| 触达 | 播放量、展现/点击（如可得） |
| 留存 | 平均观看时长、完播率、前30秒留存 |
| 互动 | 点赞、投币、收藏、评论、分享、弹幕 |
| 转化 | 涨粉、私信/咨询、合集追更 |
| 长尾 | 搜索来源、收藏增长、系列播放 |

## 内容策略

| 类型 | 适合度 | 说明 |
|:--|:--:|:--|
| 面试/简历/谈薪长讲解 | 高 | 抖音短视频做钩子，B站承接完整方法 |
| 嵌入式/项目拆解 | 高 | 可建立专业信任，适合长尾 |
| 外包避坑/产品落地 | 中高 | 适合讲案例和交易边界 |
| 纯情绪短口播 | 低 | 不适合作为B站主内容，可做动态或切片 |

## 读取规则

账号数据从当前账号项目读取。本文件只定义B站平台字段和指标，不保存任何账号数值。
