# 抖音平台适配

## 适用内容

- 短视频
- 中长视频
- 口播类内容
- 系列合集

## 交付字段

| 字段 | 要求 |
|:--|:--|
| 逐字稿 | 纯中文口播，按内容类型控制字数 |
| 标题 | 强钩子或搜索关键词，避免标题党 |
| 简介 | 补充价值承诺、互动引导、必要背景 |
| 话题 | 账号标签 + 内容标签 + 平台热点，最多按当前项目规则执行 |
| 封面 | 前3秒承诺一致，不能挂羊头卖狗肉 |
| 发布检查 | 敏感词、平台风控、标题承诺、数据预测 |

## 指标字段

| 类型 | 字段 |
|:--|:--|
| 触达 | 播放量 |
| 留存 | 2秒跳出、5秒完播、整体完播 |
| 互动 | 点赞、评论、收藏、分享 |
| 转化 | 涨粉 |

## 读取规则

账号数据从当前账号项目读取。本文件只定义抖音平台字段和指标，不保存任何账号数值。
