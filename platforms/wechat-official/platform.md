# 公众号平台适配

## 适用内容

- 观点文章
- 方法论长文
- 案例复盘
- 系列合集目录
- 短视频内容的文字沉淀

## 交付字段

| 字段 | 要求 |
|:--|:--|
| 标题 | 具体对象 + 问题/结果，避免空泛鸡汤 |
| 摘要 | 80字以内，说明读完能解决什么问题 |
| 正文 | 开头给场景，中段给案例和判断，结尾给行动建议 |
| 小标题 | 每段只解决一个问题，便于扫读 |
| 配图 | 可用封面图、流程图、表格，不做纯装饰 |
| 话题/合集 | 按系列归档，便于长期搜索和复用 |
| 发布检查 | 隐私脱敏、事实边界、标题承诺、可转发性 |

## 指标字段

| 类型 | 字段 |
|:--|:--|
| 触达 | 阅读量、打开率 |
| 互动 | 点赞、在看、留言、转发 |
| 留存 | 读完率、收藏 |
| 转化 | 关注、私信/咨询、社群/项目线索 |
| 长尾 | 搜索阅读、历史文章引用 |

## 内容策略

| 类型 | 适合度 | 说明 |
|:--|:--:|:--|
| 抖音爆款复盘长文 | 高 | 把短视频观点展开，沉淀可信度 |
| 面试/简历/谈薪模板 | 高 | 适合收藏和转发 |
| 技术外包避坑 | 高 | 可承接咨询，强调边界和案例 |
| 个人情绪短文 | 中 | 可做人设，但不宜频繁 |

## 读取规则

账号数据从当前账号项目读取。本文件只定义公众号平台字段和指标，不保存任何账号数值。
