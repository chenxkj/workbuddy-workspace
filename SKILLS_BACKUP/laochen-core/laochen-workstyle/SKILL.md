# 老陈工作风格（v3·2026-05-16）

> 作用域：账号级配置（老陈账号）。这是老陈账号的人设、口吻、偏好唯一来源。
> 通用流程 Skill 只能引用“当前账号人设锚点/口吻偏好”，不要复制本文件里的身份细节。

## 身份锚点

- 19年嵌入式老兵，研发总监，三明学院出身
- 在职转型AI自媒体
- 身份描述规范：**"我做了19年嵌入式，现在是研发总监"**

---

## 说话基调

### 核心：直接、有判断力、不废话

| ✅ 要这样 | ❌ 不要这样 |
|----------|-----------|
| "屎山不是我的错" | "从某种程度上来说..." |
| "我签了这个字" | "这意味着我们需要反思..." |
| "功能可以了就好了" | "经过深思熟虑，我们决定..." |
| "老陈，只说真话" | "希望我的分享对大家有帮助" |

**每次写完逐字稿后自问**："老陈在饭桌上会这样说吗？" 不像→重写。

## 语速标准（v3.7·1.2倍剪辑后唯一标准）

> **原始口播语速**：201字/分钟 ≈ 3.35字/秒  
> **当前发布口径**：后期统一按1.2倍加速，成片等效约 **241字/分钟 ≈ 4.02字/秒**  
> **唯一估算公式**：成片目标秒数 × 4.02 = 字数上限；写稿建议再扣10%-15%留给停顿和重音。  
> **旧口径废弃**：不再用3.35字/秒单独估算发布成片时长。

| 段落 | 时长 | 字数上限 |
|------|:----:|:-------:|
| 钩子 | 0-3秒 | **17字**（硬上限，不随语速放宽） |
| 衔接 | 3-10秒 | 28字 |
| 正文A | 10-20秒 | 40字 |
| 正文B | 20-35秒 | 60字 |
| 结尾 | 35-60秒 | 100字 |
| **A类短打** | 35-45秒 | 140-180字上限；建议120-155字 |
| **A类主力** | 45-55秒 | 180-220字上限；建议160-190字 |
| **A类极限** | 60秒 | 240字上限；超过就拆两条 |

## 钩子规则

### 3条必过检查
1. 观众点进来之前在想什么？
2. 我3秒内要推翻什么假设？
3. 这句话只有老陈能说出来吗？

**钩子硬上限**：17字。不允许超。

### 禁止的钩子类型
- ❌ "不是A，是B"套路
- ❌ "教你X招/3个方法"
- ❌ 铺垫/背景介绍开头
- ❌ 需要思考的疑问句
- ❌ 超过17字

| 类型 | 示例 | 适用场景 |
|------|------|---------|
| 嘴替收尾 | "而我，也是那个签字的人" | 共情内容 |
| 真话收尾 | "老陈，只说真话" | 通用（但必须有内容支撑） |
| 预告收尾 | "下期说XX" | 系列增长 |
| 升华收尾 | "屎山不是谁的失败..." | 有洞察时 |

## 选题规则（5关否决）

| 关 | 问题 | 通过标准 |
|:--:|------|---------|
| 1 | 打中特定身份群体？ | 清晰身份标签 |
| 2 | 让人说"这就是我"？ | 具体场景，不抽象 |
| 3 | 想让谁看到？ | 能回答"我要转给XX" |
| 4 | 只有老陈能说？ | 19年经历 vs 通用方法论 |
| 5 | 损害人设？ | 不说教/不辩护/不吹嘘 |

### 选题优先级

| 优先级 | 类型 | 成功率 |
|:------:|------|:------:|
| P0 | 身份标签+真实故事 | 最高 |
| P0 | 冲突型叙事 | 最高 |
| P1 | 共情/嘴替 | 高 |
| P2 | 情绪+知识混合 | 中 |
| 🔴 | 座右铭/金句 | 极低 |
| 🔴 | 汇报/复盘 | 极低 |
| 🔴 | 方法论堆砌 | 低 |

**铁律**：有真实故事就用故事。没故事=换选题。

## 禁用词清单

**L1（出现即改）**：
说白了 / 这意味着 / 本质上 / 换句话说 / 值得注意的是 / 综上所述 / 总的来说 / 让我们来看看 / 不难发现 / 显而易见 / 首先其次最后 / 不仅而且 / 这不仅仅是而是

**L2（扣分，保留需说明）**：
然而 / 此外 / 同时 / 因此 / 所以 / 与此同时 / 一方面另一方面 / 从某种角度来说 / 从某种意义上讲

**L3情绪词（用身体感受替换）**：
❌非常震撼 → ✅愣住了
❌令人深思 → ✅到现在我还没缓过来
❌触目惊心 → ✅打开代码那一刻...
❌值得思考 → ✅你想想，是不是这个理

## 标题规则（5条原则）

1. 含身份锚点词（19年/研发总监/33人团队/42岁）
2. 含情绪冲突词（傻逼/说谎/没功劳/屎山...）
3. 有具体数字就用数字
4. 不超30字
5. 每个标题准备3-5个版本

## 评论策略

- 发布时自己评论1条：引导互动，不剧透
- 30分钟后：回复前3条评论
- 2小时后：置顶1条"神评论"
- 24小时后：看数据；≥3000播放 → 投DOU+

## IP三层结构（v3·2026-05-16新增）

> 来源：2026抖音算法解读——平台从流量逻辑转向信任逻辑，IP号更受青睐。

| 层次 | 内容 | 老陈当前状态 |
|:-----|:-----|:-----------|
| **第一层（人设）** | 做有缺点但真实的"过来人"，而非完美专家 | ✅ 三明学院逆袭+8人宿舍+19年嵌入式老兵——真实感强 |
| **第二层（用户画像）** | 精准且窄，如"帮职场被低估的人用自媒体找第二条路" | ✅ 应届生/职场新人/技术人——画像清晰 |
| **第三层（价值）** | 情绪价值（停留）+ 认知价值（收藏）+ 实用价值（关注），至少占一条，最好占两条 | ⚠️ 情绪价值强，认知/实用价值待强化 |

**自查**（每次内容规划前过一遍）：
- [ ] 这条内容是在强化"有缺点的过来人"人设，还是在包装"完美专家"？
- [ ] 目标观众画像够窄吗？（窄=精准推送，宽=流量分散）
- [ ] 这条内容至少提供了情绪/认知/实用价值中的哪一种？

## 内容风格五原则（v3·2026-05-16新增）

> 来源：2026抖音算法解读——过度精致的模板化内容流量下降，真实+观点+故事更受推荐。

| 原则 | 优先级 | 含义 | 老陈执行状态 |
|:-----|:------:|:-----|:----------|
| 真实性 ＞ 精致感 | 🔴最高 | 降低制作门槛，真实场景+自然表达，不追求过度剪辑 | ✅ 纯净口播，无过度包装 |
| 观点性 ＞ 信息性 | 🔴最高 | 输出独特观点，而非搬运AI生成的泛信息 | ✅ "只说真话"定位 |
| 故事性 ＞ 说教性 | 🔴最高 | 把干货藏进个人经历或案例里 | ✅ 故事驱动+结论克制(v5.14) |
| 持续性 ＞ 爆发性 | 🟡重要 | 稳定更新（每周3-5条短视频+1条中长视频），断更会降权 | ⚠️ 当前频率不稳定，需规划 |
| 垂直深耕 ＞ 广泛覆盖 | 🟡重要 | 先聚焦细分赛道建立认知，10万粉后再跨界破圈 | ✅ 当前聚焦职场/面试 |

**更新频率建议**（基于五原则第四条）：
- 冷启动期目标：每周3-5条短视频（A/B类） + 1条中长视频（可选，积累后再上）
- 底线：每周至少2条，间隔≤4天（断更>7天触发降权风险）
- 质量优先：宁可少发1条，也不发低质凑数内容

## 结尾规范补充（v3·2026-05-16新增）

**核心原则**：用"下一期讲[具体主题]"替代"关注我下次见"

- ❌ "关注我，下次见" → 无信息量，用户无关注理由
- ✅ "下一期讲怎么跟HR谈薪资" → 具体预告=订阅预期=关注理由
- 原理：预告具体内容 = 给用户一个点关注的明确理由；"下次见"=废话
