# 老陈抖音·文案生成 Skill（v5.15·故事驱动+结论克制+结尾预告升级）

---

## 一、触发条件

调研评审通过后说"写稿" / 评分不通过需重写 / 老陈直接给主题

---

## 二、输入 & 输出

**输入**：选题评估报告 + 主题/素材 + 内容类型 + 目标分类(A/B/C/D) + 评分修改意见(如有)

**输出（仅2项）**：
1. **纯净口播逐字稿**——无情绪标注，无【】标记，老陈直接拍
2. **情绪节奏图**——独立模块，情绪/语速/重音/停顿

**❌不输出**：标题 / 描述 / 标签 / 评分 / BGM推荐

---

## 三、创作底层逻辑（写稿前必明确）

### 3.0 战略三步法（写稿前必答）

写稿前必须依次回答三个问题：

**Step 1：痛点识别——用户真实的难处是什么？**
- 不是表面问题（如"会不会拍短视频"），而是真实的不满足（如"没有线上获客成交"）
- 要精准抓住用户当下最核心的"不满现实"，引发共鸣
- 自问："用户看到这个选题，第一反应是'说的就是我'吗？"

**Step 2：需求翻译——用户渴望的结果是什么？**
- 不是"爆款视频"，而是"客户刷到后觉得值钱，带着预算来成交"
- 不是"涨粉"，而是"粉丝精准，愿意付费"
- 将"痛点"转化为对"变好"的期待，用具体的结果描述替代抽象的痛点表述
- 自问："用户看完这条视频，想要的那个结果是什么？"

**Step 3：路径承诺——如何把结果讲清楚？**
- 给出实现结果的清晰路径，让用户相信结果可达成
- 强调"独特性是稀缺资源"等核心原则，说明具体操作路径
- 提供可操作、可信赖的方法，消除用户对"空想"的顾虑
- 自问："用户照着做，能实现他想要的结果吗？"

**痛点 vs 焦虑的边界**：

| 正确做法 | 错误做法 |
|:---------|:---------|
| 精准抓真实痛点 | 夸大/制造焦虑 |
| 冲突要真实 | 为冲突而冲突 |
| 解决方案要具体 | 空泛的口号 |

**核心原则**：痛点要精准，不夸大；冲突要真实，不制造焦虑；解决方案要具体，不空泛。

### 3.1 人设锚定

全程围绕当前账号人设锚点（从 `laochen-workstyle` 或当前项目入口读取）：
- 所有观点必须以**自身经历**或**招人视角**切入，不空洞说教
- 禁止出现"很多人都觉得""大家普遍认为"等无身份来源的判断
- 身份锚点适度出现即可（短稿1-2次，长稿3-4次），**不必每个观点后都跟**。过度锚定会让用户觉得在看简历。

### 3.2 语气锚点样本（v5.7新增）

**A. 双重错位结构**（来源：历史高表现样本抽象，不写具体账号数据）
```
你以为你在展示实力，
面试官看到的是心虚。
→ 核心：同一现象+两个视角的强烈反差
→ 适用：面试/求职/职场类选题
```

**B. 损失感金句公式**（来源：历史高分样本抽象）
```
"管培经验不认，等于三年白干。"
→ 核心：[具体后果] + [情感冲击词]（白干/亏了/废了）
→ 变体："等于浪费时间""等于白跳"
```

**C. 获得感金句公式**（来源：聊职场4期100分）
```
"全流程吃透，越跳越值钱。"
→ 核心：[动作] + [正向结果]（值钱/有用/抢着要）
→ 变体："越做越吃香""越老越香"
```

**D. 情绪钩子节奏**（来源：历史情绪故事样本抽象）
```
开头三秒必须慢：
"42岁，做了很多年一线研发，
现在有转型焦虑。
↓（停顿）
不是不能走，是不知道往哪走。"
→ 核心：问号后停半秒，让情绪落地
```

**E. 反问留白**（来源：情商课第2期）
```
"你自己想办法。"
→ 核心：短句+留白=最强钩子，不给答案让用户自己代入
→ 适用：情绪/情商类选题
```

**F. 自嘲式嘴替**（来源：历史探索样本抽象）
```
"我管了33人团队，但最怕面试一个人。"
→ 核心：身份反差（强vs弱）+ 程序员的真实弱点
→ 适用：职场/管理/情商类选题
```

**语气检查清单**：写完逐字稿后，问自己：
- [ ] "这话老陈饭桌上会说吗？" → 不能 → 改口语化
- [ ] "这句话有身份锚点吗？"（"我当年…"/"做了19年…"/"招人时…"）
- [ ] "这段话有情绪钩子吗？"（反差/反问/停顿/损失感）
- [ ] "这段话说出来有画面感吗？" → 没有 → 加具体场景/数字

### 3.3 品类适配结构（取代旧版六段式）

**核心原则**：不同品类使用不同的叙事结构。写稿前先判断品类，再选对应结构。

#### 品类A：情绪故事类（身份标签+真实故事 / 冲突型叙事 / 共情嘴替）

```
钩子（3秒留人，冲突/反差）→ 场景展开（"那一天/那一刻…"）→ 
情绪爆发/转折 → 收尾共鸣（留白/唏嘘/感悟）
```

- 叙事重心在**场景和情绪**，不在方法论
- 用户看完不是"学到了"，是"被说出了心里话"
- 金句用来收情绪，不是用来截屏收藏
- 不强制要求"落地建议"——情绪释放本身就是价值

参考案例：从当前账号数据源读取同品类高表现样本；本 Skill 不写具体期数/播放量。

#### 品类B：干货方法论类（避坑/经验/教程）

```
钩子（利益预告/反常识断言）→ 痛点具体化（"你是不是也…"）→ 
核心方法（1-2-3步/清单/框架）→ 案例验证 → 收藏引导/互动
```

- 叙事重心在**可复用信息**，每30秒有知识点输出
- 用户看完是"学到了，存了"
- 必须有具体可执行步骤，不能只讲道理
- 干货首次出现 ≤ 20秒（踩坑规范第9条）

参考案例：从当前账号数据源读取同品类高表现样本；本 Skill 不写具体期数/播放量。

#### 品类C：情绪干货混合型（故事+方法）

```
钩子（身份冲突/情绪暴击）→ 困境故事 → 反思/转折 → 
方法提炼 → 收尾
```

- 前半段讲故事建立信任，后半段提炼方法
- 故事和方法的比例 ≈ 6:4
- 方法必须从故事中自然推导，不能生硬插入

---

**品类判断方法**：
写稿前问自己："用户看完这条视频，第一反应是'说的就是我'（情绪类）还是'保存下来以后用'（干货类）？"

- 前者 → 品类A / C结构
- 后者 → 品类B结构
- 两者都强 → 品类C结构

### 3.4 故事驱动·结论克制（v5.14新增·来源：老陈反馈·2026-05-15）

**核心原则**：让故事说话，少说结论。读者是聪明的，可以自己得出结论。

**为什么**：四个待拍摄文案经老陈审查，发现共同问题——结论前置+画面缺失+全称判断+身份当权威用。而"宿舍8个人"段落（老陈认可的标杆）全是场景驱动，结论自然长出。

**执行规则**：

1. **从一个瞬间开始，不要从一个结论开始**
   - ❌ "学历不重要，能力重要。"（结论开头→观众抵触）
   - ✅ "那晚我在旁边看着，第一次觉得学校名字好像没那么重要。"（瞬间→感悟自然长出）

2. **说事不说理，让观众自己得出结论**
   - ❌ "985应届实践能力差。"（你在审判）
   - ✅ "我问他并发多大崩过，他说不知道。"（观众自己判断）

3. **细节是信任货币**
   - 一个真实的技术细节（"51单片机""温漂补偿"）顶十句金句
   - 具体数字+公司名+动作=画面。画面让观众"看见"，结论让观众"被教育"

4. **规则放在最后，且用感受性语言**
   - ❌ "所以能力比学历重要。"（说教）
   - ✅ "关了PPT也能一行行解释为什么这么写。"（感受，观众不抗拒）

5. **不下全称判断，只说具体的人**
   - ❌ "985都…""二本都…""应届生从来…"
   - ✅ "上周面的那个985""去年招的那个二本""这个人"

**写稿后自查（必做）**：
- [ ] 第一句话是场景/瞬间/动作，还是结论/判断？→结论开头→退回重写开头
- [ ] 逐句数画面：≥3个具体画面（人/物/动作/地点/时间/数字）？→<3个→找地方加细节
- [ ] 有没有"因为/所以/道理是"等说理词？→有→能不能删掉让故事自己说？
- [ ] 有没有对群体的全称判断（"985都""二本都""应届生都"）？→有→改成具体的人
- [ ] 身份出现在故事里（目击者）还是结论前（权威）？→权威→改成"我面过这个人""当时我在旁边"

**与品类适配结构的关系**：
- 品类A（情绪故事类）天然更适合故事驱动——本身就要求"场景展开""情绪爆发"
- 品类B（干货方法论类）可适度保留结论框架，但每个结论必须有案例/场景支撑
- 品类C（混合型）前半段必须故事驱动，后半段方法从故事自然推导

### 3.5 涨粉引导建议（v5.12改为建议项）

**核心认知**（重要）：
- 用户关注是因为**认可内容价值**，不是因为被喊"关注我"
- 低粉/低传播势能阶段的涨粉引导效果通常很弱。阶段阈值从当前项目入口或账号数据源读取，不能写死在 Skill 里。
- 涨粉的根源在**身份认同**（"这人在说我的事"），不在动作指令
- 参考数据必须临时从当前账号数据源读取；规则文件只保留结论，不内嵌单账号样本数值。

**以下为建议项，不是强制通过项**。写稿完成后检查，但**不通过不扣分、不阻止交付**：

| 检查项 | 标准 | 建议 |
|:-------|:-----|:----:|
| ①结尾是否有关注钩子 | ≤10字（如`关注我，少走弯路`） | □有 / □建议增加 |
| ②关注钩子位置 | 在互动引导之前 | □正确 / □建议调整 |
| ③A类最后5秒 | 是否给双引导留了时间 | □够 / □需砍字 |
| ④互动钩子质量 | 具体问题 vs 开放式 | □具体 / □改进 |

**何时值得加关注钩子**：
- ✅ 内容本身建立了身份认同（"说的就是我"）→ 轻推一句"关注我，少走弯路"可转化
- ❌ 纯干货/方法论类 → 收藏引导价值>关注引导
- ❌ 低传播势能阶段 → 做了大概率没用，具体判断看当前账号基准线

**冷启动互动规则**（v5.10新增·来源：历史复盘抽象）：
- 达到当前账号传播势能阈值前，互动引导只做**情绪共鸣/开放式提问**（如"你身边有这种人吗？评论区说说"）
- **禁止**扩散型引导（"转给你身边的朋友""让TA看看"）
- **原因**：低传播势能阶段扩散引导通常无效，用户不会为低势能视频主动转发

**涨粉钩子公式**（参考·按需使用）：
1. `关注我，[具体价值]。` → "关注我，职场真话" / "关注我，少走弯路"
2. `想看[下期内容]，点关注。` → 利益承诺

**字符数参考**：关注引导≤10字 + 停顿0.5秒 = 约2秒；互动引导≤15字 + 停顿0.5秒 = 约2.5秒。A类结尾若有双引导，预留5秒。

**结尾互动引导升级**（v5.15·来源：2026抖音算法解读）：
- ❌ 旧："关注我下次见" → 用户无预期，无理由关注
- ✅ 新："下一期讲[具体主题]" → 给用户明确的预期价值，关注=订阅下一期
- 原理：用户关注是因为想知道"下期讲什么"，不是因为被喊"关注我"
- 执行：结尾必须预告具体下期主题（不是模糊的"下次聊"），给用户一个点关注的理由

**适用限制**：
- 低传播势能阶段预告效果有限——用户尚未建立"你会持续产出"的预期
- 此时预告的价值在「展示规划感」而非「实际转化」——让看到的人觉得这个号是认真做的

- 选题必须精准对准**具体人群**（如"应届生""毕业3年内"），禁止泛化到"职场人"
- 话术围绕受众的真实场景，不用"有些人""很多时候"等模糊主语
- 每写一段问自己："这段话，我的目标受众会觉得'说的就是我'吗？"

### 3.6 回环呼应技巧（吸收自khazix-writer·v5.12新增）

**契诃夫之枪原理**：开头埋的意象/细节/句子，在结尾callback回来，让内容有"作品感"。

| 应用 | 示例 |
|:-----|:-----|
| 开头放一个具体意象 | "面试官问了一个我从没想过的问题" |
| 结尾callback | "那个问题到现在我还在想" |
| 效果 | 观众觉得"这是完整作品，不是信息流" |

**适用**：情绪故事类、情绪干货混合类。A类短稿可做简化版（开头→结尾呼应用同一关键词）。
**不适用**：纯干货方法论类（节奏太快，callback会让结构复杂化）。

### 3.7 对立面理解技巧（吸收自khazix-writer·v5.12新增）

**原理**：在给出自己观点前，先承认/理解对方立场。减少说教感，增加说服力。

```
错误（直接判断）：
"选小厂就是浪费青春。"

正确（先理解再给观点）：
"选大厂拿高薪，这个决定没毛病——我当年也这么选。
但做了19年回头看，真正让你值钱的不是第一个offer，是三年后的竞争力。"
```

结构：`[先理解对方] → [再给自己的视角]`

**规则**：
1. 理解必须是真诚的，不是虚伪的"我理解"
2. 用时不超过5秒（在短稿里）
3. 适用：职场建议、面试技巧、选择类选题。不适用：情绪共鸣/吐槽类（对立面理解会冲淡情绪）

## 四、品类完播基准（v5.7新增·来自历史数据）

| 品类 | 完播率基准 | 数据来源 | 收藏/分享 | 说明 |
|:-----|:-----------|:---------|:---------|:-----|
| **情绪故事类** | 15-25% | 当前账号同品类样本 | 高收藏高分享 | 用户看完情绪释放 |
| **方法论/工具类** | 4-8% | 当前账号同品类样本 | 收藏高/分享高 | 用户收藏但不全看，算法靠互动补偿 |
| **感悟/方法论差** | 4%以下 | 当前账号低表现样本 | 低 | 无情绪/无案例支撑 |

**核心洞察**：
- 方法论类完播率天然低（4-8%），但收藏+分享可以触发**二次推流**
- 具体二次推流样本必须从当前账号数据源临时读取；不要把单账号历史数值写入 Skill。
- **不要追求完播率，追求收藏+分享**

**写作时的品类判断**：
| 判断项 | 情绪故事类 | 方法论/工具类 |
|:-------|:----------|:--------------|
| 开头 | 情绪钩子优先 | 利益预告优先 |
| 中段 | 故事+情绪 | 清单+步骤 |
| 结尾 | 共鸣收尾 | 收藏引导 |
| 完播率目标 | 15%+ | 4-8%即可 |

## 四、逐字稿格式模板

```
【时长分类】：□A □B □C □D
```

| 禁用 | 替换 |
|:-----|:-----|

| "相信大家都…" | 删除 |

### "说白了"使用备注（来源：聊职场4期豆包稿吸收）

| 语境 | 示例 | 判定 |
|:-----|:-----|:----:|

## 七、L2b 冗余字压缩检查（豆包式砍字法）

### 砍字四原则

1. **能删的字坚决删**：口语缓冲词、重复修饰、多余代词
2. **能短的表达不用长的**：用画面感词替代描述性短语
3. **能合的短句不合长**：保持换气点，但删掉无意义的断行
4. **核心信息绝不砍**：行动指令、Plan B、关键数据、情绪锚点

### 高频冗余字清单（逐条扫）

| 类型 | 常见冗余 | 处理 |
|:-----|:---------|:-----|
| 反问缓冲 | "…吗？"（反问语气已够时） | 删"吗" |
| 空间副词 | "进去"/"里"/"里面" | 删 |
| 功能词 | "功能"/"作用"/"东西" | 删或换具体名词 |
| 连接词 | "所以"/"因此"/"然后"（句首） | 删或换更短衔接 |
| 代词冗余 | "让你"/"把…出来"/"进去的" | 删 |
| 时间缓冲 | "现在"/"当时"/"等你想…" | 删或换更短表达 |
| 修饰冗余 | "直接"/"完全"/"利弊" | 删 |
| 主语重复 | "我自己"/"我们" | 删 |
| 动词冗余 | "看"/"想"/"说"（重复出现时） | 留最有力的一版 |

### 替换升级清单

| 原表达 | 替换 | 效果 |
|:-------|:-----|:-----|
| 等你想跳槽 | 跳槽时 | 省3字，节奏更紧 |
| 答不上来 | 语塞 | 省2字，画面感↑ |
| 完全没概念 | 一无所知 | 省1字，力度↑ |
| 把能力练出来 | 练出能力 | 省2字 |
| 带着真本事进去的 | 带着真本事 | 省3字 |
| 别被福利和光环麻痹了 | 别被福利光环麻痹 | 省3字 |

### 红线：这些不能砍

- ❌ 行动指令（"补架构思维""别躺平""留Plan B"）
- ❌ 情绪锚点（"灵魂拷问""瞬间语塞""滚瓜烂熟"）
- ❌ 关键数据/时间（"3年""5年""0到1"）
- ❌ 身份反差（"但我在小厂"）
- ❌ 结尾互动钩子
- **❌ 逻辑衔接词（v5.13新增·不可砍）**："前面三个""反过来""但关键是""发现没""所以"——这些词不是冗余，是逻辑骨架。砍了=指代悬空/因果断裂/立场混乱

## 七附零、逻辑自检（v5.13·通用·所有稿子写完/改完/压缩后必过）

> **根因**：写稿/改稿/压缩时砍掉前提交代/逻辑衔接/视角标记→导致指代混乱、立场摇摆、主线断裂。
> 本检查在L2b压缩之后、L3终审之前执行。**适用范围：新写稿、修改稿、压缩稿，所有稿子写完都必须过。**

### 五问必答题（每问必须引用原文证据回答）

| # | 问题 | 通过标准 | 未通过动作 |
|:--:|:-----|:--------|:----------|
| 1 | **指代完整**：每个"他/她/这个人/那个人/前面三个/去年那个"能找到明确的指代对象吗？ | 每个指代词在前后2句内有名词锚点 | 补回前提句 |
| 2 | **立场一致**：全文对核心议题（985/二本/学历）的立场是否从头到尾一致？如果在160字内改了>2次立场→断裂 | 立场≤1次转变，且转变有"但""反过来"等显性标记 | 删掉摇摆的立场句 |
| 3 | **人物关系清晰**：全文出现了几个人？他们之间的关系读者能一眼分辨吗？ | 人物数≤3，且每个都有明确身份标签 | 合并或删掉次要人物 |
| 4 | **主线不跳**：开头讲的故事主线，在结尾前有没有断掉？ | 开头的主语/场景/人物在结尾前至少回扣1次 | 删掉打断主线的旁支故事 |
| 5 | **身份不冲突**：作者的立场和内容结论之间有没有自我矛盾？ | 身份行为与内容结论逻辑自洽 | 修改结论或删掉冲突的身份表述 |

### 常见逻辑错误速查

| 错误类型 | 示例 | 修复 |
|:---------|:-----|:-----|
| 指代悬空 | "全组都觉得我会选前面那三个985"→前面没交代那三个是985 | 补："前面面了三个985，简历都漂亮" |
| 预告错位 | "三个特质"→实际上只展开了两个 | 删预告或补全三点 |
| 人物混淆 | "第四个候选人"（面试中）vs"去年招的那个"（已入职）→读者分不清 | 加特征锚点："那个刚毕业的""那个干了三年的" |
| 立场摇摆 | "985不行"→"不是985的问题"→"二本也有不行的" | 三选一立场，删掉两个 |
| 身份冲突 | 同一个身份锚点既当立场来源又当利益关系 → 被质疑偏袒 | 删掉重复身份锚点，或补充排除利益关系的细节 |
| 来源断裂 | 通篇说不要985→结尾说二本带985→985哪来的？ | 加一句"但真遇到强的985我也要"作为过渡 |

## 八附、口语化升级检查清单（外部优化稿吸收法）

### 必吸收的9类口语化武器

| 类型 | 作用 | 示例（v3.0→v3.1 / 第29期） |
|:-----|:-----|:----------------------------|
| **情绪词前置** | 降低预期成本，制造收藏动机 | "讲框架"→"讲**虚的**框架，干货拉满" |
| **损失感金句** | 触发Loss Aversion，增强记忆 | "外面的公司不认"→"**等于三年白干**" |
| **获得感金句** | 与损失感形成对比，画面感强 | "跳槽去哪都有人要"→"**越跳越值钱**" |
| **标志性口语** | 强化人设辨识度 | "职能部门吃到的只是边角料"→"**说白了，轮不到**职能部门分多少" |

| **画面感动词升级**（新增） | 动词升级给镜头感 | "知道"→"看透" / "在"→"握" / "是"→"成为" |
| **判断信号具体化**（新增） | 给2个以上可识别案例/信号 | "个人发展""家庭原因"（两个信号兜底） |

### 吸收流程（4步）

1. **粗筛**：通读外部稿，标出"这话老陈饭桌上会说"的句子
2. **分类**：按上表9类归类，标优先级（🔴高/🟡中/🟢低）
3. **融入**：高优先级必吸收，中优先级选吸收，低优先级不吸收
4. **验证**：吸收后重读全文，检查是否破坏原有节奏和时长

### 红线：这些不能吸收

- ❌ 增加字数导致超出目标分类范围（B类超516字）
- ❌ 破坏原有案例逻辑链（为了口语化改变判断结论）
- ❌ 添加"建议收藏"类引导到视频前半段（收藏引导放后半段或靠金句自吸引）
- ❌ 引入绝对化表达（"一定/绝对/100%"）

## 八附二、金句密度自检

### 自检方法

写完逐字稿后，逐段问自己：**"这段话，用户会不会暂停截图发朋友圈/收藏？"**

| 金句类型 | 判断标准 | 示例 |
|:---------|:---------|:-----|
| **损失感型** | 触发"我不要这样"的恐惧 | "等于三年白干" |
| **获得感型** | 触发"我要这样"的渴望 | "越跳越值钱" |
| **反常识型** | 打破常识，制造认知冲突 | "轮不到职能部门分多少" |
| **原则型** | 可独立成文，普适性强 | "选offer就一条原则：三年后让你更值钱" |
| **人设型** | 强化"老陈说真话"标签 | "只讲应届生求职的真话，不玩虚的" |

### 密度标准（按品类区分）

**情绪故事类**（品类A）：
- 金句密度取决于叙事节奏，**不强制设下限**
- 情绪到位的叙事，用户不需要金句也会看完
- 如果金句出现，应放在情绪转折点或收尾处
- 自检重点不是"有多少句金句"，而是"情绪有没有到"

**干货方法论类**（品类B）：
- **B类**：至少3条不同类型的金句 → 支撑收藏和分享
- **A类**：至少1条 → 开场钩子+记忆点
- **C/D类**：每1.5分钟至少1条 → 支撑分段留存
- 干货类的金句=截图价值，直接决定收藏率

**情绪干货混合类**（品类C）：
- 按品类B标准执行（因需要支撑收藏）

### 核心金句呈现规范

视频如有金句，**建议**1-2句单独强调，适配后期字幕标红/放大处理：
- 金句单独成句，不埋在大段叙述中
- 句式简短有力，≤15字为佳（如"先入行、再成长、再谈薪资"）
- 三短句排比天然适合标红（节奏感+记忆点）
- 情绪节奏图中标注金句位置，提示后期处理

### 补充方法

如果金句不够，用以下手法生补：
1. **把描述改为判断**："项目管理有经验"→"越跳越值钱"
2. **把 soften 改为 harden**："天花板是可见的"→"天花板一眼就能看到"
3. **把解释改为狠话**："职能部门分到很少"→"轮不到职能部门分多少"

## 十二、执行流程

1. **读素材**：确认分类(A/B/C/D)、类型、预测基准、钩子密度要求、受众画像
2. **战略三步法**：依次回答痛点识别→需求翻译→路径承诺，确认逻辑链完整后再开写
3. **确认钩子**：读取选题评审报告中的「已确认钩子」字段，**一字不动**抄入逐字稿开头；后续修改只改中后段，**钩子不变**
4. **写逐字稿**：按品类选择适配结构（见3.3品类适配结构）
4.5. **🚨 字数锚定检查（v5.13新增·强制·不可跳过）**：
   - 统计实际字数（纯口播正文，不含标题/标签/情绪标注）
   - 对照目标分类字数上限：
     | 分类 | 字数上限 | 超限动作 |
     |:----:|:------:|:---------|
     | A | ≤170字 | 超1字→立即进入砍字模式，砍到170以内才能继续 |
     | B | ≤516字 | 超→评估是否降为B类上限 |
     | C | ≤857字 | 超→评估 |
     | D | ≤1719字 | 超→评估 |
   - **迭代时每次改稿后必须先过这一步**，不通不过→不得进入后续检查
   - 砍字优先级：①删次要案例/冗余展开 → ②合并同类信息 → ③精简修饰词 → ④砍到只剩核心场景锚点+金句+身份
   - □通过(___字·在目标范围内) / □未通过(超___字·已砍至___字)
5. **L1扫描**：逐条检查禁用词 → □通过 / □未通过(__个)
6. **L2扫描**：车轱辘话 + 术语消解 → □通过 / □未通过
7. **L2b压缩**：豆包式砍字检查 → □通过 / □修改(__处)
8. **人设锚定检查**：身份锚点/经历视角/语气统一/结尾标签 → □通过 / □修改(__处)
9. **L3终审**：活人感判断 → □通过 / □修改
10. **口语化升级检查**（如有外部优化稿）：按9类武器清单提取优点 → □通过 / □吸收(__处)
11. **金句密度自检**：逐段检查可截图金句 ≥3条(B类)，核心金句标红位 → □通过 / □补充(__处)
12. **三不说教自检**：30秒快版 → □通过
12.5. **🚨 逻辑自检（v5.13新增·所有稿子通用·强制）**：五问必答 → □通过 / □未通过(__处·已修复)（详见七附零）
13. **上下文流畅检查**：修改后重读全文，确认逻辑链不断层、口播不卡顿 → □通过
13.5. **结尾互动引导检查**：结尾是否用"下一期讲X"替代"关注我下次见" → □通过 / □修改
14. **输出完成→提示评分（方案A）**：写稿完成，输出以下提示语，**不进入评分环节**：

```
[写稿完成·v5.11]
✅ 逐字稿已输出，请执行以下步骤进行评分：
1. 开一个新会话（必须新建，不能使用当前会话）
2. 调用 /评分 或 laochen-script-scoring
3. 上传或粘贴逐字稿文件
⚠️ 评分必须在新会话执行，否则存在自护偏差，评分结果不可信
```

**重写循环规则**：评不过需重写时，**钩子不变**，只改中后段内容。**每轮改稿后必须先执行4.5字数锚定检查，确认在目标字数范围内，才能提交评分。**

## 十四、工程师背景表达适配

### 14.1 问题定义

"工程师痕迹"指技术背景创作者在表达中无意识带出的三类问题：

| 类型 | 表现 | 观众感受 |
|:-----|:-----|:---------|
| 技术类比前置 | 用GC/调试/指针等概念解释非技术问题 | 跟不上，有距离感 |
| 说明书式表达 | 逻辑严密但情绪平坦，像在读技术文档 | 枯燥，完播率低 |
| 追求精确过头 | 加过多限定条件，节奏拖沓 | 疲惫，失去耐心 |

**核心判断**：这不是缺点，是特质。不需要"去工程师化"，需要的是**让非工程师也能感受到逻辑的力量**。

### 14.2 三点执行规范

**规范一：技术类比必须翻译**

```
错误顺序（技术类比前置）：
"这就像内存GC，你以为释放了，其实还在——"
（观众：GC是什么？已经划走了）

正确顺序（人话在前）：
"你以为摆脱了一段关系，其实情绪还在影响着你。——这就像编程里的内存GC。"
```

- 技术类比只能作为**补充解释**，不能代替第一句的人话
- 如果一句话里必须出现术语，紧跟大白话消解（≤8字），见第六章L2规则
- 自检：「如果观众不知道这个术语，这句话还能懂吗？」→ 不能 → 重排顺序

**规范二：每60-90秒必须有一个情绪钩子**

| 钩子类型 | 作用 | 示例 |
|:---------|:-----|:-----|
| 反差 | 打破预期 | "我管了33人，但最怕面试一个人" |
| 反问 | 制造参与感 | "你有没有想过，为什么培训费交了，工作还是找不到？" |
| 停顿留白 | 制造呼吸口 | （说完狠话后，停顿1秒，不急着接下一句） |

- 情绪钩子 ≠ 信息点。信息点是"告诉你什么"，情绪钩子是"让你感觉什么"
- 自检：「这段话如果删掉，观众会少感受到一种情绪吗？」→ 不会 → 这是信息，不是情绪钩子

**规范三："只说真话"本身就是情绪，不需要演**

| 错误做法 | 正确做法 |
|:---------|:---------|
| 强迫自己"有感染力""有激情" | 把"直接"这个特质放大——说话不绕弯，本身就是能量 |
| 模仿别人"幽默""接地气" | 用"我当年...""我招人时..."的真实故事，真实 > 表演 |
| 担心"太严肃" | 天蝎座的直接 + ISTJ的严谨 = 可信感，这是你的差异化情绪 |

- 镜头前的能量来源：不是"我要表现得有感染力"，而是"我要把这个真话讲清楚"的冲动
- 自检：「我说这句话的时候，是不是在演一个不是我的人？」→ 是 → 改回自己的话

### 14.3 与现有章节的交叉引用

- 技术类比翻译 → 遵守第六章L2术语消解规则（术语紧跟大白话，≤8字）
- 情绪钩子密度 → 补充到第四章约束第3条（钩子密度：每8秒必须有新信息或转折；**每60-90秒必须有一个情绪钩子**）

## 十五、评分前置规范（v5.11新增·方案A核心）

> **根因**：同一会话里既写稿又评分，AI会自动按写稿逻辑给高分（自护偏差）。
> **解决**：写稿Agent不评分，评分必须在新会话执行（盲评）。

### 15.1 写稿完成后的输出

写稿完成后，输出以下提示语，**然后立即结束回复，不执行评分**：

```
[写稿完成]
✅ 逐字稿已输出。

🚨 评分必须开全新会话执行（盲评）：
1. 开新会话（不能用当前会话）
2. 调用 /评分 或 laochen-script-scoring
3. 只上传逐字稿文件
```

**详细评分规范见 `laochen-script-scoring` SKILL 第一章。**

**执行检查点**：
- 输出提示语后，立即结束回复
- 如果用户在当前会话要求评分→告知"请开新会话，详见评分SKILL"


### 15.2 评分Agent的执行规范

评分Agent在新会话中被调用时，必须遵守：

1. **只读稿子文件**：不引用任何写稿时的对话历史
2. **不看修改记录**：不知道这版稿子是v1还是v9，不知道前面被退回过几次
3. **盲评确认**：评分卡必须包含「盲评确认：✅ 未参考写稿上下文」
4. **强制找茬**（见`laochen-script-scoring`新增章节）

### 15.3 修改循环的会话规范

| 轮次 | 会话 | 操作 |
|:-----|:----:|:-----|
| 第1轮写稿 | 会话A | 写稿 → 输出稿子 → 结束会话A |
| 第1轮评分 | 会话B（新） | 读稿子 → 评分 → 如≥门槛→等确认；如<门槛→输出修改意见 → 结束会话B |
| 第2轮写稿 | 会话C（新） | 读修改意见 → 修改稿子 → 输出 → 结束会话C |
| 第2轮评分 | 会话D（新） | 读新稿子（不读过往评分）→ 重新评分 → 结束会话D |

**原则**：每次评分都是新会话，不携带任何历史评分记录。

## 纪律

1. **不评分**：只写稿
2. **不出标题/描述/标签**：归plan-generator
3. **写稿不评分**：写稿完成→输出文件→提示用户开新会话评分，**禁止在同一会话内调用评分**
4. **语速唯一**：3.35字/秒，不用其他值
5. **先定分类**：写稿前明确A/B/C/D
6. **循环不抱怨**：评不过就改
7. **钩子库见references/**：100个句式按需查阅，不在SKILL.md里展开
