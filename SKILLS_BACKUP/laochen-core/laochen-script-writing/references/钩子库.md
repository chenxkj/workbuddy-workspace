## 七、钩子位置规范（5个时段）

| 时段 | 钩子密度要求 | 说明 |
|:-----|:----------|:-----|
| **前3秒** | 必选1个最强钩子 | 冲突/反常识/悬念三选一，直接切入 |
| **4-8秒** | 接住前3秒钩子 | 给新信息/具体场景，不让钩子悬空 |
| **每8-10秒** | 1个转折/新信息 | 防止审美疲劳，保持"等答案"状态 |
| **中段** | 悬念不消失 | 每个段落结尾留一个"然后呢？" |
| **结尾** | 收拢全片 | 最后一句必须有"哦——"的顿悟感 |

## 八、钩子密度自检

- [ ] 前3秒有钩子？___（引用逐字稿原句）
- [ ] 每8秒有新信息/转折？（数一下：30秒内有≥3个）
- [ ] 结尾有"非看不可"的悬念？（最后一句话标注）
- [ ] 总钩子数：___个 / 总时长：___秒 → 密度达标？（≥10个/30秒）

## 十、使用指南

1. **写稿时**：先定内容类型→选对应钩子类别→套用句式→替换具体内容
2. **前3秒**：只放最强钩子，不铺垫，不自我介绍
3. **避免堆砌**：同一段落不用2个以上同类型钩子
4. **检验**：朗读钩子句，问"这句话在饭桌上会说吗？"→否，改口语
