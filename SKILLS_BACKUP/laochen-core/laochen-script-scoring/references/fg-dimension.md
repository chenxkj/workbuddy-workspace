# FG维度（v5.13改为纯建议项·不参与总分）

> **核心认知**（与writing skill 3.4保持统一）：
> 用户关注是因为认可内容价值，不是因为被喊"关注我"。
> 低粉/低传播势能阶段涨粉引导效果通常很弱。阶段阈值必须从当前项目入口或账号数据源读取，不写死在评分规则里。
> FG维度仅作为参考信号，不参与总分计算。

## FG维度定义

**FG — Follower Growth Potential（涨粉引导）**

| 状态 | 标准 | 建议 |
|:-----|:-----|:-----|
| ✅ **有关注钩子** | 结尾有关注引导（≤10字），位置在互动引导之前 | 情绪故事类且建立了身份认同→可加分 |
| ⚠️ **建议加关注** | 无关注钩子，但内容建立了身份认同 | 可轻推一句（如"关注我，少走弯路"） |
| ❌ **不适用** | 纯干货/方法论类，或冷启动期 | 收藏引导价值>关注引导，不加 |

## 执行规则

1. **评分顺序**：先评6维 → 再检FG → 输出建议
2. **FG不参与总分**：最终得分 = 6维总分 / 100 × 100（FG纯参考）
3. **品类判断优先级**：
   - 情绪故事类 + 身份认同建立 → 建议加关注钩子
   - 干货方法论类 → 收藏引导优先，关注钩子非必要
   - 低传播势能阶段 → 不做涨粉引导建议，具体阈值看当前账号基准线
4. **如果决定加**：关注钩子≤10字，在互动引导之前，A类预留最后5秒

## FG与互动引导的关系

| 顺序 | 判断 | 说明 |
|:-----|:----:|:-----|
| 关注钩子 → 互动引导 | ✅ 正确 | 先让用户"想关注"，再引导评论 |
| 互动引导 → 关注钩子 | ⚠️ 无影响 | 用户关注与否取决于整体内容价值，不取决于顺序 |

## 评分报告必须包含

```
涨粉引导（FG）检查：
  - 品类判断：情绪故事 / 干货方法论
  - 是否建议加关注钩子：是 / 否（理由：___）
  - FG建议内容：{有就写，没有就写"本次不适用"}
  - 最终得分：___/100（仅6维，FG不参与）
```

## 使用方式

FG是纯建议项，不参与总分。
评分完成后，按上述规则给出FG建议，写在评分卡最后。
