# 踩坑红线（全类通用·评分核验）

评分时必须逐项检查以下10条红线。触犯即标注，按对应规则处理。

| # | 红线 | 触发场景 | 评分处理 |
|:-:|:-----|:---------|:---------|
| 1 | 封面点击率0% → 播放封顶 | 任何类 | 预警标注，不扣分 |
| 2 | 开头钩子失败 → 算法停推 | 任何类 | 开场维度≤10 |
| 3 | 方法论/感悟类 → 完播天生低(4-8%)，非内容错误 | A/C类 | 完播率预期按品类基准执行，不扣分不封顶 |
| 4 | 好封面掩盖执行问题 | 任何类 | 必须独立查5秒完播 |
| 5 | 5秒完播<35% → 停推 | 任何类 | 发布后4h内必查 |
| 6 | 方法论长视频前30秒全铺垫 | C/D类 | 触发选题否决 |
| 7 | **B类干货（可操作内容/具体利益）首次出现 > 20秒** → 中段崩盘风险高；例外：「观点+故事+建议」结构，前15秒已抛明确观点，故事支撑观点（非无效铺垫）→ 不触发 | B类 | 触犯→「15秒留存钩」强制扣5分 |
| 8 | **分享引导出现在干货前** → 推销感=加速流失 | 任何类 | 「分享+扩散」强制扣3分 |
| 9 | **A类中段内容密度断层**：5秒完播≥55%但整体完播<10%的潜在风险——评分时检查每15-20秒是否有信息增量/情绪转折点。连续20秒无新信息或转折点 → 触犯中段密度断层 | A类 | 「结构张力」额外扣5分，并标注"中段密度断层，退回修改" |
| 10 | **数据陈述式开头=无钩子**：前3秒为"数据陈述"（如"我拍了XX条视频""我做了XX次尝试"）或"通用开场"（如"说句实在话""今天不玩虚的"），对陌生用户=无任何钩子效应。**此红线独立于开场钩子维度评分**，触犯时即使开场钩子维度评分已≥15分，仍触发此红线警示 | 任何类 | 开场钩子维度**强制下调至≤15分**，并标注"数据陈述式开头→对陌生用户无钩子" |
| 11 | **全称判断红线（v5.19新增）**：逐字稿中出现对群体的全称判断（如"985应届都…""二本生都…""应届生从来…""所有人都…"）。**替代方案**：用具体的人（"上周面的那个985""去年招的那个二本"）或限定范围（"我面过的985里""我接触过的"）。触犯→观众第一反应是"我不是这样"，评论区必然失控 | 任何类 | ①情绪共鸣维度强制-5分 ②在评分卡中标注"全称判断→评论区风险" ③必须在找茬清单中给出具体修改建议（指明哪句、怎么改） |

**使用方式**：
评分时逐项检查，触犯的红线在评分卡中标注，并按规定扣分/警示。
