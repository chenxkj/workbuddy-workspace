# 历史数据锚点

本文件不保存任何账号实绩数据。

## Source

评分或校准需要历史样本时，必须读取当前账号项目声明的数据源：

1. 作品维度数据：当前项目入口声明的 `作品列表.xlsx`
2. 账号时间点数据：当前项目入口声明的 `关键数据时间点.md` 或等价文件
3. 复盘结论：当前项目的已发布方案文件和 `rubric_notes.md`

## Rules

- 不在 Skill 或 reference 文件中硬编码粉丝数、播放量、完播率、收藏、分享、涨粉等账号数据。
- 不把某个账号的样本复制成通用规则。
- 只把跨样本稳定成立的判断沉淀为规则；沉淀前必须能追溯到当前账号的数据文件。
- 对多账号项目分别读取各自数据源，不跨账号混用校准样本。

## Usage

评分时如需历史锚点，先读取当前账号数据，再在评分报告中注明数据来源和采集时间。数据不足时必须标注低置信度。
