# 校准工具（比率桶 + Rubric升级规范）

## 比率桶方案（吸收自cheat-on-content·v5.13新增·辅助校准）

> **核心价值**：绝对分数（6维100分）在冷启动期不具备横向可比性——80分的A类不代表一定能爆。
> 比率桶用"相对上一条的倍数"来校准预期，更适合账号早期。

### 比率桶定义

让 `baseline = 上一条的实际播放数`。

| Bucket | 倍数范围 | 含义 |
|--------|---------|------|
| 退步 | < 0.3 × baseline | 比上条明显差 |
| 持平 | 0.3 - 1 × baseline | 与上条同档 |
| 命中 | 1 - 3 × baseline | 中度突破 |
| 小爆 | 3 - 10 × baseline | 显著破圈 |
| 大爆 | > 10 × baseline | 量级跃迁 |

### 使用方式

1. 评分完成后，查看上一条已发布视频的实际播放量
2. 用比率桶判断本条预期位置
3. 记录在评分卡的"辅助判断"字段

```
辅助判断：
- 上条实际播：___
- 本条比率桶预期：持平 / 命中 / 小爆
- 依据：___
```

### Confidence等级（校准样本数决定可信度）

| 校准样本 | Confidence |
|:--------:|:-----------|
| N=0-2 | 🔴 极低，啥都别信 |
| N=3-5 | 🟠 低，信方向不信数字 |
| N=5-10 | 🟡 偏低，信bucket排序 |
| N=10-20 | 🟢 中，中枢可信±30% |
| N≥20 | 🔵 高，rubric真正成为参考 |

## Rubric 升级规范（v5.13移至此）

**升级门槛**：
1. ≥2条有实绩数据的历史样本支撑
2. 新标准重判近5条历史样本
3. 新排序与实际表现排序≥4/5吻合 → 通过；否则拒绝

**变更记录格式**：
```
变更：[维度] [改动内容]
来源：[期数复盘数据]
验证：[X/Y样本吻合] → [通过/拒绝]
```

## 使用方式

比率桶和Rubric升级都是辅助校准工具，非评分必检项。
当账号有≥3条历史数据后，评分时可使用比率桶辅助判断预期。
当评分偏差持续>5分时，触发Rubric升级流程。
