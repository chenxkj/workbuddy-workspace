# TS/MS 落地执行（v5.8新增·必检项）

## TS — 议题分享冲动（Topic Shareability）量化判定（v5.15新增）

> **抖音分享机制说明**：抖音的"分享"主要是私信发给具体的人，不是发朋友圈。
> 社交成本远低于"公开转发"。TS=1（转发=暴露处境）只适用于真正敏感的内容。
> 普通职场建议、求职建议，转发给朋友=帮他，社交成本低，TS应评3-4。

**量化判定标准**：

| 分 | 场景 | 判定问题（评分时必须回答） | 老陈案例 |
|:--:|:-----|:---------------------|:---------|
| 1 | 转发=暴露处境（真正敏感） | "转发这条会让自己尴尬/暴露隐私吗？" → 是 | 被裁经历/薪资对比/吐槽现公司 |
| 3 | 转发中性（私信给朋友，低风险） | "转发这条是帮朋友，还是暴露自己？" → 帮朋友 | 普通职场建议/求职建议（转发=帮他） |
| 5 | 转发=表演（转发=表达立场/炫耀见识） | "转发这条能让自己看起来更XX吗？" → 能 | 程序员集体吐槽/in-group黑话 |

**落地执行**：评分时回答上述"判定问题"，按回答结果给TS分，写在评分卡【TS预估】字段

## MS — 模因可挪用性（Memetic Shareability）量化判定（v5.15新增）

| 分 | 场景 | 判定问题（评分时必须回答） | 老陈案例 |
|:--:|:-----|:---------------------|:---------|
| 1 | 原样引用 | "这句话观众能换个主语直接用吗？" → 不能 | "三年后年薪差距15万" |
| 3 | 部分可套用 | "这句话观众能换个主语/场景用吗？" → 能，但需要改几个字 | "相当于三年白干"（可换主语） |
| 5 | 主动造句变体 | "这句话观众能直接当模因造句吗？" → 能，句式固定 | "XX不一样"模因 |

**落地执行**：评分时回答上述"判定问题"，按回答结果给MS分，写在评分卡【MS预估】字段
**MS高→评论区互动预期上调**：MS=5的内容，评论区预期有"XX不一样"类造句

## TS/MS组合规律（评分辅助判断）

| 组合 | 分享数 | 评论数 | 老陈系列 |
|:----:|:------:|:------:|:---------|
| TS低+MS高 | 低 | 高 | 情商课系列 |
| TS高+MS低 | 高 | 静 | 普通职场建议 |
| 两者都高 | 高 | 高 | 爆款条件之一 |

**评分报告必须包含**：
```
TS预估：[1/3/5] · 依据：___
MS预估：[1/3/5] · 依据：___
组合预期：分享___ / 评论___
```

## 使用方式

评分前必读此文件，理解TS/MS判定标准。
评分时必须回答判定问题，不能凭感觉给分。
