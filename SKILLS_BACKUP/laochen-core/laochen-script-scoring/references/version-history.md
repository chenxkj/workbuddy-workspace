# 版本修改记录

## v5.15（2026-05-12）

**触发**：同一文案盲评最大偏差17分（方案3：D1=75 vs D2=92）

| # | 修改位置 | 改动内容 | 根因 |
|:--:|:---------|:--------|:-----|
| 1 | 二、分类决策 | 增加「字数统计规范」：统一统计工具、统计对象、边界争议处理 | 字数统计不一致→分类争议→评分偏差 |
| 2 | 一.1 盲评执行规范 | 增加「输出格式强制要求」：必须声明字数/分类依据/引用原文/陌生用户测试结果；禁止推测性语言 | Agent输出格式不统一→判断依据不可比对 |
| 3 | 一.3 评分卡新增字段 | 增加【字数统计】【分类依据】【TS预估】【MS预估】字段 | 盲评规范强化 |
| 4 | 八、A类评分卡·6维度 | 全部增加「量化锚点」：每个维度分4档（满分/良好/及格/不及格），每档有具体判断标准和引用要求 | 主观维度判定差异大→同一文案偏差17分 |
| 5 | 九、B类评分卡·6维度 | 全部增加「量化锚点」（同A类） | 同上 |
| 6 | 十五、TS落地执行 | 增加「量化判定标准」：每个TS分(1/3/5)有对应判定问题，评分时必须回答 | TS判定无量化标准→Agent随意给分 |
| 7 | 十五、MS落地执行 | 增加「量化判定标准」：每个MS分(1/3/5)有对应判定问题，评分时必须回答 | MS判定无量化标准→Agent随意给分 |

**未改动**：FG维度、比率桶方案、Rubric升级规范（保持v5.14不变）
**v5.15验证结果**：量化锚点有效，偏差从17分→9分，但结构张力维度仍有3分偏差（Agent对"说教感"豁免理解不一致）
**待验证**：v5.16豁免边界明确后，5文件盲测最大偏差能否≤5分
