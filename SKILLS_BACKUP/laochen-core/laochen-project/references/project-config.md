# 账号运营项目配置边界

本文件只定义“去哪里读”，不保存任何账号数据。后续运营多个账号时，每个账号项目必须有自己的数据源和状态索引。

## Source Boundaries

| 类型 | 放在哪里 | 说明 |
|:-----|:---------|:-----|
| 通用规则/流程 | `SKILLS_BACKUP/laochen-core/*/SKILL.md` 或已安装技能副本 | 可跨账号复用，不写粉丝数、播放量、账号昵称等数据 |
| 当前账号数据 | 当前工作区 `AGENTS.md` 指定的数据源 | 每个账号项目单独维护 |
| 作品维度数据 | 当前账号项目声明的 `作品列表.xlsx` | 用于复盘、预测校准、播放/完播/互动分析 |
| 账号时间点数据 | 当前账号项目的 `00_数据存档/关键数据时间点.md` 或等价文件 | 账号基础、粉丝画像、诊断、周期数据按时间追加 |
| 项目状态索引 | 当前工作区 `.workbuddy/memory/MEMORY.md` 或等价文件 | 只做索引和当前任务状态，不作为数值真值来源 |
| 评分/校准状态 | 当前工作区 `.cheat-state.json`、`rubric_notes.md`、`script_patterns.md` | 属于该账号项目，不得写入通用规则 |

## Required Checks

1. 涉及数据分析时，先读取当前项目入口，确认作品数据和账号时间点数据路径。
2. 如果账号数据超过项目声明阈值，提醒导出最新数据。
3. 如果规则文件里出现具体账号数值、旧路径、旧自动化 ID，视为污染，应迁移到账号数据文件或项目状态索引。
4. 复制本技能到其他账号项目时，只复用规则和流程；不要复制当前账号的数据文件内容。

## Current Workspace Convention

老陈项目当前约定由工作区 `AGENTS.md` 声明。其他账号项目必须在自己的入口文件声明等价信息，不得修改本技能来适配某个账号。
