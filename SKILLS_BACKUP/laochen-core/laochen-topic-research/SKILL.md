# 老陈抖音·主题调研评审 Skill（v5.6·受众宽度降为FG建议+踩坑更新）

> **职责边界**：只负责"选题是否值得做"。不碰文案，不评分，不预测播放量
> **触发词**：研究一下/调研/选题/这个方向行不行

---

## 一、触发条件

老陈说"想做个XX视频" / 发来选题方向 / "研究一下XX" / 每周选题会

---

## 二、执行流程

### 步骤1：调研深度

| 档位 | 触发条件 | 操作 | 输出 |
|:-----|:---------|:-----|:-----|
| A·查一下 | 快速验证 | WebSearch×1，5min | 一句话结论+来源 |
| B·摸清楚 | 需要做判断 | 搜索2-3轮+竞品摸底 | 定位+风险+建议 |
| C·深度调研 | 选题立项 | 纵横分析法(3子Agent) | 万字报告 |

本期选择：□A □B □C

### 步骤2：钩子方案生成（选题评审的核心输出）

> 钩子必须在选题阶段生成并确认，写稿阶段直接取用、不改动。
> 每个选题生成3-5个钩子选项，老陈确认1个后固化。

#### 钩子模板（6类）

**A类·冲突型**（最强，推荐开场）
- 公式：`"你以为X，实际上Y"`
- 公式：`"X年了，还在做X？"`
- 公式：`"明知山有虎，偏向虎山行——然后……"`
- 要求：前3秒必须出现冲突词（但/其实/实际上/没想到）

**B类·反常识型**
- 公式：`"所有人都说X，但Y才是真相"`
- 公式：`"越是被夸X，越要警惕"`
- 公式：`"这件事，99%的人都搞反了"`
- 要求：必须有具体数字或具体场景

**C类·损失感型**
- 公式：`"管培经验不认，等于X"`
- 公式：`"花了X万买来的教训，免费给你"`
- 要求：数字+具体后果，让人感到"不要这样"

**D类·获得感型**
- 公式：`"全流程吃透，越X越Y"`
- 公式：`"有了X，你就能Y"`
- 要求：正向结果，画面感

**E类·情绪暴击型**
- 公式：`"42岁，19年研发，现在……"`
- 公式：`"亲手签了那张裁员单，才知道……"`
- 要求：具体场景+情绪名词，不用抒情铺垫

**F类·自嘲型**
- 公式：`"我管了33人团队，但最怕……"`
- 要求：身份反差（强身份+弱时刻），真实弱点

#### 生成要求

1. 对应选题方向，生成3-5个钩子选项（覆盖不同类型）
2. 每个钩子标注类型、核心机制、适用理由
3. 老陈确认1个后，该钩子**一字不动**进入写稿环节
4. 选题通过7关否决制后，输出「已确认钩子」字段

```
【已确认钩子】
类型：___ / 钩子句：___ / 来源：老陈确认
```

### 步骤3：六关否决制（逐项，全通过→写稿）+ FG受众宽度预警

> 注：受众宽度为FG建议项，不阻断流程但须老陈确认知晓。

#### FG·受众宽度（建议项，非否决，天花板预警）

> **核心问题**：这个话题能触达多少人？专业术语/小众场景/垂直行业话题天然天花板低。
>
> 数据依据：电赛视频5s完播45.76%（优秀）但播放仅4,207——内容质量高但受众太窄，天花板锁死。
>
> **注意**：有时做垂度是战略选择（如建立专业人设/测试品类边界）。此检查仅作预警，老陈决定是否继续。

| 检查项 | 说明 | 结果 |
|:-------|:-----|:-----|
| 跨行业共鸣？ | "offer选择/简历写法/面试应对"可跨行业，"画圆模块/电赛"只针对参赛者 | □✅ □⚠️窄 |
| 非专业术语？ | 标题和开头3秒无垂直行业术语（如具体技术栈/行业黑话直接说） | □✅ □⚠️窄 |
| 情绪可迁移？ | 即使讲专业场景，情绪有普遍性（加班的苦/选错的悔/迷茫的痛） | □✅ □⚠️窄 |
| 无需前置知识？ | 普通观众无需了解行业背景就能理解并共鸣 | □✅ □⚠️窄 |

> ⚠️ 任一⚠️ → **FG建议**：此选题受众窄，天花板预计≤5万播放。老陈确认继续→可进入第1关；老陈决定放弃→返回修改方向。

#### 第1关：爆款基因

□ 身份标签明确(职业/年龄/学历群体) · □ 有具体情绪场景(非抽象) · □ 有分享动机("让谁看") · □ 独特性(19年经历 vs 通用方法论)

#### 第2关：脚本类型

| 类型 | 推荐 | 本期 |
|:-----|:----:|:----:|
| 身份标签+真实故事 | ⭐⭐⭐⭐⭐ | |
| 冲突型叙事 | ⭐⭐⭐⭐⭐ | |
| 共情/嘴替型 | ⭐⭐⭐⭐(上限7分) | |
| 情绪干货(故事+方法) | ⭐⭐⭐ | |
| 干货教程/方法论 | ⭐⭐ | |
| 座右铭/金句感悟 | ⭐ | |
| 汇报/复盘型 | ❌禁止 | |

> ⚠️ 座右铭/感悟/汇报三类在有成功案例前禁止拍摄。

#### 第3关：钩子密度 + 干货前置

**钩子引用检查**：
- [ ] 选题阶段「已确认钩子」已生成并记录于报告
- [ ] 开头3秒使用已确认钩子，不替换不修改

**中段钩子密度**：
- [ ] 每8-10秒有转折/新信息？
- [ ] 结尾有"非看不可"的悬念？

**干货前置校验**（来源：历史复盘抽象·品类自适应）：

| 品类 | 标准 | 结果 |
|:-----|:----|:----:|
| 干货方法论类 | 第一个实质性观点 ≤ **15秒** | □✅ □❌ |
| 情绪干货混合类 | 第一个实质性观点 ≤ **20秒** | □✅ □❌ |
| 情绪故事类 | 不强制干货前置（叙事重心在情绪） | □ |

> "实质性内容"=非背景交代、非自我介绍，而是核心信息（观点/数字/反常识/冲突峰值）
>
> 干货类 >20秒 → 打回修改，不得进入第4关。

**搜索意图判断**（v5.4·来源：2026抖音算法解读）：

写稿前检查——这个选题的标题/文案是否埋入了用户会搜索的关键词？

| 意图类型 | 信号 | 标题策略 | 本选题 |
|:---------|:-----|:---------|:------:|
| 信息型 | "怎么""如何""是什么" | 标题直接回答问题 | □ |
| 决策型 | "选哪个""值不值" | 标题给明确判断 | □ |
| 情绪型 | "太难了""想哭" | 标题说共鸣情绪 | □ |

> 注意：搜索流量是辅助策略。当前账号所处阶段必须从项目入口声明的数据源/状态索引读取，不能在本 Skill 硬编码粉丝数。低粉阶段通常优先用「身份标签+情绪共鸣」拉信任；B类干货类内容优先布局搜索关键词，A类情绪故事类不强制。

#### 第4关：传播预测（调用view-prediction skill）

> **本关不手算预测值**。调用 `laochen-view-prediction` 获取完整预测字段后，确认结果是否合理。

确认：□ view-prediction输出已获取且冷启动修正已执行

#### 第5关：完播钩子（核心否决）

> 核心问题：用户为什么要看完？看完前在等什么？

必须从逐字稿中找到"让用户停下来的那句话"，找不到=缺失。

| 钩子位置 | 留人机制 | 通过? |
|:---------|:--------|:----:|
| 开头 | 制造悬念/接住情绪/身份锚点 | □ |
| 中段 | 说了什么让用户等答案？ | □ |
| 结尾 | 最后一句有收拢全文的力量？ | □ |
| 整体 | 每8秒有新信息？"等答案"时刻？ | □ |

#### 第6关：互动动机（核心否决）

> 核心问题：用户看完后会做什么？

| 问题 | 必须具体回答 |
|:-----|:-----------|
| 目标观众是谁？ | （具体画像，不是泛泛的"打工人") |
| 转发给谁？ | （不是泛泛的"同行"） |
| 哪句话值得被转述？ | （必须是逐字稿原话） |
| 评论区会说什么？ | （具体场景/争辩/发现） |

##### 参与接口强制检查（来源：历史低互动复盘教训）

视频后半段必须有1个参与触点（与主题直接相关）：

| 类型 | 效果 |
|:-----|:-----|
| 反问型："你有没有被老板否定过？" | 触发倾诉 |
| 争议型："很多人觉得压抑叫成熟，我觉得叫自杀" | 触发站队 |
| 行动召唤："这三步记下来" | 触发收藏+反馈 |
| 求助型："你们遇到过吗？教教我" | 触发分享 |

- [ ] 有明确的参与接口？
- [ ] 出现在视频后半段？
- [ ] 与主题直接相关（非硬塞）？

→ 未设计 → 互动关不通过，打回。

#### 第7关：利他属性 + 自嗨检查（参考项，5+6关通过后补充）

| 检查项 | 问题 | 结果 |
|:-----|:-----|:----:|
| 利他属性 | 靠什么留住用户？（共情/新知/行动） | ___ |
| 经历者判断 | 有"经历者才能说"的判断？ | ___ |
| **自嗨检查** | **"这是我（老陈）想说的真话，还是观众需要听到的真话？"** | □✅ □❌ |

> **自嗨检查说明**（来源：2026-05-05 老陈直接指出）：
> - ✅ "观众需要听到的真话"= 对准观众的真实焦虑，他们看完觉得"说的就是我"
> - ❌ "我想说的真话"= 自我表达驱动，离观众焦虑有距离，即使说的是事实也没人听
> - 典型自嗨信号：选题来自于"我觉得这个问题值得讲"，而不是"观众在问/在焦虑什么"
> - 自检方法：问"如果这条视频只有50播放，我发不发？"→ 仍然发 = 可能是自嗨；不发 = 说明你在意观众要不要看

### 步骤3：选题结论

```
□ 通过（7关✅ + 第5+6关✅）→ 进入写稿
□ 否决（第5关❌）→ 完播钩子缺失
□ 否决（第6关❌）→ 互动动机缺失
□ 否决（其他关❌）→ 对应维度问题
```

## 三、输出格式

1. 调研深度(A/B/C)
2. **钩子选项（3-5个）**：类型/句式/核心机制/适用理由
3. **已确认钩子**（老陈选定后固化）：类型 / 句式（一字不动）
4. 七关否决结论（逐关标注）
5. 内容类型 + 建议分类(A/B/C/D)
6. 预测数据（来自view-prediction skill）
7. 结论（通过/否决+原因）

**交付文件**：`抖音账号运营模板包/03_选题评估/选题-YYYYMMDD-主题关键词.md`

## 四、选题踩坑规范

| # | 规范 | 来源 |
|:-:|:-----|:-----|
| 1 | **选题不能受众太窄**：垂直行业话题即使5s完播高，也容易卡在小圈层。专业术语/小众场景/无情绪迁移性的话题 = 天然天花板 | 历史复盘教训 |
| 2 | **选题不能泛化**："如何做好职场沟通"太泛 → 改成"面试时被问到缺点怎么说" | 泛化=完播死 |
| 2 | **方法论长视频慎选**：纯方法论/感悟类C/D类视频完播天生低(4-8%)，除非有强故事包裹 | 历史复盘教训 |
| 3 | **预测偏差校正**：历史预测值经常偏高，实际常低于悲观值(×0.7)。方法论类执行风险尤高 | 历史复盘教训 |
| 4 | **干货类选题标题必须埋搜索关键词**：B类/C类内容（避坑/教程）的标题需包含用户会搜的词（如"面试怎么说""某领域怎么入门"），A类情绪内容不强制 | 2026抖音算法解读视频 |

## 纪律

1. **不写文案**：只出评估报告
2. **不预测播放量**：归view-prediction skill
3. **否决必说原因**：任何❌给具体原因和修改方向
