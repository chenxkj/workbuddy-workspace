## 三层分工架构

> **模板文件 ≠ Skill ≠ MEMORY**，三层各司其职，不重复。

| 层级 | 维护文件 | 内容 | 原则 |
|------|---------|------|------|
| **规范层** | 01_模板文件/ | 评分卡/否决制/预测机制/踩坑 | 唯一标准来源 |
| **执行层** | Skill（laochen-script-writing/laochen-script-scoring） | 铁律/禁用词/人设/选题 | AI执行时自动加载 |
| **记忆层** | MEMORY.md + MemPalace | 账号状态/拍摄进度/全局铁律 | 跨会话持久化 |

**铁律三层架构**：

| 层级 | 归属 | 规则 |
|------|------|------|
| A层·写稿执行纪律 | laochen-script-writing | 铁律一/二/三/五 |
| B层·评分行为纪律 | laochen-script-scoring | 铁律四/七/八 + 流程A/B |
| D层·全局行为纪律 | MEMORY.md | 铁律六/九 |
| C层·内容质量红线 | 模板文件 | 操作铁律7条 + 三不说教 + 踩坑 |

## 创作流程（标准链路）

```
选题/素材
    ↓
PHASE A：选题评估（laochen-topic-research）
    A1→调研深度判断 / A2→7关否决制 / A3→结论
    ↓ 通过
PHASE B：写稿评分（laochen-script-writing）
    B1→写逐字稿 / B2-L1扫描 / B3-L2节奏 / B4-L3活人感
    ↓ 通过
评分（laochen-script-scoring）
    6维评分卡 + 心理模型记录 → 评分后停等老陈确认
    ↓ 确认
去AI味（humanizer-zh）→ 查违禁词（douyin-sensitive-check）
    ↓ 通过
发布 → 数据复盘（laochen-data-review，写入方案文件）
```

## 必读文件

每次做方案前，确认以下文件存在：

1. `01_模板文件/老陈视频标准化生产模板.md`（核心模板）
2. `02_执行指南/踩坑自检清单.md`（发布前必查）
3. `02_执行指南/合规红线清单.md`（抖音平台合规规则）
4. `02_执行指南/违规词库.md`（平台违规词库）
