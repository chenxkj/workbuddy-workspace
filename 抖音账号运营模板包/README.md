## 🚀 快速开始（新账号）

### 1. 导入模板
把 `01_模板文件/` 下的文件导入到新的 brain/ 目录

### 2. 配置自动化
把 `03_自动化配置/` 下的 .yaml 文件导入 Clawflows

### 3. 按指南执行
按 `02_执行指南/` 里的清单操作

## ⚠️ 必读：合规红线

| 禁止内容 | 示例 |
|---------|------|
| 具体薪资数额 | ❌ "年薪50万" / "月薪2万" |
| 明确公司/品牌名 | ❌ "华为"/"阿里" |
| 裸辞劝导 | ❌ "直接辞职" / "裸辞是对的" |
| 医疗/法律建议 | 需加"仅供参考" |
| 虚假信息 | 夸大经历、捏造数据 |

## 📝 使用说明

### 方案模板结构
每期方案包含11项交付物：
1. 问题诊断报告
2. 完整脚本（逐字稿）
3. 分镜脚本
4. 流量预计 + 操作说明
5. 标题方案 ×5
6. 话题标签策略
7. 描述文案（发布版）
8. 评论区运营策略
9. 内容质量评分卡
10. 优化前后对比
11. 复盘模板

### 封面制作流程
1. 从方案中复制"即梦Prompt"
2. 粘贴到即梦生成
3. 下载后用剪映微调

### 口播录制流程
1. 从方案中复制"口播文本（提词器版）"
2. 粘贴到提词器App
3. 对着念，真实表达

## 🔧 适配新账号

新建账号时，需要修改模板中的：
- 账号定位/人设（当前是老陈版本）
- 合辑名称和数量
- 封面配色和风格
- BGM歌单

其余流程可直接复用。
