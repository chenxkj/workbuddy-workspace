# 数据存档规范（v1.0·2026-05-18）

## 核心原则

**每次收到的数据都必须存档，带时间戳，不覆盖历史版本。**
**账号级数据存入"关键数据时间点.md"，按时间节点追加。**
**MEMORY.md只存索引引用，不参与趋势分析。**

---

## 数据时间戳体系

| 时间点 | 含义 | 用途 |
|--------|------|------|
| **视频发布时间** | 作品在抖音上发布的时间 | 计算数据"年龄" |
| **数据获取时间** | 从后台导出/截图的时间 | 判断数据新鲜度 |
| **发布后时长** | 数据获取时间 - 发布时间 | 跨视频横向对比基准 |

### 为什么必须记录时间

同一个视频，发布后8小时和发布后48小时，数据差异可能超过10倍：
- 深夜返程：8小时3,477 → 最终97,699（差了28倍）
- 如果只看最终数字不知道"增长曲线"，反之只知早期数字不知道"天花板"

---

## 隐藏视频说明

xlsx里审核状态=**自见**的视频：播放量显示0，但完播率/5s完播率等互动指标**仍然有效**（后台仍在统计）。

| 视频 | 发布时间 | 状态 |
|------|----------|------|
| 偷得浮生半日闲 | 2026-04-19 | 自见（隐藏） |
| 天塌了 | 2026-04-16 | 自见（隐藏） |
| 养虾第1期 | 2026-04-15 | 自见（隐藏） |

## 存档文件命名

格式：`作品列表_YYYY-MM-DD_HHmm.xlsx`

示例：
- `作品列表_2026-05-18_1111.xlsx`
- `作品列表_2026-05-20_0915.xlsx`

---

## 存档目录

```
抖音账号运营模板包/00_数据存档/
├── 作品列表_2026-05-18_1111.xlsx  # 主数据存档（带原始字段）
├── 作品列表_2026-05-18_1111.csv  # 带备注的辅助存档
└── 灵感素材库.md                   # 灵感素材记录
```

---

## 分析时数据溯源规范

每次做数据分析时，必须在输出中注明：

```
数据来源：作品列表_2026-05-18_1111.xlsx
数据获取时间：2026-05-18 11:11
有效样本：17条公开视频（排除3条隐藏）
```

禁止说"数据是今天"、"数据显示"——必须精确到存档文件名。

---

## 老陈提供额外数据时的处理

场景：老陈在对话中单独发送某个时间点的数据（如"发布8小时3,477"）

处理：
1. 在对话输出中记录该时间点数据
2. 如果该数据与存档xlsx存在差异，注明差异来源
3. 不覆盖存档，单独建立**时间点快照**

## 账号级数据时序存档（关键数据时间点.md）

账号主页、粉丝画像、账号诊断等数据**不存MEMORY.md**，统一追加到 `关键数据时间点.md`。

### 数据结构（每次采集 = 一个节点）

每个节点包含以下5个数据块，必须全部填写：

1. **账号基础**：`采集时间` `粉丝数` `关注数` `获赞数` `抖音号`
2. **近周期数据**：`周期` `播放量` `主页访问` `点赞` `评论` `分享` `新增粉丝`
3. **封面效率+互动**：`封面点击率` `完播率` `互动指数` `涨粉率`
4. **粉丝画像**：`性别` `年龄` `地域` `设备` `兴趣` `活跃度` `关注热词`（含采集日期）
5. **账号诊断**：`投稿量` `诊断周期` `各项指标 vs 同类均值 vs 排名百分位`

### 字段命名规范（统一snake_case）

```
账号基础：粉丝数 / 关注数 / 获赞数 / 抖音号
周期数据：播放量 / 主页访问 / 点赞 / 评论 / 分享 / 新增粉丝
效率指标：封面点击率 / 完播率 / 互动指数 / 涨粉率
粉丝画像：性别_男 / 年龄_<23 / 地域_Top1 / 设备_Top1 / 兴趣_Top1 / 活跃_重度 / 关注热词_1
诊断指标：投稿量 / 诊断周期 / 同类均值_播放 / 排名_播放
视频追踪：发布时播放 / 最终播放 / 增长倍数
```

### 禁止行为

- ❌ 覆盖历史节点——每次采集新增节点
- ❌ 在MEMORY.md写账号具体数值
- ❌ 用"数据是今天"/"数据显示"等模糊表述——必须精确到节点采集时间
- ❌ 把xlsx里的账号级数据（如总粉丝）当成最新值——xlsx只包含视频维度，账号维度看本文件
