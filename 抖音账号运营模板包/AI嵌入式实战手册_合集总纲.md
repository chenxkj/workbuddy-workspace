## 一、合集定位

### 一句话定位
**19年嵌入式老兵的AI升级路线图——不是科普，是实战。**

### 核心差异化
| 维度 | 大部分AI博主 | 本合集 |
|------|-------------|--------|
| 身份 | 纯AI从业者/产品经理 | 19年嵌入式+研发总监，真干过 |
| 内容 | AI概念科普/工具测评 | 真实工作场景下的AI落地方案 |
| 深度 | "这个工具很好用" | "我拿它解决了什么问题、踩了什么坑" |
| 独家 | 通用内容 | 嵌入式逆向+传感器AI化，全网几乎没人做 |

### 目标观众
| 画像 | 痛点 | 为什么看 |
|------|------|----------|
| 嵌入式工程师（3-10年） | 想用AI提效但不知从哪下手 | 老陈是同行，说得上话 |
| 硬件/逆向工程师 | 手动逆向效率低，想AI化 | 逆向AI化全网独家 |
| 研发管理者 | 想推AI落地但阻力大 | 总监视角，真实案例 |
| 计算机专业学生/应届生 | 想入行嵌入式+AI方向 | 完整路线图+工具链 |

### 内容原则
1. **每期必须能实操**——看完能动手，不是听完就忘
2. **真案例>假演示**——用真实项目素材，不编造
3. **踩坑经验是核心价值**——成功经验到处有，失败经验才稀缺
4. **不吹AI**——AI能做什么、不能做什么、什么时候会骗你，都说实话
5. **每期一个aha时刻**——至少一个"原来还能这样"的瞬间

### 发布策略
- **时长**：按内容自然长度，不硬卡（预估3-15分钟不等）
- **频率**：1-2期/周
- **平台**：抖音+B站同步
- **抖音适配**：前15秒放高能片段做钩子，中段干货，结尾引导收藏关注

## 三、每期通用结构模板

### 长视频结构（3段式）

```
┌─────────────────────────────────────────┐
│  钩子段（15-30秒）                        │
│  身份锚点 + 反常识事实 + 本期预告         │
│  例："19年嵌入式老兵，用AI逆向一个传感器   │
│       固件只用了4小时，以前要3天"          │
├─────────────────────────────────────────┤
│  干货段（主体，时长不限）                  │
│  问题→方案→实操演示→踩坑→优化            │
│  每2-3分钟一个信息密度高点               │
│  关键操作必须录屏                         │
├─────────────────────────────────────────┤
│  收尾段（30-60秒）                       │
│  本期要点回顾（3条以内）                  │
│  下期预告（如果有关联）                   │
│  引导：收藏+关注+评论区讨论               │
└─────────────────────────────────────────┘
```

### 抖音适配规则
- **前15秒必须是高能片段**（从干货段截取最震撼的部分前置）
- **中段如果超过3分钟没有画面变化，必须加字幕动画/画面切换**
- **结尾卡点BGM**，引导收藏

### B站适配规则
- **开头可以有15秒正式引入**（不用像抖音那么猛）
- **P1可以更完整**，P2放实操录屏
- **简介区放时间轴**，方便跳转

## 四、制作规范

### 拍摄风格（延续老陈风格）
- 口播：正面近景，纯白墙背景
- 表情：克制，不夸张
- 录屏：实操部分直接录屏，加关键步骤标注
- 素材：代码截图、原理图、工具界面后期剪入

### 每期交付清单
1. 完整脚本（口播逐字稿 + 录屏操作步骤）
2. 录屏素材清单（每步操作的具体步骤，方便提前录）
3. 标题方案×3
4. 话题标签（≤5个）
5. 描述文案
6. 封面方案（即梦Prompt）
7. BGM推荐
8. 时间轴标记（每30秒一个节点，方便剪辑定位）

### 封面风格
- 统一模板：深色背景 + 工具Logo + 大字标题
- 左上角固定：合集名"AI嵌入式实战手册"
- 右下角：期数编号
