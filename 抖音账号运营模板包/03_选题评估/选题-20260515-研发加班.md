# 选题评估：研发加班·深夜车内自省

> 评估日期：2026-05-15 | 分析师：选题分析师 | 调研深度：B级（摸清楚）
> 选题来源：老陈主动提出 | 拍摄场景：深夜车内，刚加完班，深度疲惫

## 一、调研深度：B级·摸清楚

### 1.1 竞品摸底

| 方向 | 市场现状 | 机会判断 |
|:-----|:--------|:--------|
| "加班好累"型 | 泛滥，同情疲劳 | ❌ 没人看了 |
| "反抗加班"型 | 已有爆款案例 | ❌ 老陈不适合走对抗路线 |
| "加班猝死/健康警示"型 | 震惊体，不可持续 | ❌ 与"讲真话"人设冲突 |
| **"加班是心理依赖"型** | **几乎空白** | **✅ 蓝海** |
| **"深夜车内自省"型** | **零竞品** | **✅ 首创** |

### 1.2 核心判断

**创作方向**：不讲道理，不分析加班，不说"你应该XX"。就是深夜车内一个42岁研发老兵的真实瞬间。让观众自己得出结论。

现有加班内容全部停留在"苦/累/惨/分析/反抗"的表面叙事。**没有人做过"只描述今晚发生了什么"的内容**。老陈在深夜车内，用真实疲惫状态，说一个极小、极具体的瞬间——不加评判，不总结道理——这种内容在抖音加班类目中**不存在**。

### 1.3 新颖性验证

| 维度 | 市场上有什么 | 我们要做的 |
|:-----|:-----------|:---------|
| 表达 | 分析/抱怨/教人/总结 | **只描述·零评判** |
| 内容 | "加班好不好/怎么办" | **"今晚发生了什么"** |
| 身份 | 匿名打工人 | **实名·42岁·19年研发·前总监** |
| 场景 | 工位/办公室 | **深夜车内·红灯前** |
| 钩子 | 结论/道理/金句 | **"今天已经是周五了"——一个瞬间** |
| 观众关系 | "听我说" | **"你看到了什么"** |

## 二、钩子方案（5选1）

### 选项1：E类·情绪暴击型（⭐推荐）

```
42岁，19年研发，凌晨12点从公司出来，我开车开到一半停在路边。
不是累了——是我想明白了一件事。
```

- **核心机制**：身份锚点（42岁/19年）+ 极端场景（凌晨路边停车）+ 开放式悬念（想明白什么）
- **适用理由**：天然匹配拍摄场景（车里），疲惫真实流露，悬念强制停留
- **2s跳出预测**：极低（≤25%），因为"开到一半停在路边"异常行为剧烈拉停

### 选项2：B类·反常识型

```
研发加班19年，我得出一个反常识结论：
加班最多的，往往不是最忙的——是最没安全感的人。包括我自己。
```

- **核心机制**：反常识 + 自曝 + 标签化（"没安全感的人"=身份标签）
- **适用理由**：智力刺激型钩子，引发"那我呢"的自我投射
- **风险**：稍微偏"讲道理"，情绪冲击力不如选项1

### 选项3：A类·冲突型

```
你以为加班是在拼事业？
19年研发老兵告诉你——很多时候，你只是在躲一个问题。
```

- **核心机制**：冲突翻转 + 身份背书 + 悬念
- **适用理由**：简短有力，适合≤45s的快节奏
- **风险**：稍显对抗性，"躲"字可能引发防御心理

### 选项4：C类·损失感型

```
19年加班，我算过一笔账——那些加到凌晨写的代码，80%第二天根本没通过评审。
真正可怕的不是这个80%，是你明明知道，还是继续加。
```

- **核心机制**：具体数字（80%）+ 矛盾行为（明知还做）+ 自省
- **适用理由**：数据记忆点强，"80%没通过评审"可被转述
- **风险**：偏长，适合50-60s版；前半句可能被误解为"效率抱怨"

### 选项5：F类·自嘲型

```
42岁研发老兵，凌晨才下班，坐车里我突然笑了——
19年了，我还在用加班证明自己有用。
```

- **核心机制**：身份反差（老兵→脆弱）+ 自嘲 + "证明自己有用"刺痛点
- **适用理由**：轻量化，笑中带泪，容易转述
- **风险**：情绪深度可能不如选项1

### ✅ 已确认钩子（2026-05-15 23:16）

**方向调整记录**：老陈先后否决了3个方向——
1. "心理依赖"视角 → 太假，没人想加班，都是不得已
2. "没人敢第一个站起来" → 站着说话不腰疼
3. "分析/洞察"型 → 只要分析就站到了外面

最终确认方向：**只描述，不总结。就说今晚发生了什么。**

```
【已确认钩子】
类型：E类·情绪暴击型（纯描述版）
钩子句：
42岁，19年研发。凌晨12点刚从公司出来。
等第一个红灯的时候，我掏出手机看周报。
然后我停住了——今天已经是周五了。

核心机制：身份锚点 + 具体时间 + 具体动作 + 日常瞬间的裂口
        → "今天已经是周五了"不解释不言明，观众自己得出答案
创作原则：不讲道理、不做分析、不总结 —— 只描述这个瞬间
来源：老陈确认
```

> **写稿铁律**：确认后的钩子句一字不动，直接作为逐字稿开头。
