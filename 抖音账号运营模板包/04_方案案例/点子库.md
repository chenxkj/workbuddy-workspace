### 点子002：私信2万学费让我收学员

**评级**：⭐⭐⭐⭐ B+级
**优先级**：2
**状态**：💡 待处理风险

#### 价值评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 人设价值 | ★★★★☆ | 展示真实影响力 |
| 情绪共鸣 | ★★★☆☆ | 有话题性 |
| 流量潜力 | ★★★★☆ | "2万"是强锚点 |
| 转化价值 | ★★★☆☆ | 不能真的收，但展示问的人多 |
| 合规风险 | ★★☆☆☆ | 需处理"收徒"话术 |

#### 风险分析

| 风险点 | 等级 | 处理方式 |
|--------|------|---------|
| "收徒"话术 | 🔴 高 | 必须改成"不是收徒" |
| 承诺教学效果 | 🔴 高 | 不承诺，只讲不做什么 |
| 留联系方式 | 🔴 高 | 绝对禁止 |
| 引导站外 | 🔴 高 | 只能评论区聊 |

#### 合规转化方向

```
❌ 原话（违规）：
"有人私信2万让我收学员"

✅ 安全版本（人设展示）：
"有人问我开不开课、收不收徒。
我不是做培训的，
但问的人多了，
我想了想，以后视频里一点点教你们。"

要点：
- 不承诺收徒/开课
- 不留联系方式
- 把问题转化为"视频教学"承诺
```

#### 建议形式
- **时长**：30-45秒
- **结构**：展示私信 → 表明态度 → 给出替代方案（视频教）
- **禁忌**：不能说"带你一起做"、"评论区留言"
