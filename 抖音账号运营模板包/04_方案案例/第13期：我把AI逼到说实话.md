# 第13期：我把AI逼到说实话

> **定位**：AI使用干货 | **评级**：A | **时长**：28秒 | **类型**：实测教程型
> **分镜**：素人简化版（固定正面+后期字幕）
> **核心解决方案**：多AI相互印证

---

## 一、问题诊断报告

### 1.1 选题背景

| 维度 | 分析 |
|------|------|
| **用户痛点** | AI有时候会说谎/瞎编，但用户不知道 |
| **市场现状** | 单个AI的答案无法验证真伪 |
| **选题价值** | 给出具体方法，让用户学会验证AI |

### 1.2 核心解决方案

**多AI相互印证**：

```
同一个问题，问两个以上的AI
如果答案一致 → 可信度高
如果答案完全不同 → 至少有一个在说谎
```

## 二、完整脚本（逐字稿）

```
【0-3秒 开场钩子】
我把AI逼到说实话——
它骗了我整整三次！

【3-10秒 揭示问题】
我问它一个问题，
它回答得很肯定。
结果我再问一遍，答案变了。

【10-20秒 揭秘逻辑+解决方案】
后来我发现了规律：
同一个问题，问两个AI对照。

答案一致，说明可信；
答案不同，说明有问题。

【20-25秒 强调效果】
豆包、ChatGPT、Kimi，同一个问题测一遍
谁在说谎，一目了然。

【25-28秒 收尾引导】
多AI印证，是AI时代的基本功。
我是老陈，**教真东西**。
```
