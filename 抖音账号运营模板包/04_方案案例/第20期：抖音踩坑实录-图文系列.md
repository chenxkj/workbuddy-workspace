### 图2 · 坑①

```
标题（32pt，白色，加粗）：
坑①：AI工具盘点多 ≠ 好内容

问题（20pt，白色）：
你以为"分享3个AI工具"是在帮粉丝
平台认为是批量低质内容

后果（20pt，红色强调）：
结果：这条视频被删了

原因（20pt，白色）：
一口气讲3个工具=浅盘点=同质化
触发抖音"批量低质内容"判定
直接限流为"仅自己可见"

解决方案（20pt，绿色）：
✓ 每次只讲1个工具，讲深不讲多
✓ 2天发1条，换选题，不连续同类型

金句（20pt，白色加粗）：
贪多 = 全部归零
```

### 图3 · 坑②

```
标题（32pt，白色，加粗）：
坑②：以为开头好就够了

问题（20pt，白色）：
2秒跳出率29.84%
前7秒留住了，后面全崩

数据对比（24pt，白色，大字）：
70秒视频
完播率 3.78%
平均只看到第7秒

VS

30秒视频
完播率 13.98%
平均看到第4秒

原因（20pt，白色）：
中间撑不住，不是开头不够好
是每5秒都没给用户一个"继续看下去"的理由

解决方案（20pt，绿色）：
✓ 不是缩短开头，是每5秒一个爆点
✓ 不能平铺直叙，必须有转折有冲突

金句（20pt，白色加粗）：
用户划走不是因为开头差
是因为中间没有"然后呢"
```

### 图5 · 坑④

```
标题（32pt，白色，加粗）：
坑④：以为干货多 = 有人看

问题（20pt，白色）：
你花了3小时写脚本
认真讲干货
数据：惨淡

VS

别人随便拍一个
讲个故事怼到脸上
数据：爆了

原因（20pt，白色）：
抖音是情绪平台，不是知识平台
干货是理性输出
情绪才是驱动点赞的核心

你花3小时写脚本 → 用户3秒划走
一个故事开头 → 用户想"然后呢"

结论（20pt，绿色）：
情绪驱动完播，干货驱动收藏
两个都要，但情绪是入口

金句（20pt，白色加粗）：
先让人停下来，再教他东西
```

```

✓ 钩子是内容和节奏
✓ 两者完全不冲突

金句（20pt，白色加粗）：
```
