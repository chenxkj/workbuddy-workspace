## 一、内容合规类（🔴 限流风险）

---

### 坑1：浅盘点型限流

| 字段 | 内容 |
|:-----|:-----|
| **踩坑期** | 第12期 |
| **踩坑背景** | 想快速起号，觉得多分享工具有用 |
| **原文本** | 标题：抖音起号的作弊级工具<br>口播：今天分享3个工具<br>内容：讲了3个AI工具 |
| **踩坑内容** | 开头直接说"分享3个工具"，讲了3个AI工具 |
| **后果** | 🔴 视频被限流，直接删除 |
| **根因** | 同质化内容触发"批量低质"判定 |
| **正确做法** | 深度单点，只讲1个工具，讲透 |
| **改后文本** | 标题：只有1%的人知道这个工具<br>口播：这个工具，让我多赚了X万<br>内容：只讲1个工具，讲透 |

---

### 坑2：违禁词触发

| 字段 | 内容 |
|:-----|:-----|
| **踩坑期** | 第15期 |
| **踩坑背景** | 回复粉丝问题时自然说出 |
| **原文本** | 口播：最近很多同学私信我说对未来迷茫<br>字幕：正常打出"私信" |
| **踩坑内容** | 口播："最近很多同学私信我说对未来迷茫" |
| **后果** | 🟠 机器审核标记 |
| **根因** | "私信"是违禁词，即使在陈述句里也会触发 |
| **正确做法** | 高危词提前替换，用"问我"替代"私信" |
| **改后文本** | 口播：最近很多同学问我对未来迷茫怎么办<br>字幕：用"问我"替代"私信" |

---

### 坑3：数字暗示违规

| 字段 | 内容 |
|:-----|:-----|
| **踩坑期** | 教训库记录 |

| **原文本** | 我之前年薪50万<br>现在每月多赚10k<br>存款增加了多少万 |
| **踩坑内容** | 口播中提到"年薪50万""每月多赚10k" |
| **后果** | 🟠 可能限流 |
| **根因** | 具体数字暗示薪资/存款/资产，触发违规 |

| **改后文本** | 我之前工资很低<br>现在比以前赚得多<br>经济压力小了 |

### 坑4：时长太长

| 字段 | 内容 |
|:-----|:-----|
| **踩坑期** | 第7期 |
| **踩坑背景** | 想讲得全面，内容越写越多 |
| **原文本** | 时长：70秒<br>结构：前面铺垫太多，没有爆点<br>节奏：平铺直叙 |
| **踩坑内容** | 时长70秒，前面铺垫太多，没有爆点 |
| **后果** | 🟡 完播率3.78% |
| **根因** | 视频太长+节奏平缓，观众7秒就划走 |
| **正确做法** | 严格25-30秒，删掉铺垫，只留精华 |
| **改后文本** | 时长：25-30秒<br>结构：删掉铺垫，只留精华<br>节奏：每5秒一个转折 |
