# 第14期：想让AI不说废话？先对它说这句话

> **定位**：AI使用干货教程 | **评级**：A | **时长**：28秒 | **类型**：实用技巧型
> **分镜**：素人简化版（固定正面+后期字幕）

---

## 一、问题诊断报告

### 1.1 选题背景

| 维度 | 分析 |
|------|------|
| **用户痛点** | AI夸得天花乱坠，但建议毫无用处 |
| **市场现状** | 豆包等娱乐类AI默认输出讨好内容，用户不知道可以要求它"闭嘴给干货" |
| **选题价值** | 给出一个具体指令，让AI从"彩虹屁机器"变成"有用助手" |

### 1.2 核心解决方案

**一句话让AI停止无效夸奖**：

```
"你是我的工作助手，不是拍马屁的下属。
禁止无效夸奖，只给具体、有用的建议。
如果我的方案有问题，直接指出，不要一味夸赞。"
```

## 二、完整脚本（逐字稿）

```
【0-3秒 开场钩子】
我做20年研发，
结果被AI彩虹屁夸了三个月——
想让AI不说废话？
先对它说这句话——

【3-10秒 揭示问题】
你是不是也被AI夸懵过？
"太棒了！""完美！""非常有创意！"
结果一看，全是废话。

【10-20秒 给出解决方案】
我教你一句万能指令：
"禁止无效夸奖，只给有用建议。"
加上这句话，AI立刻从彩虹屁变成真干活。

【20-25秒 强调效果】
很多娱乐向AI
你不说它就默认夸你，
因为让用户开心，是它的设计目标。

【25-28秒 收尾引导】
想要用好AI，先学会给它立规矩。
我是老陈，**教真东西**。
```
