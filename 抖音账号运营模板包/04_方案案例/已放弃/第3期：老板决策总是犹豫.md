## 一、选题评估（抖音策略师输出）

| 价值维度 | 分析 | 评分 |
|---------|------|------|
| 受众覆盖 | 所有中层管理者都有这个问题，不限行业/岗位 | ⭐⭐⭐⭐⭐ |
| 情绪共鸣 | "推不动老板"是职场人最高频的痛苦之一 | ⭐⭐⭐⭐⭐ |
| 差异化 | 普通博主会说"要沟通"，老陈能给4个具体动作 | ⭐⭐⭐⭐⭐ |
| 老陈人设契合 | 19年管理经验，经历过各种类型的老板，有真实发言权 | ⭐⭐⭐⭐⭐ |
| 讨论空间 | 评论区会有人分享成功经验和失败教训 | ⭐⭐⭐⭐ |
| 涨粉潜力 | 中等，内容实用性强，收藏率高 | ⭐⭐⭐ |

### ⚠️ 风险提示

| 风险点 | 应对方式 |
|--------|---------|
| 思维导图里的具体问题太尖锐 | 只提炼"老板决策犹豫"这个泛化主题，不提年终奖/薪资/裁员等 |
| 涉及真实公司事件 | 改为"我见过"而非"我们公司"，说结构不说事件 |
| 得罪老板群体 | 结尾主动说"老板也有老板的难"，但重点是给中层方法 |

### 📊 选题定级

> **定级**：B+（职场干货类，正常预期，内容实用性强，收藏率高）
> **预计播放**：3,000 - 20,000
> **预计完播率**：40% - 50%（问题共鸣强，用户会看到最后）
> **核心目标**：建立"中层推动老板"的方法论专家人设

## 二、问题可讲性判断

| 具体问题 | 能否讲 | 原因 |
|---------|--------|------|
| 老板决策犹豫不决 | ✅ 可以 | 泛化的管理问题，不指具体人 |
| 年终奖到现在没结果 | ❌ 不能 | 涉及具体薪资事件，太敏感 |
| 对研发无长期规划 | ✅ 可以 | 结构性问题，可泛化讨论 |
| 苏总/陈总具体定位 | ❌ 不能 | 涉及具体人名 |
| 招不到人，还留不住人 | ✅ 可以 | 行业共性问题，可泛化 |
| 实习生培养又离职 | ✅ 可以 | 结构性问题，可讨论 |
| 无年终奖/绩效考核扣工资 | ❌ 不能 | 涉及具体薪资制度 |
| 学不到东西/工作压力大 | ⚠️ 谨慎 | 可讲，但不能说"我们公司" |
| 解决不了就自己离开 | ❌ 不能 | 涉及个人职业规划 |
| 在职转型AI自媒体 | ✅ 可以 | 已经是公开的人设内容 |

## 三、完整逐字稿（v3.0 口语化版 · 可直接拍摄）

> **录制时长**：50-60秒
> **核心原则**：每句≤15字；无AI味；无管理学术语；停顿标注；结尾不硬升华

```
════════════════════════════════════════════════════════
【完整逐字稿】时长：50-60秒
════════════════════════════════════════════════════════

【开场 · 前3秒 · 黄金钩子】

  老陈（直视镜头）：
  "我等老板回复，
   等了3周。

   期间需求改了5次，
   开发做了两遍，
   最后老板说：先不做。

   ↓（停顿）
   中层最难受的，不是累。
   是白干。"


【问题拆解 · 第4-15秒】

  老陈：
  "老板犹豫，通常不是不想决策。

   是三个原因：

   信息不全。

   怕担责。

   没想清楚后果。

   你硬推，他更犹豫。
   你抱怨，他听不见。"

  （停顿）

  "那怎么办？"


【4个动作 · 第16-48秒】

  老陈（一字一顿）：
  "说4个动作，你试试看。

   第一，帮他把信息补全。

   不是你去告诉他。

   是让他看到——
   数据、对比、后果，
   摆在他面前。"

  （停顿）

  "第二，给他做选择题，
   不是问答题。

   A方案、B方案、C方案，
   各有什么后果。

   让他选，不是让他想。"

  （停顿）

  "第三，找到他的'非决策成本'。

   不决策，每天损失多少？

   这个数字，
   他自己会算。"

  （停顿）

  "第四，给台阶。

   '这个决策，可以分两步走，
   我们先做第一步。'

   让他容易开始，
   比让他一次做对，更重要。"


【结尾 · 第49-55秒】

  老陈（微笑）：
  "中层管理者的价值，
   不是执行，
   是在推不动的时候，
   找到推动的方法。"

  "我是老陈，只说真话。"

  [固定结尾动作]


【系列钩子 · 第56-60秒】

  "下期聊另一个死循环：

   招不到人，留不住人，怎么办。

   关注老陈，别错过。"

════════════════════════════════════════════════════════
```

## 三·补充：口播文本（提词器版）

> 复制以下内容到提词器使用，纯净无标注

```
我等老板回复，等了3周。期间需求改了5次，开发做了两遍，最后老板说：先不做。

中层最难受的，不是累。是白干。

老板犹豫，通常不是不想决策。是三个原因：信息不全。怕担责。没想清楚后果。

你硬推，他更犹豫。你抱怨，他听不见。那怎么办？

给你4个动作。

第一，把问题拆小。别一次推一堆决定上去。一次就推一件事，一个决定。

第二，给出选项。别问老板怎么办，问他A还是B。各有利弊，你已经想过了。

第三，说清楚后果。决策需要什么信息，就给他什么信息。别让他猜。

第四，给他时间。不是所有问题都要立刻决策。有些事情，让子弹飞一会儿。

老板不是神，他也有他的难。理解这一点，中层才能做得下去。

我是老陈，只说真话。

下期聊另一个死循环：招不到人，留不住人，怎么办。

关注老陈，别错过。
```
