# 第二十章、钩子库：100个可直接用的钩子句式

> **来源**：脚本撰写规范v7 × 内容创作专家 × NLP专场实战 × 老陈人设适配
> **日期**：2026-04-23
> **用途**：生成脚本时直接调用，按场景查，按编号用
> **核心原理**：人脑只对两件事停不下来——威胁 + 未完成。好钩子制造未完成的张力。

## 一、钩子使用指南

### 1.1 调用流程

```
┌─────────────────────────────────────────────────────────────┐
│  拿到选题 → 判断类型 → 翻对应类别 → 选评分最高的 → 套进去改  │
└─────────────────────────────────────────────────────────────┘

选题类型判断：
- 情绪/职场冲突 → A类冲突型
- 认知颠覆/干货 → B类反常识型
- 通用/故事 → C类悬念型
- 数据/经验 → D类数字型
- 共情/职场代入 → E类身份代入型
- 程序员视角 → F类程序员专属型（老陈专用）
```

### 1.2 评分说明

| 星级 | 吸引力 | 适用场景 | 说明 |
|:----:|:------:|----------|------|
| ★★★★★ | 顶级 | 前3秒 | 最强钩子，一个顶三个 |
| ★★★★☆ | 优秀 | 前5秒 | 强钩子，秒级抓住注意力 |
| ★★★☆☆ | 良好 | 过渡/转折 | 承上启下，维持注意力 |
| ★★☆☆☆ | 一般 | 备用/备选 | 组合使用，不单独用 |

### 1.3 套用规则

```
规则1：★★★☆以上才能单独用，★★☆☆必须组合
规则2：每个钩子只改[方括号]内容，不改结构
规则3：程序员专属型只有老陈能用，其他账号慎用
规则4：数字型必须真实，虚构数字会被骂
```

## 八、钩子组合公式

> 单一钩子不够强时，组合使用。**最强组合：冲突+悬念+数字**。

### 8.1 顶级组合（★★★★★）

```
冲突 + 悬念：
"有个程序员来找我，说他领导是个[傻X]——但后来我发现，问题不在他领导。"
"产品经理在我背后说我情商不行——我当时没反驳，因为[我没想清楚]。"
"凌晨2点，产品发来消息：需求又变了——我回了一句，他再也不敢了。"

数字 + 悬念：
"我做研发18年，踩过的坑可以写一本书——今天我只讲一个。"
"专科→研发总监，中间差了18年——靠的不是技术，是[3个字]。"

冲突 + 数字：
"没讲解，没评审，没排期——领导说：先做。结果我们返工了[3次]。"

程序员专属 + 悬念：
"给情绪装个防火墙——这是我在腾讯学到的，程序员最该掌握的[情商技巧]。"
```

### 8.2 钩子位置规范

| 位置 | 钩子类型 | 说明 |
|------|----------|------|
| **0-3秒** | 冲突型/悬念型 | 必须强，不能平淡 |
| **3-10秒** | 悬念续接/数字型 | 维持注意力 |
| **10-20秒** | 反常识/身份代入 | 正文转折 |
| **20-25秒** | 悬念收尾/金句 | 为结尾埋伏笔 |
| **25-30秒** | 人设锚点+悬念 | "关注我"引导 |
