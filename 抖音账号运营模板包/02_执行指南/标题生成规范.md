## 一、标题输出标准（自动化标准格式）

### 标准格式
```
主标题：xxx
副标题：xxx
情绪爆点：（可选）xxx
```

### 各部分定义

| 部分 | 定义 | 要求 |
|------|------|------|
| **主标题** | 5-15字，制造悬念/身份锚点/数字反差 | 必须有钩子，让人想点 |
| **副标题** | 10-20字，补充主标题，给出具体价值 | 承接主标题，不重复 |
| **情绪爆点** | 1-5字，强化情绪张力 | 可选，有则加分 |

### 示例

```
主标题：288位股东，我有话要说
副标题：42岁倔人，第一次公开这些数据
情绪爆点：（真实）

主标题：10天从2粉到288个
副标题：只靠一条视频，我想说几句真话
情绪爆点：（数据）

主标题：AI夸你=骗你
副标题：我信了三个月，发现全是废话
情绪爆点：（反常识）
```

### 禁用模式

| 模式 | 错误示例 | 问题 |
|------|----------|------|
| 主标题=副标题 | "涨粉难/涨粉其实不难" | 无层次 |
| 副标题剧透 | "播放264/完播5.79%我接受" | 用户看完不点 |
| 情绪爆点太虚 | "太牛了" | 无记忆点 |

## 二、核心公式（老陈专属·按优先级排序）

### 1. 身份 + 悬念 ⭐⭐⭐⭐⭐
```
格式：[身份标签] + [悬念/冲突]
示例：
- "三明学院出身，42岁研发总监做抖音，有人说……"
- "42岁倔人，第一次公开说这些"
- "我是老陈，288个股东等着我汇报"
```

### 2. 数字 + 反差 ⭐⭐⭐⭐⭐
```
格式：[具体数字] + [反差结果]
示例：
- "10天从2个粉丝到288个，我想说几句真话"
- "播放264，完播5.79%，涨粉0——我接受"
- "42岁，研发总监，288个粉丝，开始说真话"
```

### 3. 问题型 ⭐⭐⭐⭐
```
格式：[引发思考的问题]
示例：
- "为什么三明学院能出研发总监？"
- "AI夸你的时候，你信吗？"
- "288位股东想听什么？"
```

### 4. 仪式感 + 承诺 ⭐⭐⭐⭐
```
格式：[身份锚点] + [承诺/行动]
示例：
- "288位股东，我有话要说"
- "42岁倔人，第1次向288位股东汇报"
```

### 5. 反常识 ⭐⭐⭐⭐
```
格式：[颠覆认知的观点]
示例：
- "养AI不是为了夸自己"
- "做抖音不追热点，行吗？"
```

## 四、标题生成流程（自动执行）

```
【触发词】生成5个标题 / 帮我起个标题 / 用XX公式生成

1. 输入：本期主题 + 核心痛点
2. 匹配：从75个公式中选择最适合的2-3个
3. 生成：每个公式生成2-3个候选
4. 过滤：去掉禁用词 + AI味检测
5. 组装：每个候选组装为标准格式
6. 评估：按五维标准打分
7. 输出：保留Top 3，标注公式编号
```

### 自动化输出格式

**每个标题必须包含**：
```
主标题：（5-15字，制造悬念/身份/数字）
副标题：（10-20字，补充价值，承接主标题）
情绪爆点：（可选，1-5字强化情绪）
公式来源：（使用的公式编号）
```

### 输出示例

```
【标题1】公式：数字锚定型 #28 + 身份代入 #21
主标题：10天从2粉到288个
副标题：42岁倔人，说几句真话
情绪爆点：（数据）
推荐理由：数字开头建立可信度，副标题强化人设

【标题2】公式：仪式感 #4
主标题：288位股东，我有话要说
副标题：42岁研发总监，第1次公开这些数据
情绪爆点：（真实）
推荐理由：仪式感建立期待，副标题补充身份
```
