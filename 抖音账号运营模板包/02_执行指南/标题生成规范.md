# 老陈说AI · 标题生成规范

> 来源：Copywriting skill × 老陈人设适配
> 更新：2026-04-21

---

## 一、核心公式（按优先级排序）

### 1. 身份 + 悬念
```
格式：[身份标签] + [悬念/冲突]
示例：
- "三明学院出身，42岁研发总监做抖音，有人说……"
- "42岁倔人，第一次公开说这些"
- "我是老陈，288个股东等着我汇报"
```

### 2. 数字 + 反差
```
格式：[具体数字] + [反差结果]
示例：
- "10天从2个粉丝到288个，我想说几句真话"
- "播放264，完播5.79%，涨粉0——我接受"
- "42岁，研发总监，288个粉丝，开始说真话"
```

### 3. 问题型
```
格式：[引发思考的问题]
示例：
- "为什么三明学院能出研发总监？"
- "AI夸你的时候，你信吗？"
- "288位股东想听什么？"
```

### 4. 仪式感 + 承诺
```
格式：[身份锚点] + [承诺/行动]
示例：
- "288位股东，我有话要说"
- "42岁倔人，第1次向288位股东汇报"
- "各位股东，老陈来交作业了"
```

### 5. 反常识
```
格式：[颠覆认知的观点]
示例：
- "养AI不是为了夸自己"
- "做抖音不追热点，行吗？"
- "AI夸你=骗你，不夸你=真实"
```

## 二、禁用词（老陈版）

| 禁用词 | 原因 | 替代方案 |
|--------|------|----------|
| 格局炸裂/真的会谢 | 太娱乐化 | 直接描述 |
| 救命SOS/绝了 | 太情绪化 | 克制表达 |
| 后悔没早点知道 | 太营销 | 用事实说话 |
| 教你三招/学会这三点 | 太模板化 | 自然叙事 |
| 任何人错过我都会伤心 | 太讨好 | 真实邀请 |
| 具体薪资数字 | 违规 | 身份标签代替 |

---

## 三、标题生成流程

```
1. 输入：本期主题 + 核心痛点
2. 筛选：从5个公式中选择最适合的1-2个
3. 生成：每个公式生成2-3个候选
4. 过滤：去掉禁用词
5. 选择：保留最符合人设的1-2个
6. 标注：说明使用了哪个公式
```

## 四、评估标准

| 维度 | 问题 | 权重 |
|------|------|------|
| 身份锚点 | 前3秒有没有身份标签？ | 30% |
| 悬念感 | 有没有让人想点进去的悬念？ | 25% |
| 克制感 | 有没有感叹号/夸张词？ | 20% |
| 记忆点 | 有没有一个词让人记住？ | 15% |
| 人设契合 | 符不符合"42岁研发总监+只说真话"？ | 10% |
