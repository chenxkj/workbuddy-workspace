## 一、为什么要检测AI味

| 问题 | 影响 |
|------|------|
| AI味太重 | 平台识别 → 限流 |
| 讨好型输出 | 内容无价值，用户流失 |
| 套路化表达 | 用户审美疲劳，跳出率高 |

## 二、22条AI特征检测（按严重度）

### 🔴 严重（几乎只有AI会这样）

| # | 特征 | 检测标准 | 修复方法 |
|---|------|----------|----------|
| 1 | 堵住所有反驳 | 全文防反驳，生怕被骂 | 删掉防御性语句 |
| 2 | 知识全部输出 | 把知道的都塞进去 | 只留最核心的1-2个点 |
| 3 | 匀速排比 | 3个结构相同的句子并列 | 打破节奏，加长短句 |
| 4 | 同一个让步模板 | "虽然X但是Y"反复用 | 换一种转折方式 |
| 5 | 给概念起名字 | 自创词汇/缩写/框架名 | 用大白话 |
| 6 | 情绪曲线太光滑 | 没有起伏，像机器写的 | 加入真实情绪波动 |
| 9 | 没有任何犹豫 | 语气太确定，不敢质疑自己 | 加"可能""也许" |
| 10 | 精确到不真实的情绪 | "我感到99%的沮丧" | 模糊表达更真实 |
| 11 | 脆弱感服务论点 | 先卖惨再说观点 | 脆弱要真实，不要套路 |
| 12 | 把结论包装成"协议" | "这就是XX法则/定律" | 直接说结论 |
| 20 | 虚假的"讲个故事" | 故事和结论没关系 | 故事必须服务观点 |

### 🟡 中度（AI高频，但人也可能）

| # | 特征 | 检测标准 | 修复方法 |
|---|------|----------|----------|
| 7 | 替读者说蠢话 | "你是不是觉得..."然后反驳 | 删掉，假想敌太明显 |
| 8 | "不是X是Y"高密度 | 800字内出现3次以上 | 减少这个句式 |
| 13 | 每个段落收束金句 | 每段结尾都有金句 | 去掉，只留结尾金句 |
| 14 | 句子节奏过于均匀 | 长短一样，读起来平 | 打破均匀，加入长短变化 |
| 15 | 用身体感受替代论证 | "我能感受到..."代替逻辑 | 论证在前，感受在后 |
| 16 | 开头三件套 | 钩子+痛点+承诺全上 | 简化开头，直接切入 |
| 17 | 连接词过度使用 | "然而""因此""但是"太多 | 减少连接词 |
| 18 | 同义词刻意替换 | 刻意换词，不自然 | 用统一词汇 |
| 19 | 中文翻译腔 | "这意味着""也就是" | 口语化表达 |
| 21 | 结尾"你值得"式祝福 | "愿你成为更好的自己" | 删掉，干干净净结束 |
| 22 | 对"深刻"的过拟合 | 硬要升华到人生哲理 | 见好就收，不强行深刻 |

## 三、检测流程

```
1. 写完文案
2. 对照22条逐条检查
3. 标记有问题的点
4. 按修复方法修改
5. 重读检查是否还有AI味
```

---

## 四、老陈专属自检问题

| 问题 | 是AI写的吗？ |
|------|-------------|
| 这句话我能不能直接念出来？ | 不能 → 重写 |
| 我平时会这样说吗？ | 不会 → 重写 |
| 粉丝听了会不会觉得假？ | 会 → 重写 |
| 有没有非要升华的感觉？ | 有 → 删掉升华 |

## 五、快速自检表

**口播文案检查清单（5秒自检）**：

- [ ] 没有"匀速排比"
- [ ] 没有"因此""然而""所以"
- [ ] 没有结尾金句堆砌
- [ ] 没有"这意味着""也就是说"
- [ ] 没有"愿你""希望你""愿我们都"
- [ ] 没有硬要升华到人生哲理
- [ ] 这段我能直接念出来
- [ ] 粉丝听了不会觉得假

## 六、误伤说明（这些不是AI味）

| 特征 | 正常场景 | 判定标准 |
|------|----------|----------|
| "不是X是Y" | 反差对比 | 800字内≤3次 |
| 替读者说蠢话 | 经典修辞prolepsis | 虚构读者不被矮化 |
| 段落收束金句 | 短视频体裁要求 | 短视频不判定 |
| 堵住反驳 | 学术/法律论证 | 这类场景不判定 |

## 七、修复示例

| AI味原文 | 修复后 |
|----------|--------|
| "我感到极度的沮丧和焦虑，仿佛整个世界都在压迫我" | "我那段时间很焦虑" |
| "这就是著名的二八定律，也是我们今天要讨论的核心" | "20%的东西决定80%的结果" |
| "你可能会说，这不就是拖延症吗？但我想说的是..." | "拖延只是表面" |
| "因此，我们可以说..." | "所以..." |
| "愿你在AI时代找到属于自己的定位" | "关注我，少踩坑" |
