## 一、剪辑操作简化清单

### 录前准备（10分钟）
1. 手机固定机位，横屏/竖屏按平台选（抖音竖屏9:16，剪映直接适配）
2. 打开剪映，导入上期录好的素材
3. 确定本期脚本已熟读（不背稿，靠理解说）

### 剪辑流程（单期≤30分钟）

```
步骤1：粗剪（10分钟）
  → 保留完整段落，不掐细节
  → 删除明显卡壳段落（停顿>3秒可删）

步骤2：节奏调整（5分钟）
  → 语速偏慢没关系，不加速（素人感=真实感）
  → 停顿处适当留白，增强重量感

步骤3：字幕（5分钟）
  → 剪映自动识别 → 人工校对关键术语
  → 重点词加字幕高亮（如"活儿"/"本事"/"看清结构"）

步骤4：封面（5分钟）
  → 直接用下方封面模板
  → 固定位置放标题文字

步骤5：BGM（2分钟）
  → 从下方推荐歌单选一首
  → 音量：背景音乐30%，人声70%

步骤6：发布
  → 标题/描述/标签直接复制文档内容
  → 检查红线（薪资/公司名/裸辞等）→ 发布
```

### ⚡ 剪辑底线（必须遵守）
- 不加转场特效（闪白/滑动等），素人加特效=翻车
- 不加花字动画，静态字幕即可
- 不变速，真实语速
- 字幕不加颜色，统一白色黑边
