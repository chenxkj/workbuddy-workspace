## 二、30秒钩子分配

```
0-3秒   → 顶级钩子（冲突/悬念/数字），必须强
3-10秒  → 续接悬念或加数字冲击
10-20秒 → 反常识转折或身份代入
20-25秒 → 正文干货，埋1-2个程序员比喻
25-30秒 → 人设锚点 + "我是老陈，只说真话"
```

---

## 三、钩子组合公式（最强3种）

```
1. 冲突+悬念：
   "有个程序员来找我，说他领导是个傻X——但后来我发现，问题不在他领导。"

2. 数字+悬念：
   "我做研发18年，踩过的坑可以写一本书——今天我只讲一个。"

3. 程序员专属+悬念：
   "给情绪装个防火墙——这是我在腾讯学到的，程序员最该掌握的情商技巧。"
```

---

## 四、钩子自检（30秒视频）

```
□ 开头3秒有冲突/悬念/数字吗？（没有→重写）
□ 中间有程序员黑话吗？（没有→加F类钩子）
□ 结尾有"我是老陈"吗？（没有→加）
□ 钩子总数 ≥ 10个？（不足→补）
```

## 五、违规底线（速记）

```
❌ 不用"首先/大家好/随着/以上就是"
❌ 不用"格局炸裂/真的会谢/绝了/哭死"
❌ 结尾不说"交作业/评论区留言/私信"
❌ 数字必须真实，虚构数字会被骂
```
