# 老陈说AI · 脚本撰写规范

> 来源：dbs-hook × 模板包经验 × 老陈人设适配
> 更新：2026-04-22

## 一、开头公式（核心·来自dbs-hook）

### 黄金公式
```
开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```

### 老陈适配示例

| 组件 | 示例 | 说明 |
|------|------|------|
| 话题 | "选题和标题的区别" | 告诉用户要讲什么 |
| Hook | "我去年涨粉200万" | 制造吸引力 |
| 可信度 | "靠的就是搞清楚这个" | 建立信任 |
| **完整开头** | "我去年涨粉200万，靠的就是搞清楚选题和标题的区别" | 话题+Hook+可信度 |

### 老陈版开头公式

```
公式1：身份 + 数字 + 悬念
"三明学院出身，42岁研发总监，我用10天从2个粉丝做到288个——"

公式2：痛点 + 反问
"AI夸你的时候，你信吗？——我信了三个月，发现全是废话。"

公式3：反差 + 悬念
"善良的李亚鹏，认识半个娱乐圈，30年为什么赚不到钱？"

公式4：结果 + 反转
"播放264，完播5.79%，涨粉0——我接受。但这不是我要说的。"
```

## 二、开头的四大信条（来自dbs-hook）

### 信条1：开头是内容的试用装，不是标题的延续
- 开头必须**独立工作**
- 不能假设用户看了标题、看了封面
- 开头必须在**5秒内**独立建立吸引力

### 信条2：好开头公式
```
开头 = 话题 + Hook + 可信度
```
- 话题：告诉用户要讲什么
- Hook：制造"为什么看"的吸引力
- 可信度：建立"为什么信你"的信任

### 信条3：开头要制造悬念，不要直接给答案

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| AI夸你=骗你，**证明**AI不可信 | 给了答案 | AI夸你=骗你，**为什么**你还信？ |
| 他失败**证明**人脉不等于赚钱 | 说了结论 | 他失败，30年**为什么**还是没钱？ |

### 信条4：开头必须口播友好

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| 你以为你在自律？其实你只是在逃避执行 | 自问自答，念不出口 | 只要你没在执行，你的动作大概率就是逃避执行的借口 |
| 难道你不觉得XXX吗？ | 反问太多 | XXX |

## 三、内容质量自检（在优化开头之前）

### 3.1 内容完整性检查

| 检查项 | 标准 | 处理 |
|--------|------|------|
| 正文字数 | ≥200字 | 太少→警告 |
| 有无干货 | 有价值信息 | 没价值→停止 |

### 3.2 素材丰富度检查

从文案中查找以下5类素材：

| 素材类型 | 检查内容 | 优先级 | 老陈适配 |
|----------|----------|--------|----------|
| **数据冲击** | 大数字、对比数字 | ⭐⭐⭐⭐⭐ | 播放量、完播率、涨粉数 |
| **转变故事** | 之前vs之后，反差 | ⭐⭐⭐⭐⭐ | 三明学院→研发总监 |
| **金句** | 独立成立的观点 | ⭐⭐⭐⭐ | "只说真话" |
| **权威背书** | 人物、机构 | ⭐⭐⭐ | 腾讯、20年经验 |
| **痛点共鸣** | 目标人群的焦虑 | ⭐⭐⭐ | 转型焦虑、AI焦虑 |

### 3.3 诊断结果处理

| 素材数量 | 诊断结果 | 行动 |
|----------|----------|------|
| 0个 | 内容没有素材 | 停止，补充素材 |
| 1-2个 | 素材不够丰富 | 可以做，但开头冲击力受限 |
| 3个以上 | 素材丰富 | 继续优化 |

## 四、开头诊断维度（6项检查）

| 诊断维度 | 检查项 | 常见问题 |
|----------|--------|----------|
| **独立性** | 不看标题能理解吗？ | 假设用户看了标题 |
| **Hook** | 前5秒有抓手吗？ | 平铺直叙，没有数据/金句/反差 |
| **悬念** | 有没有直接给答案？ | 开头就说结论 |
| **可信度** | 为什么听你讲？ | 没有建立权威/成绩 |
| **口播友好** | 能直接念出来吗？ | 自问自答、书面语 |
| **匹配度** | 开头承诺的，正文能兑现吗？ | 标题说A，正文讲B |

## 五、生成优化方案（三种方法）

### 方法一：素材提取（优先级最高）

| Hook类型 | 示例 |
|----------|------|
| 晒结果+反转 | "10天从2粉到288个，很多人问我怎么做到的——其实我只是搞清楚了一件事" |
| 数据冲击 | "264播放，5.79%完播，涨粉0" |
| 反差/转变 | "从技术总监到抖音小白" |
| 金句 | "只说真话，不割韭菜" |
| 痛点+悬念 | "研究3个月AI，焦虑3年，后悔30年" |

### 方法二：素材增补

如果文案素材不够，主动增补：
- 真实数据或结果
- 具体案例或对比
- 反常识的结论

### 方法三：悬念制造

| 错误写法 | 正确写法 |
|----------|----------|
| 用了"证明" | 改成"为什么" |
| 直接给答案 | 用"问题"而不是"结论" |
| AI夸你=骗你，**证明**AI不可信 | AI夸你=骗你，**为什么**你还信？ |

## 六、完整脚本结构

```
┌─────────────────────────────────────┐
│  开头（0-5秒）                      │
│  话题 + Hook + 可信度               │
│  必须独立工作，5秒内建立吸引力      │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  痛点（5-10秒）                     │
│  说出目标人群的焦虑                  │
│  制造"说的就是我"的感觉             │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  正文（10-25秒）                    │
│  每5秒一个转折/爆点                  │
│  删除废话，只留核心观点              │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  结尾（25-30秒）                    │
│  金句收尾 + 引导关注                │
│  不说"交作业"，改说"关注我"        │
└─────────────────────────────────────┘
```

## 七、老陈专属注意事项

| 禁止 | 原因 | 替代 |
|------|------|------|
| 结尾说"交作业" | 违规引流 | "关注我，少踩坑" |
| 硬要升华 | AI味 | 见好就收 |
| 替观众说蠢话 | 太假 | 直接说观点 |
| 每段都加金句 | AI味太重 | 只留结尾金句 |
| "因此""然而"太多 | 书面语 | 口语化 |
