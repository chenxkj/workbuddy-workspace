## 一、开头公式（核心）

### 黄金公式
```
开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```

### 老陈版四大公式

| 公式 | 示例 |
|------|------|
| 身份+数字+悬念 | "三明学院出身，42岁研发总监，我从2个粉丝做到288个——" |
| 痛点+反问 | "AI夸你的时候，你信吗？我信了三个月，发现全是废话。" |
| 反差+悬念 | "善良的李亚鹏，认识半个娱乐圈，30年为什么赚不到钱？" |
| 结果+反转 | "播放264，涨粉0——我接受。但这不是我要说的。" |

### 开头四大信条

1. **开头必须独立工作**：不假设用户看了标题/封面，5秒内建立吸引力
2. **制造悬念，不给答案**："AI夸你=骗你，**为什么**你还信？"
3. **口播友好**：能直接念出来，不自问自答，不用书面语
4. **钩子类型优先**：冲突开场/反常识开场/场景开场/数字开场/身份代入开场

### 开头的死法（禁止）

| 死法 | 问题 |
|------|------|
| 以"随着"/"首先"/"大家好"/"今天我要讲"开头 | 平铺直叙，催眠 |
| 以"相信大家都有过"开头 | 没人有耐心 |
| 上来就讲背景/讲道理 | 没给看下去的理由 |

## 三、完整脚本结构（30秒版）

```
【0-3秒】钩子：话题+Hook+可信度，独立工作
【3-10秒】痛点：说出目标人群的具体焦虑
【10-22秒】正文：每8秒一个转折/新信息，不平铺直叙
【22-28秒】结尾：嘴替收尾/升维收尾，不升华
【28-30秒】人设锚点：我是老陈，只说真话
```

### 老陈专属结尾标准结构
```
我是老陈，18年程序员。
[行动钩子：关注我，下期见/我会把更多...]
我是老陈，只说真话。
```

### 结尾的死法（禁止）
- "以上就是今天的全部内容" / "感谢观看"
- "有问题可以在评论区留言"（让人不知道怎么回）
- 突然结束，没有收尾感
- 硬升华到人生哲理

## 四、正文节奏五工具

| 工具 | 操作 | 示例 |
|------|------|------|
| **长短句交替** | 短句有力，长句渲染 | "你被否定了。"（短）/ "那天你写了一千行代码，改了两版，上线后产品说——这不行。"（长） |
| **停顿留白** | 每段后停顿2秒 | "我很长时间都在想这个问题。（停顿）为什么我会被这些话点燃？" |
| **转折词要狠** | 铺垫三句，转折一句 | 你写了一千行。✓ 改了三版需求。✓ 有人说"重做"。✓（停顿）你什么感觉？ |
| **具象不抽象** | 具体画面感 | "职场压力大"→"产品说需求又变了，你改到凌晨两点，第三版上线后他说：算了不要了" |
| **金句密度** | 每段留一句让人想截图的话 | "我像个没有root权限的进程"/"情绪问题不是性格问题，是技术问题" |

## 五、人设一致性三要素

| 要素 | 操作 |
|------|------|
| 立场鲜明 | 我站哪边，说清楚。老陈：带过的人比多数人见过的bug多，但不是来教训人的 |
| 语言风格统一 | 用"你"不用"大家"，程序员黑话（GC/Ctrl+C/断点），短句不用报告腔 |
| 情绪节奏统一 | 整体犀利+实在，结尾偶尔温情收尾 |

### 老陈语言风格底线
- 用"你"不用"大家"/"我们"
- 程序员黑话为主，不用商业黑话（"赋能"/"抓手"/"打造闭环"）
- 不说"这意味着"/"本质上"/"说白了"
- 动词+名词直给，不绕

## 六、共情底层逻辑（2026-04-23验证）

**核心定义**：我说了一句话，你有了感觉，你想参与——这叫共情。
vs. 我抒发我想写的，不管别人听不听——这叫自嗨。

**短视频逻辑**：我端了一锅东西在煮，你要不要来趴着看。
**说话逻辑**：我在跟你讲一件事，你听懂了就行。

→ 讲故事就是讲故事，不用圆回来，不用升华
→ 观众看完故事，心里有自己的答案
→ 不把答案说出来
