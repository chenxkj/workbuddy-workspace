# 抖音违规词库 & 合规替换手册

> 版本：v1.0（2026-04-18）
> 用途：方案设计自查、发布前审核
> 说明：**没有永久清单，平台每周更新，AI语义审核持续升级**

---

## ⚠️ 为什么别人能用，我们用不了？

| 原因 | 解释 |
|------|------|
| **账号权重差异** | 老号宽松模型，新号高敏感模型 |
| **发布时间差** | 爆款可能是半年前/1年前发的，当时规则松 |
| **AI语义审核** | 从关键词→上下文+场景+语气联合判定 |
| **历史内容不回溯** | 已爆内容不重新审核，新内容严卡 |
| **语境+场景** | 同样的词，带货违规，日常可能合规 |

**结论：同样的词在不同账号、不同时期、不同语境下，合规性完全不同。**

### 每次做方案必查

```
□ 标题：有没有绝对化词？（最、第一、顶级、封神）
□ 开头：有没有诱导/夸大词？
□ 正文：有没有功效/承诺词？
□ 结尾：有没有导流词？（交作业、私信）
□ 字幕：口播和字幕是否双重触发？

□ 数字：有没有具体薪资/资产数字？
```

## 📌 重要提醒

1. **没有永久清单**：平台每周更新词库，今天合规，明天可能违规
2. **AI看整段语义**：不是单个词，而是场景+语气+用途综合判定
3. **权重差异**：大号宽松、小号严打，低权重号必须更干净
4. **历史不追溯**：已爆内容不再审，新内容严卡
5. **语境决定合规**：日常口语vs营销语气，同样的词不同结果
