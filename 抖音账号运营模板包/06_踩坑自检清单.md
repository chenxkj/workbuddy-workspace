# 抖音内容创作 · 踩坑自检清单

> 版本：v1.1 | 日期：2026-04-20
> 用途：每次做方案前自检，发布前复核
> 定位：把每个坑转化为可执行的规则

---

## ⚠️ 铁律（踩过必死的坑，碰都不要碰）

### 1. 批量低质内容（直接限流）
```
❌ 连续发同类型AI工具盘点
❌ "分享3个工具"、"盘点N个AI"开头
❌ 工具1→2→3模板化结构
❌ 高频发同类内容（间隔<2天）

✅ 每次换选题类型（避坑/故事/复盘/实操）
✅ 深度单点：30秒只讲1个点，讲透
✅ 发布间隔≥2天
```

### 2. 引流话术（直接限流）
```
❌ "评论区交作业"
❌ "带你一起做"
❌ "私信我"
❌ "收徒"
❌ "有需要加微信"

✅ "关注我，少踩坑"
✅ "有问题评论区问"
✅ "按这个做，有问题来说说"
```

### 3. 夸大词（触发审核）
```
❌ "作弊级工具"
❌ "直接封神"
❌ "7天破万粉"
❌ "保证赚钱"

✅ 用事实说话，不夸大
✅ "不放弃就成功，只是快慢而已"
```

### 4. 具体数字承诺（违规）
```
❌ 具体薪资："50万"、"10k"
❌ 具体存款："存了200万"
❌ 具体涨粉承诺："保证涨粉1万"

✅ 用情绪描述："工资太低"、"看不到头"
✅ 用身份标签："35岁"、"电工"、"上有老下有小"
```

## 📋 方案设计自检清单（做方案前必查）

### 一、开头钩子自检（3秒生死线）

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 身份+冲突 | 前3秒包含：身份+金额/痛点/冲突 | 只有观点，没有冲突 |
| 爆点前置 | 最强的钩子在第1秒 | 爆点藏在后面 |
| 无说教感 | 不像"劝你别做" | "别创业"、"别冲动"开局 |
| 有悬念 | 用户想问"然后呢？" | 平铺直叙 |
| 情绪到位 | 严肃/心疼/愤怒/扎心之一 | 太平、太理性 |

**不合格的钩子**：
```
❌ "粉丝要给我2万学费，我直接劝他别给！"（太平、无冲突）
❌ "今天分享3个AI工具"（浅盘点开头）
❌ "创业要谨慎，中年转行别冲动"（说教开局）
```

**合格的钩子**：
```
✅ "35岁电工拿积蓄做宠物洗澡机，还要交我2万学费！我直接骂醒他"（身份+金额+冲突）
✅ "用AI做抖音，90%的人在第一步就错了"（问题导向+悬念）
✅ "被豆包骂完，我养了只虾做运营总监"（反差+好奇）
```

### 二、内容结构自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 有故事 | 有具体案例/细节/画面感 | 只有观点+道理 |
| 有转折 | 每5秒一个转折 | 平铺直叙 |
| 干货前置 | 前7秒给2个爆点 | 干货后半段才讲 |
| 信息密度 | 一句话一个信息点 | 同样的话反复说 |
| 不说教 | 故事代替讲道理 | 观点→讲道理→结束 |

**不合格的结构**：
```
❌ 观点→讲道理→再讲道理→再强调（说教型）
❌ 前半段劝退，后半段才给方法（痛点后置）
❌ 同样的话换三种说法（信息密度低）
```

**合格的结构**：
```
✅ 故事→冲突→干货→结尾
✅ 前7秒：身份+冲突+情绪
✅ 每5秒一个转折或爆点
```

### 三、情绪价值自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 有情绪 | 严肃/心疼/愤怒/扎心之一 | 太理性、太冷静 |
| 有共情 | 用户会说"说的就是我" | 无共情点 |
| 有记忆点 | 结尾有金句或核心观点 | 干巴巴收尾 |
| 情绪驱动 | 情绪在前，干货在后 | 干货堆砌 |

**自检问题**：
- 看完这条视频，用户会想点赞吗？
- 用户看完会说"说的就是我"吗？
- 情绪够不够强？

### 四、节奏设计自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 时长 | 25-30秒（不超过35秒） | 超过40秒 |
| 语速 | 稍快但清晰 | 长停顿、重复句 |
| 每段撑住 | 每5秒有爆点/转折 | 中间大量流失 |
| 开头留人 | 前3秒有强钩子 | 开头太平 |

**节奏公式**：
```
前3秒：强钩子（身份+冲突+悬念）
第3-7秒：第1个爆点
第7-12秒：第2个爆点
第12-20秒：核心干货
第20-25秒：结尾+金句
```

### 五、结尾收尾自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 有金句 | 一句话总结核心观点 | 干巴巴收尾 |
| 引导关注 | "关注我"或"少踩坑" | 没有转化动作 |
| 不违规 | 不用引流话术 | "交作业"、"私信" |
| 符合人设 | "我是老陈，只说真话" | 结尾偏离人设 |

**不合格的结尾**：
```
❌ "学会了记得回来交作业"（违规引流）
❌ "赶紧去试试吧"（太平，无记忆）
❌ 说完干货直接结束（无金句）
```

**合格的结尾**：
```
✅ "我是老陈，只说真话。关注我，少踩AI的坑。"
✅ "不放弃，就一定会成功，只是快慢而已。"
✅ "你卡在哪一步？评论区告诉我。"
```

### 六、标题自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 无夸大词 | 不用"作弊级"、"封神" | 夸大词违规 |
| 无工具盘点 | 不用"分享3个AI" | 浅盘点标题 |
| 有钩子 | 问题/冲突/悬念之一 | 太工具化 |
| 人设+痛点 | 加人设标签或痛点 | 纯工具标题 |

**不合格的标题**：
```
❌ "豆包+龙虾，抖音起号的作弊级工具"（夸大词+工具盘点）
❌ "分享3个免费的AI工具"（浅盘点开头）
❌ "抖音运营教程"（太平，无钩子）
```

**合格的标题**：
```
✅ "用AI做抖音，90%的人在第一步就错了"（问题导向+悬念）
✅ "35岁电工拿积蓄创业，还要交2万学费"（身份+冲突+数字）
✅ "粉丝催更的AI起号教程，我给你扒出来了"（钩子+人设）
```

### 七、合规安全自检

| 检查项 | 检查内容 |
|--------|----------|
| 无具体薪资 | 不说"50万"、"10k"等 |
| 无联系方式 | 不留微信号/二维码 |
| 无引流话术 | 不用"交作业"/"私信"/"带你做" |
| 无夸大承诺 | 不用"保证"、"一定"、"绝对" |
| 无敏感内容 | 政治/医疗/法律不碰 |
| 选题合规 | 不是批量低质/同质化内容 |

### 八、AI内容专项自检

| 检查项 | 合格标准 | 常见错误 |
|--------|----------|----------|
| 不讨好 | 不因为AI夸你就推荐 | AI夸→你→推荐 |
| 客观分析 | 说AI能做什么+不能做什么 | 无脑吹AI |
| 不浅盘点 | 不"分享3个工具" | 浅盘点触发风控 |
| 真实价值 | AI能做什么、什么时候会骗你 | 讨好型输出 |

**AI内容公式**：
```
✅ 讲AI能做什么（具体）
✅ 讲AI不能做什么（诚实）
✅ 讲什么时候AI会骗你（识别）
✅ 讲怎么用AI避坑（实操）
```

## 🔴 评分标准（方案质量评级）

### 评级维度

| 维度 | A级标准 | B级标准 | C级标准 |
|------|---------|---------|---------|
| 开头钩子 | 3秒内身份+冲突+悬念 | 有钩子但不爆 | 太平/说教 |
| 内容结构 | 故事→冲突→干货→结尾 | 有结构但不完整 | 平铺直叙 |
| 情绪价值 | 有情绪+有共情+有记忆 | 有情绪但不够 | 太理性 |
| 节奏设计 | 每5秒一个爆点 | 有节奏但不紧凑 | 拖沓/中间流失 |
| 结尾收尾 | 金句+引导关注 | 有结尾但不有力 | 太平/违规引流 |
| 合规安全 | 全部合规 | 小问题 | 有违规风险 |
| AI内容 | 客观+不讨好+深度 | 有一定价值 | 浅盘点/无脑吹 |

### 综合评级

| 评级 | 要求 | 说明 |
|------|------|------|
| S级 | 7项全A | 爆款潜力，可直接执行 |
| A级 | 6项A，1项B | 优秀，可执行 |
| B级 | 5项A+2项B | 良好，需优化后执行 |
| C级 | 4项以下A | 较差，需大幅修改 |

| 第12期 | 引流话术违规 | 合规 | "交作业"→"关注我" |
| 第12期 | 夸大词违规 | 合规 | "作弊级"、"封神"要删 |
| 第16期 | 中间流失严重 | 节奏 | 每5秒一个爆点 |
| 第16期 | 开头太平 | 钩子 | 强钩子前置 |
| 第16期 | 说教型内容 | 结构 | 故事代替说教 |
| 第16期 | 情绪价值=0 | 情绪 | 严肃+心疼+扎心 |
| 第16期 | 方案太保守 | 执行 | 直接S级，不试探 |
| D4 vs D11 | 长视频完播崩 | 节奏 | 严格25-30秒 |
| 第14期 | AI讨好内容 | AI内容 | 教用户识别AI讨好 |
| 第15期 | 陈述句"私信"被误判 | 合规 | "私信我说对未来迷茫"是陈述事实，无引流意图，但平台机器审核会误判。改为"问我" |
| 第15期 | 钩子冲突不足 | 钩子 | "觉得不是985211"单独存在偏平，需形成反差（+身份结果："但我做到了研发总监"）|
| 第15期 | AI幻觉：把方案设计意图当成脚本内容 | 执行 | 方案备注写"人设反差强"，我误当成脚本里有反差句。**评分必须引用脚本逐字稿，不能引用备注/说明文字** |
| 第13期 | "学聪明了"有损人设 | 人设 | "学聪明了"=承认之前蠢，42岁研发总监不该这么说 | 改为"发现了规律"/"找到方法了"/"换了思路"，体现分析型人设而非自贬 |
| **通用** | **所有方案钩子缺身份锚点** | 钩子 | D13/D14/D15/D17钩子有冲突但脚本无身份信息 | **每期钩子必须加身份锚点：年龄/职位/背景+反常识事实** |
| 第15期 | **标题胜利/内容失败**：播放5991但完播3.35% | 整体 | 标题封面强→初始流量拿到，但前2秒钩子弱→40%划走→中间无爆点→7秒就停。收藏8，转发89。 | **封面标题和内容完播是两件事**——封面好≠内容好，封面方向对时尤其要检查开头钩子 |
| 第15期 | **封面强≠开头强** | 钩子 | 标题/封面拿到5991播放（目前最高），但2秒跳出40%、完播3.35%。封面是点击率，内容是留存率，不能互相替代 | 每条视频都要单独检查前2秒钩子，不能因为封面好就默认开头没问题 |
| **通用** | **期次文件重名/多版本并存** | 文件管理 | 2026-04-20：第18期出现3个文件（第18期真实自我+第18期真实自我vsAI焦虑+第18期图文系列）。原因：生成新版本时另存为不同文件名，而非替换原文件；图文系列和视频混用期次数 | **①同一期只保留一个文件；②修改直接改原文件；③图文系列单独编号不占视频期次** |
| **D18** | **56秒全程无身份锚点，涨粉0** | 钩子+结尾 | 口播56秒直到结尾才出现"老陈"，钩子"今天我想试试"无身份。2秒跳出39.1%，涨粉0，播放264 | 情绪型内容更要加身份锚点，"放飞自我"不是理由。结尾必须加"关注我"引导 |
| **D18** | **结尾无引导关注** | 结尾 | 结尾"今天我做我自己"无涨粉转化动作。实际涨粉0 | 结尾必须加"关注我"/"少踩坑"等引导，否则内容再真也涨不了粉 |
