## 简化互动原则

> 发完视频后，自己简单评论1条即可，不需要批量操作

| 操作 | 频率 | 示例 |
|------|------|------|
| 自己评论 | 1条/期 | "来了" / "先看看" |
| 回复粉丝 | 有则回 | 真实互动 |
| 刷评论 | ❌ 不做 | 破坏真实感 |

## 交付物模板

### 1. 📋 问题诊断报告

**格式**：
```
【本期主题】：xxx
【目标人群】：xxx
【核心冲突】：xxx
【预期价值】：xxx
```

---

### 2. 🎬 完整脚本（逐字稿）

**标准格式**：
```
【时长】：25-30秒
【结构】：
  - 开场钩子（3秒）：制造悬念，不给答案
  - 身份背书（3秒）："三明学院出身，42岁研发总监"
  - 核心内容（20秒）：每5秒一个转折
  - 结论建议（5秒）：给出明确观点
  - 结尾固定语（2秒）："只说真话"

【逐字稿】：
（开始写口播内容）
```

---

### 3. ✍️ 标题方案 ×5（新标准格式）

**标准格式**：
```
主标题：5-15字，制造悬念/身份/数字
副标题：10-20字，补充价值，承接主标题
情绪爆点：（可选）1-5字强化情绪
公式来源：使用的公式编号
```

**输出示例**：
```
【标题1】公式：数字锚定型 #35 + 仪式感 #4
主标题：10天从2粉到288个
副标题：42岁倔人，第1次向股东汇报
情绪爆点：（成绩）
推荐理由：...
```

---

### 4. 📊 内容质量评分卡

**自检标准**（≥70分发布）：

| 维度 | 检查项 | 是/否 |
|------|--------|-------|
| 开头钩子 | 前3秒有冲突/悬念/身份锚点？ |  |
| 节奏 | 每5秒有转折/信息增量？ |  |
| 克制 | 无AI味、无套路、无讨好？ |  |
| 金句 | 有记忆点/传播性？ |  |
| 合规 | 无违禁词/无引流/无敏感话题？ |  |

**总分**：_____ / 70分

## 爆款评估（简化版）

满足越多，爆款概率越高：

```
□ 选题有强情绪冲突
□ 标题含数字
□ 涉及AI/职场/中年等高搜索量赛道词
□ 有身份背书
□ 开场前3秒有画面冲击或语言冲突

触发 4-5 条 → 🟢 正常爆款预期
触发 3 条 → 🟡 普通视频
触发 0-2 条 → 🔴 低预期
```

## 质量控制红线

```
发布前必须同时满足：
□ 内容质量评分卡 ≥ 70分
□ 无违禁词（通过抖音文案检测工具）
□ 无外部平台引流（微信/QQ/链接等）
□ 固化标签已确认
□ 自己评论1条已准备
```
