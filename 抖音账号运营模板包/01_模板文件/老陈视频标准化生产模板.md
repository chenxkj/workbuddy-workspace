## 核心规则

### 标题 + 简介 三要素关联规则

**核心原则**：标题/简介各自承担不同作用，信息不重复，组合形成完整钩子链。

**三步钩子链**：
```
标题 → 制造悬念/仪式感/期待
    ↓ 问出"是什么/为什么"
简介 → 提炼洞察，制造好奇（与口播不同！）
```

### 5. 📝 视频描述（简介）

**本质**：视频的第三道钩子，出现在折叠区。用户在看完标题+开头后是否点进来看完，取决于简介。

**核心原则**：
- 简介 ≠ 口播复述
- 简介 = 提炼视频里没说出口的那层洞察
- 制造好奇，不给答案

**好简介的标准**：

| 标准 | 说明 | 示例 |
|------|------|------|
| **提炼洞察** | 说出视频里用行动展示、但没直接讲出来的结论 | 口播："我没说，让他问龙虾" → 简介："授人以渔的最好方式，是不给他鱼" |
| **不剧透** | 不提前说出结果、答案、金句 | 口播金句是"龙虾就是AI时代最好的渔" → 简介里不要出现"龙虾"这个词 |
| **制造好奇** | 让用户想点进来看"然后呢/为什么" | "过了会儿，截图发回来了" → 制造悬念 |

**禁止**：
- ❌ 照抄口播原话（会剧透）
- ❌ 列3条干货要点
- ❌ 与标题重复信息
- ❌ "想知道的评论区留言"类营销话术

**底部固定格式**：
```
只说真话

#老陈说AI #AI #职场 #研发总监 #xxx（最多5个标签）
```

> **⚠️ 身份信息原则**：简介是否需要加入"三明学院/42岁研发总监"——取决于这个身份是否与本条视频的核心洞察相关。
> - 如果身份是洞察来源（比如学历影响判断、职业经历带来独特视角）→ 写
> - 如果身份与内容无关（比如讲龙虾工具，跟哪个学校出身无关）→ 不写
> - 原则：身份是洞察的背书，不是万能装饰
```

### 第3维度「结构张力」：三不说教否决制

> 来源：第26期「明知山有屎」教训——"整体太弱，像在说教，车轱辘话"

**30秒快速自检**：

| 问题 | 是→ | 说明 |
|------|-----|------|
| 前面有没有已经把这个说清楚了？ | **车轱辘话** | 同义重复2次以上 |
| 这是不是在说"你应该这么想"？ | **说教感** | 出现"这是因为/道理是/其实"等 |
| 有没有一个"那一刻"的具体场景？ | **没故事感** | 无"那一天/那一刻/他说了/我看到"锚点 |

**否决扣分**：

| 问题类型 | 具体表现 | 扣分 | 引用来源 |
|----------|---------|:----:|---------|
| 说教感 | 出现"这是因为……/道理是……/其实……" | -10分 | 逐字稿第___行 |
| 车轱辘话 | 同一件事用不同说法重复2次以上 | -8分 | 逐字稿第___行 |
| 没故事感 | 无故事锚点（那一天/那一刻/他说了） | -7分 | 逐字稿第___行 |

**结构张力维度评分**：

| 得分 | 表现 |
|:----:|------|
| 15 | 有故事弧线+冲突双方+递进+悬念，三无问题全清 |
| 12 | 有故事弧线但递进不够，轻微重复感 |
| 9 | 有故事但讲得像流水账，或有1项三不说教问题 |
| 5 | 有2项三不说教问题，或缺乏故事弧线 |
| 0 | 3项全中，或像念说明书/讲方法论 |

**发布否决线**：结构张力 < 10分 → 直接否决

## 附件A：L1禁用词清单

### 句式禁用（说教感来源）

| 禁用词/句式 | 替换建议 |
|------------|---------|
| "这是因为……" | 直接说结果 |
| "道理很简单……" | 删除，直接陈述 |
| "其实（后面跟解释）" | 删除，直接陈述 |
| "首先……其次……最后" | 用"有一回/那天"叙事替代 |
| "更重要的是……" | 删除或合并到上一句 |
| "换句话说……" | 删除，结论直接说 |
| "因此……" | 改用"所以" |

### 词汇禁用（AI感来源）

| 禁用词 | 替换建议 |
|--------|---------|
| "赋能" | 说具体动作 |
| "抓手" | 说具体手段 |
| "打造闭环" | 说具体结果 |
| "本质上" | 删除 |
| "说白了" | 删除 |

### 句型禁用

| 禁用句型 | 替换 |
|---------|------|
| "我们都知道……" | 删除 |
| "相信大家都知道……" | 删除 |
| "这就是为什么……" | 改"所以" |

## 附件C：内容输出双轨原则

**每个主题可选覆盖两个方向（单轨达标即可）：**

| 方向 | 定位 | 目标感受 |
|------|------|----------|
| A轨：底层共鸣 | 程序员的自己人 | "这个总监站我们这边的" |
| B轨：专业管理 | 懂行的职业人 | "这个总监是真的懂管理" |

**A轨写法**：替程序员说出他们想说但没人说的话。先押中痛点，再揭示真相。
**B轨写法**：说出管理决策背后的真实逻辑。事实→逻辑→结论，不说教。

**实操要求**：立项时必须写出：
1. A轨：我要替目标观众说哪句他们说不出来的话？
2. B轨：我要让观众看到哪层他们平时看不到的逻辑？
