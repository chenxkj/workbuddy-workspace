# 💰 老陈抖音 · 投入产出预算方案
> **原则**：前期极简轻投，用数据驱动决策，不烧钱换虚荣流量
> **版本**：v1.0 正式版
> **日期**：2026-04-13

---

## 一、核心预算原则

```
极简投入三原则

① 先测自然流量，再用数据决定是否追加
   → 不在发布前预设DOU+金额，让视频自己"证明"值得投

② 每笔投放必须有明确的回报预期
   → 500元DOU+ → 预期带来多少粉丝？多少私域用户？值不值？

③ 冷启动期不追求爆款，追求"最低成本验证内容方向"
   → 前30天：验证哪类内容方向有自然流量 → 后续集中投这一类
```

## 二、分阶段预算方案

### 🚀 第一阶段：冷启动期（第1-30天）

**预算上限**：每月 **300元**
**单条视频上限**：100元（仅在数据达标时追加）

#### 投放策略：不投，让视频自己证明

| 动作 | 操作 | 花费 |
|------|------|------|
| 自然发布 | 不投DOU+，每天发布1条，观察自然流量 | 0元 |
| 数据观察 | 前24小时只记录数据，不做任何动作 | 0元 |
| 达标追加 | 仅对播放>5,000 且 完播率>40% 的视频追加 | 最高100元/条 |
| 月度总花费 | 所有投放合计不超过 | **≤ 300元** |

#### 本阶段目标：用300元验证2-3个内容方向

**判断逻辑**：
```
第1周：发布3条不同方向视频（AI实测/转型/职场），观察自然播放量

  ↓

第2周：选出自然流量最好的方向
  · 哪条 > 3,000播放 → 这个方向值得追投
  · 哪条 < 500播放 → 这个方向暂停或优化

↓

第3-4周：集中做被验证的方向
  · 对该方向数据好的视频追加DOU+
  · 每月最多追投3条视频
  · 确认月度总花费不超过300元
```

## 三、ROI追踪体系

### 核心ROI计算公式

```
月度ROI = （粉丝增长价值 + 私域引流价值 + 变现收入）÷ 月度投放总额

粉丝增长价值估算：
  · 1个精准粉丝 = 3-10元（根据私域转化价值估算）
  · 每月涨粉500人 × 5元 = 2,500元粉丝价值

私域引流价值估算：
  · 1个私域用户 = 10-50元（根据后续转化能力估算）
  · 每月引流100人 × 20元 = 2,000元私域价值
```

### ROI判断标准

| ROI倍数 | 判断 | 行动 |
|---------|------|------|
| ROI < 1x | 亏损 | 立即复盘，暂停投放或大幅降低预算 |
| ROI 1-2x | 持平 | 优化投放定向，减少浪费 |
| ROI 2-3x | 良好 | 保持现有策略，小幅加投 |
| ROI > 3x | 优秀 | 加大投放，扩大战果 |
| ROI > 5x | 超级 | 全力追投，直到ROI回落 |

## 四、DOU+投放实操指南

### 投放步骤（每次投放按此流程）

```
第1步：确认触发条件（播放>3,000 + 完播率>40%）
  ↓
第2步：确定投放金额（100-500元，根据口袋和信心度）
  ↓
第3步：选择投放定向
  · 首选：相似达人粉丝（找同赛道10万粉以内的账号）
  · 次选：兴趣标签（AI工具/职场提升/中年转型）
  · 不选：地域/年龄过窄（限制流量池上限）
  ↓
第4步：设置投放时长
  · 追投选"6小时"（快速放量）
  · 常规选"24小时"（平稳放量）
  ↓
第5步：发布后2小时观察数据
  · 数据继续上涨 → 追加投放
  · 数据停滞 → 停止投放，节省预算
```

### 定向优先级参考

| 定向类型 | 适用场景 | 效果 |
|---------|---------|------|
| 相似达人粉丝（5-20万粉同类账号） | 有明确对标账号时 | ⭐⭐⭐⭐⭐ 效果最好 |
| 兴趣标签（AI/职场/管理） | 无明确对标时 | ⭐⭐⭐⭐ 稳定 |
| 粉丝量（18-35岁男性为主） | 职场干货类内容 | ⭐⭐⭐ 需测试 |
|地域定向 | 地域特色内容 | ⭐⭐ 不推荐 |

## 五、零预算增长策略（贯穿全阶段）

> 即使完全不投放，以下方法也能带来自然增长：

### 免费流量获取

| 方法 | 操作 | 预计效果 |
|------|------|---------|
| **抖音热榜蹭流量** | 每天刷抖音热榜，找与AI/职场相关话题，48小时内发相关内容 | 单条可能带来500-2,000额外播放 |
| **评论区引流** | 在同赛道爆款视频下发布有价值的评论，引导用户点进主页 | 每天30分钟，预期涨粉10-30人/天 |
| **合集SEO** | 创建合集名称含搜索关键词（如"AI工具实测"） | 长期稳定带来搜索流量 |
| **定期直播** | 每周1次30分钟答疑直播 | 每次直播涨粉50-200人（零投放）|
| **互动话题** | 每条视频结尾设置问题，引导评论 | 可提升互动率30-50% |
| **跨平台导流** | 视频同步发视频号/B站，简介引导关注抖音 | 其他平台粉丝转化 |

## 七、常见误区提醒

```
❌ 误区1：视频没发就先投DOU+
   → 错！先看自然流量，数据好的才值得追投

❌ 误区2：每天固定投100元
   → 错！不要"撒胡椒面"，集中投数据验证过的内容

❌ 误区3：播放量低就追加投放
   → 错！播放低通常是内容问题，追加投DOU+不会改变内容质量

❌ 误区4：追求播放量数字好看
   → 错！目标是精准粉丝，不是虚荣数字。1万泛流量不如500精准粉丝

❌ 误区5：爆款后立刻追投
   → 正确！但追投后要持续观察，数据停滞立刻停止
```
