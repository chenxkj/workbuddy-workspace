## 简化互动原则

> 发完视频后，自己简单评论1条即可，不需要批量操作

| 操作 | 频率 | 示例 |
|------|------|------|
| 自己评论 | 1条/期 | "来了" / "先看看" |
| 回复粉丝 | 有则回 | 真实互动 |
| 刷评论 | ❌ 不做 | 破坏真实感 |

### 2. 🎬 完整脚本（逐字稿）

**标准格式**：
```
【时长】：25-30秒
【结构】：
  - 开场钩子（3秒）：制造悬念，不给答案
  - 身份背书（3秒）："三明学院出身，42岁研发总监"
  - 核心内容（20秒）：每5秒一个转折
  - 结论建议（5秒）：给出明确观点
  - 结尾固定语（2秒）："只说真话"

【逐字稿】：
（开始写口播内容）

【拍摄备注】：
  - 机位：正面近景，固定机位
  - 表情：克制，不夸张
  - 背景：纯色墙面
  - 素材：xxx（后期剪入）
```

### 3. 📊 流量预计 + 关键节点

**算法参考**（抖音冷启动3阶段）：

| 指标 | 初期(0-30天) | 成长期(30-90天) | 稳定期(90天后) | 本期预测值 |
|------|:----------:|:----------:|:----------:|:---------:|
| 自然播放量 | 500-3,000 | 3,000-20,000 | 20,000+ | **_____** |
| 完播率均值 | 30%-40% | 40%-50% | 50%+ | **_____** |
| 互动率 | 2%-4% | 3%-5% | 5%+ | **_____** |
| 涨粉量/条 | 20-200 | 200-1,000 | 1,000+ | **_____** |

**关键节点操作说明**：
```
发布后1小时：
  □ 查看基础播放（<500需检查标题/封面）
  □ 自己评论1条

发布后24小时：
  □ 完播率≥10% → 正常
  □ 完播率<8% → 下期优化开头
  □ 有评论 → 回复

发布后72小时：
  □ 进入推荐 → 保持更新频率
  □ 未进入推荐 → 检查内容质量
```

## 爆款评估（简化版）

满足越多，爆款概率越高：

```
□ 选题有强情绪冲突
□ 标题含数字
□ 涉及AI/职场/中年等高搜索量赛道词
□ 有身份背书
□ 开场前3秒有画面冲击或语言冲突

触发 4-5 条 → 🟢 正常爆款预期
触发 3 条 → 🟡 普通视频
触发 0-2 条 → 🔴 低预期
```
