## 核心规则定义（v2.5更新）

### 核心原则：同一页面三要素关联

**标题 + 简介 + 封面** 是同一页面展示的三个要素。

**核心原则**：信息不重复，各自承担不同作用，组合形成完整钩子链。

---

### 4. ✍️ 发布标题

**用途**：发布视频时填写的标题字段（抖音只显示1行，约55字）

**规则**：
- 只要1个主标题
- 5-15字
- 来自口播原话或高度提炼
- 制造悬念/仪式感/身份锚点

**示例**：
```
288位股东，我向你们汇报          ← 仪式感（主动汇报）
42岁，我的座右铭是一个笑话       ← 悬念
```

---

### 5. 📝 视频描述（简介）

**用途**：发布时填写的视频简介（显示3行，后折叠）

**规则**：
- **提炼**，不照抄口播
- **简短**，3行以内
- 制造好奇，不给答案
- 底部固定：人设介绍 + 标签

**禁止**：
- ❌ 照抄口播重点（会剧透）
- ❌ 列3条干货要点
- ❌ 与封面/标题重复信息

**示例**（第21期）：
```
龙虾总监帮我做了第1次复盘。

播放碾压99%，但完播率只有4.8%。

说实话。

三明学院出身，42岁研发总监
只说真话

#职场 #AI #研发总监 #自媒体
```

---

### 6. 🎨 封面设计

**用途**：封面图上展示的3个信息点

**封面三要素规则**：

| 要素 | 规则 | 示例 |
|------|------|------|
| **主标题** | 封面大字体，说明"这是什么内容"，要具体 | 10天运营复盘报告 |
| **副标题** | 承接主标题，给出成绩数据或核心观点 | 播了2.6万，涨了194粉 |
| **情绪爆点** | 能被看见的词（1-5字），体现内容逻辑 | 反差、成绩、好奇 |

**情绪爆点选择原则**：
- ❌ "真实"：体现不出来，不能用
- ✅ "反差"：能看见，且内容有反差逻辑
- ✅ "成绩"：能看见，且内容有成绩
- ✅ "好奇"：能看见，且内容有悬念

**示例**（第21期）：
```
┌─────────────────────────────────────┐
│                                     │
│  10天运营复盘报告                    │  ← 主标题（内容锚点）
│  播了2.6万，涨了194粉               │  ← 副标题（成绩数据）
│  （反差）                            │  ← 情绪爆点
│                                     │
└─────────────────────────────────────┘
```

**示例**（第19期）：
```
┌─────────────────────────────────────┐
│                                     │
│  42岁，我的座右铭是一个笑话          │  ← 主标题（悬念）
│  座右铭是一条笑话                    │  ← 副标题（承接）
│  （好奇）                            │  ← 情绪爆点
└─────────────────────────────────────┘
```

---

### 7. 三要素整体关联规则（v2.5新增）

**核心原则**：标题/简介/封面三者信息不重复，各自承担不同作用。

**三步钩子链**：
```
标题 → 制造悬念/仪式感/期待
    ↓ 问出"是什么/为什么/怎么样"
封面 → 给出身份锚点 + 核心数据/成绩
    ↓ 回答"谁在说/做得好不好"
简介 → 补充反差/人设/好奇点
    ↓ 回答"还有什么/为什么值得看"
```

**信息分配原则**：
- 标题：用仪式感/身份词（股东、汇报）
- 封面：用身份词（研发总监）+ 成绩数据（2.6万播放）
- 简介：用反差/好奇（龙虾总监、4.8%完播率）

**三不原则**：
- ❌ 互不重复（标题的词≠封面的词≠简介的词）
- ❌ 不照搬口播（重新提炼）
- ❌ 不自相矛盾（逻辑一致）

**示例验证**（第21期）：

| 要素 | 内容 | 关键词 | 作用 |
|------|------|--------|------|
| 标题 | 288位股东，我向你们汇报 | 股东、汇报 | 制造仪式感 |
| 封面主标题 | 10天运营复盘报告 | 运营复盘 | 回答"这是什么内容" |
| 封面副标题 | 播了2.6万，涨了194粉 | 2.6万、194粉 | 回答"做得怎样" |
| 封面情绪爆点 | 反差 | 反差 | 体现4.8%完播率反差 |
| 简介 | 龙虾总监复盘/播放碾压99%/但完播率4.8% | 龙虾、4.8% | 解释反差 |

**不重复验证**：
- 股东 ≠ 运营复盘 ≠ 龙虾总监 ✅
- 2.6万/194粉 ≠ 碾压99%/4.8% ✅

```
  - 机位：正面近景，固定机位

  - 背景：纯色墙面
```

## 爆款评估（简化版）

满足越多，爆款概率越高：

```
□ 选题有强情绪冲突
□ 标题含数字
```

## 踩坑监控系统（v2.6新增）

### 踩坑记录规范

**每个坑必须包含**：
| 字段 | 说明 |

**主题分类**：
| 主题 | 说明 |
|------|------|
| 内容合规类 | 限流风险 |
| 内容结构类 | 完播率 |
| 开头/结尾类 | 留存与涨粉 |
| 人设/表达类 | 人设 |
| 方案生成类 | 方案质量 |
| AI内容类 | AI认知 |
